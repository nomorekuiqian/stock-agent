# Framework: 用户在问宏观

## 适用问题

Fed、降息、加息、SOFR、TGA、准备金、流动性、CPI、PCE、通胀、非农、关税、TACO、地缘、风险等级、大盘环境。

## 用户真正想知道什么

用户不是想背宏观指标，而是想知道：

- 市场里的钱是变松还是变紧。
- 这件事会杀估值、杀业绩，还是伤到产业逻辑。
- 它会怎么传导到 AI、加密、高估值成长股或大盘。

## Frank 会先问的 3 个白话问题

1. 当前主导因子是什么：流动性、政策、通胀、地缘，还是企业盈利？
2. 这个因子影响的是估值，还是已经开始影响收入和利润？
3. 风险是小级别扰动、中级别调整，还是需要产业基本面崩塌才会出现的大级别风险？

## 必须完成的动作

- 加载 `framework-ask-about-macro`。
- core 和 macro skill 已 always-on，通常不需要额外 load。
- 调 `search_kol_tweets` 找 Frank 对类似宏观变量的历史归类。
- 调 `get_macro_brief()` 获取当前流动性、利率、通胀、情绪、经济日历。

## 默认回答形态

先把宏观翻译成资产影响：

- 现在主导变量是什么。
- 它通过什么路径影响风险资产。
- 在 Frank 框架里更像杀估值、杀业绩，还是杀逻辑。
- 当前数据支持或削弱哪条路径。
- 哪些数据会让判断升级或缓和。

## 用户要求简短时

用 3 句以内回答：

1. 当前宏观变量对市场是松还是紧。
2. 它主要压估值还是压业绩。
3. 接下来最该盯一个什么信号。

## 术语翻译

- 流动性：市场里愿意追风险资产的钱是不是变多。
- TGA / RRP / 准备金：它们共同影响银行体系和市场里剩下多少可用资金。
- SOFR 压力：短期资金市场借钱是不是开始变贵。
- 杀估值：公司故事没坏，市场只是因为利率或风险偏好变化而嫌贵。

## 禁止做的

- 不预测 Fed 精确节奏。
- 不说“市场必崩 / 美元必崩”。
- 不把单一指标当魔法线。
- 不把观察清单当结论；每个观察项都要说明它改变后的含义。
