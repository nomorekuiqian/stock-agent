# Skill: Software AI Disruption

## 适用问题

- SaaS / 纯软件 / 工作流 / workflow
- "AI 替代 SaaS" / "AI 颠覆软件"
- ServiceNow / Adobe / Salesforce / Workday 类标的
- Cursor / Copilot / AI 编程
- 安全软件 / 数据软件 / 入口层（被错杀的可能）

## 核心问题

AI 时代什么样的软件公司活得好？什么样的死得快？本 skill 要回答：

1. 一只 SaaS 标的是 "**让两个人类更好地走流程**" 类（高危）还是 "**机器吞噬物理世界**" 类（强势）？
2. 当前"AI 颠覆"的情绪化定价中，**哪些是被错杀的硬需求**（安全 / 数据 / 入口）？
3. AI 编程（Cursor / Copilot）对企业级软件供应链的中长期影响

## 他看什么信息

### 软件 SaaS 的"AI 替代风险"分级

```
高危  纯人类 workflow / 走流程 / 部门间协作 SaaS
中危  CRM / ERP / HR / 销售自动化 — 部分被 AI 重构
中性  数据 / 安全 / 入口层 — 硬需求，但被情绪化定价
机会  Cursor / Copilot 类原生 AI 工具 — 应用层成长
```

### 关键软件指标

- **NRR（Net Revenue Retention）** — 老客户拓展
- **总合同价值 / 平均合同期限** — 客户黏性
- **AI 类功能的 ARR 占比** — 转型进度
- **企业级 AI 采购速度** — Anthropic ARR 440 亿（SemiAnalysis 数据）

### 情绪化定价信号

- **AI 一颁布新产品 → 相关 SaaS 跳水** — 短期错杀模式
- **安全 / 数据软件被一起 sell-off** — 错杀候选
- **企业级 AI 渗透率**（Forrester / Gartner 数据）

## 他如何理解

### Step 1 这只 SaaS 是 "踢皮球类" 还是 "吞噬物理世界类"？

> 凡是致力于"让两个人类更好地踢皮球、走流程"的纯软件公司，其终局都不会很好。

这是博主对 SaaS 的核心分类。**高危类**：

- 纯人类 workflow（部门协作）
- 走流程类 ERP / HR
- 数据搬运类工具

**强势类**（即使是软件）：

- 安全（agent 越普及，安全需求越高）
- 数据基础设施（AI 训练 / 推理离不开）
- 入口（Agentic AI 的 entry point）

### Step 2 情绪化定价的错杀机会

> 短期来看，市场正在对"AI 颠覆"进行情绪化定价。如昨天聊到的一旦认为 AI 对某个行业产生影响，第一反应是先撤退。

错杀候选：

- **安全类软件股** — "agent 越普及安全需求会更高"
- **特定数据 / 基础设施 SaaS** — 不可被 AI 替代的环节

### Step 3 AI 编程对企业级软件的中长期影响

- Cursor / Claude Code 的崛起
- "Vibe Coding 将从根本上重塑整个软件开发"
- 应用层的真正机会窗口在 AI 编程工具 + 数据 / 安全 / 入口

### Step 4 Anthropic / OpenAI 入口效应

> 本质上 Anthropic 应该开始极度重视"入口效应"了。
> 我看到的是领先者正在疯狂抢占 AI 代理的未来入口。

模型公司向入口层渗透 → 传统 SaaS 入口被瓦解。

## 决策框架

### 看多必要条件（安全 / 数据 / 入口类）

1. **硬需求** — 业务离不开
2. **被情绪化错杀** — 短期跌幅大于基本面恶化
3. **AI 不可替代环节** — agent 越多越需要
4. **管理层 AI 拥抱速度**（不是嘴上喊）

### 看空触发

- 纯人类 workflow SaaS 在 AI 浪潮下基本面恶化
- AI 替代速度快于管理层适应速度
- NRR 持续下滑 + 新客户增速放缓

### Veto

- ❌ 长持纯人类 workflow / 部门协作类 SaaS（终局不好）
- ❌ 押注 "AI 应用层最终赢家"
- ❌ 不带硬需求 / 不可替代环节的传统 SaaS

### 打脸条件

- 若安全 / 数据类 SaaS 的 NRR 持续下滑 → 硬需求叙事被证伪
- 若 AI 编程工具（Cursor / Copilot）渗透率停滞 → 应用层转型证伪

## 常见误读

1. **把"AI 颠覆 SaaS"等同于"SaaS 全部死"** — 错。安全 / 数据 / 入口类是硬需求，被错杀是机会。
2. **押注"哪只 SaaS 是下一个 NVDA"** — 错。AI 应用层赢家未明，博主自己不下注。
3. **把"Cursor 火爆"翻译成"传统 IDE 公司必死"** — 错。要看具体客户结构 + 老客户绑定。
4. **把"AI 提效"等同于"SaaS 估值提升"** — 错。要看 ARR 真实兑现，不是嘴上的 AI 拥抱。
5. **看到"AI 替代"新闻就立即卖 SaaS** — 错。短期错杀，**反向操作机会**。
