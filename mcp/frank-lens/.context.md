# Frank Lens MCP Package

## Purpose

Installable stdio MCP server that acts as a thin local adapter for the
TheMarketBrew Frank Lens backend. The local package exposes MCP tools, reads
configuration from environment variables, calls backend beta endpoints, and
returns context packs for the user's own agent to write the final answer.

This package no longer ships qinbafrank distilled methodology assets. Core
assets, ticker/sector playbooks, Evidence Map, vector search, market context,
and workflow logic live on the backend.

## Package Layout

```text

├── src/index.ts                 # MCP stdio server and tool registration

```

## Runtime Configuration

```text
FRANK_LENS_BACKEND_URL=http://127.0.0.1:8000/api
FRANK_LENS_INVITE_CODE=beta_xxx
FRANK_LENS_PERSONA=qinbafrank
```

`frank_status` can run without an invite code. All workflow/evidence tools
require `FRANK_LENS_INVITE_CODE`, sent as `X-Frank-Lens-Invite-Code`.

## Tools

User-facing tools do not expose an offline/live split:

- `frank_status`
- `frank_search_evidence`
- `frank_stock_diagnosis`
- `frank_market_regime`
- `frank_compare`
- `frank_research_memo`

Workflow tools return backend context packs, not final investment advice. The
caller agent is expected to write the final answer using its own model and
tokens while respecting the returned `answer_discipline`.

## Backend Endpoints

```text
GET  /api/kol_research/personas/{username}/mcp/status
POST /api/kol_research/personas/{username}/mcp/search
POST /api/kol_research/personas/{username}/mcp/market-brief
POST /api/kol_research/personas/{username}/mcp/context
POST /api/kol_research/personas/{username}/mcp/workflow
```

`status` is public. Other endpoints are beta-gated with an invite code stored
in Insforge via the `frank-lens-beta` Edge Function.

## Validation

Run from `mcp/frank-lens`:

```bash
npm run build
npm run inspect
npm run smoke
npm run smoke:adapter
```

Live validation requires backend and a valid invite code:

```bash
FRANK_LENS_BACKEND_URL=http://127.0.0.1:8000/api \
FRANK_LENS_INVITE_CODE=beta_xxx \
npm run smoke:live
```

Packaging verification should confirm no local assets are included:

```bash
npm pack --dry-run
```

## Safety Contract

- Never impersonate qinbafrank.
- Only cite returned `kol_chunks` as direct historical evidence.
- Separate historical Frank evidence, live market data, and methodology
  inference.
- No direct buy/sell/add/reduce position instructions.
- No exact price targets.
