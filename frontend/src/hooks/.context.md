# Hooks - 自定义 Hooks

## 功能概述

全局共享的自定义 React hooks，包含搜索逻辑和 React Query 配置。

## 文件

| 文件 | 职责 |
|------|------|
| `useStockSearch.ts` | 股票搜索 hook (防抖 + 竞态 + 键盘导航) |
| `use-is-admin.ts` | 管理员判定 hook (调用 `GET /api/admin/whoami`，React Query 缓存)；Navbar/MobileMenu 用它条件渲染管理员入口 |
| `queries/query-client.ts` | React Query 客户端 (stale 5min, gc 30min) |
| `queries/query-keys.ts` | 集中管理所有 query key (7 域 ~22 个工厂) |
| `queries/use-report-data.ts` | 日报数据 hooks (list/latest/byId) |
| `queries/use-stock-data.ts` | 股票数据 hooks (quotes/profile/detail/history/valuation/snapshot) + AI 分析 mutations |
| `queries/use-liquidity-data.ts` | 流动性数据 hooks (metrics/history/global) |
| `queries/use-macro-data.ts` | 宏观数据 hooks (economy/sentiment/inflation/cpi/treasury/risk) |
| `queries/use-morning-report-data.ts` | 早报数据 hooks |
| `queries/use-digest-data.ts` | 摘要数据 hooks (list/byId) + 生成 mutation |
| `queries/use-watchlist.ts` | 自选股 hooks (query + 乐观更新 mutation) |
| `queries/use-weekly-report.ts` | 周报 hook |
| `queries/use-preferences.ts` | 用户偏好设置 hook |

## useStockSearch

### 功能

- 300ms 防抖搜索，调用 `api.searchStocks()`
- 竞态保护：快速连续输入只采用最新结果
- 键盘导航：ArrowDown/Up 循环高亮、Enter 选中、Escape 关闭
- 两种回调：`onSelect(result)` 选中搜索结果、`onEnterRaw(query)` 无结果时回车

### 返回值

```typescript
{
  query: string,
  results: SearchResult[],
  isSearching: boolean,
  showDropdown: boolean,
  highlightedIndex: number,
  inputProps: { value, onChange, onKeyDown, ... },
  clearSearch(): void,
  closeDropdown(): void,
}
```

## Query Keys

集中定义，按功能域分组：`macro`, `liquidity`, `weeklyReport`, `reports`, `stocks`, `watchlist`, `digests`。

使用方式：`queryKeys.stocks.quotes(['AAPL', 'GOOGL'])`

注意：`stocks.quotes()` 内部对 symbols 做 `.sort().join(',')` 确保缓存 key 稳定。

## Query Client

- SSR: 每次创建新 `QueryClient` (避免跨请求污染)
- 客户端: 单例模式 (`browserQueryClient`)
- 默认配置: `staleTime: 5min`, `gcTime: 30min`, `retry: 1`, `refetchOnWindowFocus: false`
- 挂载在 `Providers.tsx` 的 `QueryClientProvider` 中

## Query Hooks 缓存策略

| Hook 类别 | staleTime | gcTime | 说明 |
|-----------|-----------|--------|------|
| 股票报价 | 1min | 5min | 高频变动数据 |
| 日报/周报 | 30min | 2h | 低频更新 |
| 宏观/流动性 | 10min | 1h | 中频更新 |
| 自选股 | Infinity | 10min | 只通过 mutation invalidate |

### Watchlist 缓存隔离

- `watchlist` 查询必须使用 `queryKeys.watchlist.byUser(userId)`，不要使用跨用户共享 key。
- 这样可避免同一浏览器切换账号后出现持仓缓存串用。
- `useSaveWatchlist` 的乐观更新/回滚/invalidate 也必须使用对应 `userId` 的 key。

## Mutation 模式

- **乐观更新**: `useSaveWatchlist` — onMutate 立即更新缓存，onError 回滚，onSettled invalidate
- **缓存注入**: `useGenerateStockAnalysis` / `useGenerateTechnicalAnalysis` — onSuccess 用 `setQueryData` 写入分析缓存
- **列表刷新**: `useGenerateDigest` — onSuccess invalidate `digests.all` 触发列表重新获取

## 注意事项

- `useStockSearch` 的 debounce 用 `setTimeout`，测试需要 `vi.useFakeTimers()`
- query key 必须从 `query-keys.ts` 导入，不要手写字符串
- `getQueryClient()` 在 SSR 和 CSR 行为不同，注意测试环境区分
- 页面刷新数据用 `queryClient.invalidateQueries()`，不要手动 setState
- `api.ts` 的方法现在是纯 fetcher，不再有内存缓存，所有缓存由 React Query 管理
