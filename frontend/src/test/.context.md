# Test - 前端测试体系

## 功能概述

前端测试分两层：Vitest 单元/组件测试 + Playwright E2E 页面测试。

## 工具栈

| 工具 | 用途 | 配置文件 |
|------|------|----------|
| Vitest 4 | 单元测试 + 组件测试 | `vitest.config.ts` |
| @testing-library/react | React 组件渲染 + 断言 | - |
| @testing-library/jest-dom | DOM 匹配器 (toBeVisible 等) | `src/test/setup.ts` |
| jsdom | 浏览器环境模拟 | vitest.config.ts `environment: 'jsdom'` |
| Playwright | E2E 浏览器测试 | `playwright.config.ts` |

## 运行命令

```bash
npx vitest run                # 运行所有单元/组件测试
npx vitest run src/lib        # 只运行 lib 目录的测试
npx vitest --watch            # 监听模式

npx playwright test           # E2E 测试 (大多数页面需后端运行)
npx playwright test --headed  # 有头模式 (可视化)
npx playwright test e2e/login.spec.ts  # 运行 auth E2E（route mock，不依赖后端）
```

## 测试约定

### 文件组织

- 测试文件放在被测模块的 `__tests__/` 子目录
- 命名: `<模块名>.test.ts(x)`，组件测试用 `.tsx`
- E2E 文件放在 `frontend/e2e/`，命名: `<页面>.spec.ts`

### Mock 模式

| 场景 | Mock 方式 |
|------|----------|
| API 调用 | `vi.mock('@/lib/api')` |
| 认证 | `vi.mock('@/lib/auth')` 或 `vi.mock('@/contexts/AuthContext')` |
| 网络请求 | `globalThis.fetch = vi.fn()` |
| Next.js 路由 | `vi.mock('next/navigation')` |
| 时间 | `vi.useFakeTimers()` + `vi.setSystemTime()` |
| Next Image | `vi.mock('next/image', () => ...)` stub 为 `<img>` |
| React Query hooks | `new QueryClient({ defaultOptions: { queries: { retry: false } } })` + `QueryClientProvider` wrapper |

### 已知限制

- **模块级常量不可 mock**: `PAYWALL_ENABLED` 等在模块加载时求值的常量，`vi.stubEnv()` 无法在测试中改变它。这类分支只能通过 E2E 测试覆盖
- **api.ts 无内存缓存**: 缓存由 TanStack Query 管理，api 方法为纯 fetcher
- **Navbar 重复元素**: `MobileMenu` 会复制导航链接，测试中用 `getAllByText` 而非 `getByText`

### E2E 前提

- 后端 `uvicorn app.main:app --reload` 运行在 localhost:8000
- Playwright 会自动启动前端 dev server (localhost:3000)
- 测试账号: `voya.technologies@gmail.com` / `123456`
- `login.spec.ts` 使用 Playwright route mock 覆盖登录/注册/验证邮箱浏览器链路，不依赖测试账号或真实验证码邮件
- `login.spec.ts` 现在还覆盖“进入受保护页后命中 401，会自动清理陈旧登录态并强制回登录页”的兜底链路

## 注意事项

- `vitest.config.ts` 已排除 `e2e/**`，防止 Vitest 加载 Playwright 文件
- `.gitignore` 已包含 `test-results/`、`playwright-report/`、`blob-report/`
- 新增测试文件后无需额外配置，Vitest 自动发现 `**/*.test.{ts,tsx}`
- 组件测试中多个 render 可能导致 DOM 元素重复，用唯一 testId 或 `getAllBy*`
