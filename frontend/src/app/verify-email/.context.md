# Verify Email - 邮箱验证页

## 页面概述

`/verify-email` 处理注册后的 6 位验证码验证，也支持邮件链接携带 `token` / `otp` 的自动验证模式。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 验证码输入、自动验证、resend、pending profile name 补写 |
| `__tests__/page.test.tsx` | code/link 验证、pending profile、错误恢复 |

## 数据流

```text
/login signUp requiresEmailVerification
  -> storePendingVerification(email, name)
  -> /verify-email?email=<email>&redirect=<safe>
  -> AuthContext.verifyEmail(email, otp/token)
  -> set auth cookies via server action
  -> updateProfile(pending name)
  -> router.push(redirect)
```

## 注意事项

- `redirect` 必须继续使用 `sanitizeRedirectPath()`。
- 自动验证失败后应保留手动输入路径。
- pending name 只在验证成功后补写 profile，不要提前写。
