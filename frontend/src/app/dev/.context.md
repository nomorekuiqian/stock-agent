# Dev Pages - 本地开发辅助页

## 页面概述

`/dev/*` 放本地开发/诊断页面。当前只有 `/dev/feedback`，生产环境应返回 404。

## 路由

| 路由 | 页面 | 数据来源 | 认证 |
|------|------|----------|------|
| `/dev/feedback` | 邮件反馈统计调试面板 | `/api/dev/feedback` proxy | development only |

## 文件结构

| 文件 | 职责 |
|------|------|
| `feedback/page.tsx` | 开发反馈 dashboard，生产 `notFound()` |
| `../api/dev/feedback/route.ts` | Next route proxy，携带 `CRON_SECRET` 调后端反馈统计/list API |

## 注意事项

- `NODE_ENV !== "development"` 时必须不可用。
- `CRON_SECRET` 只在 server route 中使用，不要暴露给 client component。
