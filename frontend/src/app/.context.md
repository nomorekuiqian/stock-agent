# App Shell - Next.js App Router 根目录

## 功能概述

`frontend/src/app/` 是 Next.js App Router 根目录，包含全站 layout、首页、错误页、SEO route handlers，以及若干按目录拆分的页面模块。

## 核心文件

| 文件 | 职责 |
|------|------|
| `layout.tsx` | 全站 metadata、字体变量、`Providers` + `PageShell` 包裹、Vercel Analytics |
| `page.tsx` | 首页 landing，展示居中 Hero、订阅表单、Trust Signal、投研 Agent 主叙事、博主研究室、支撑功能区、定价、创始人故事和最终 CTA，并挂载 `LandingDelight` 与注册后 `HomeGuidedTour` |
| `error.tsx` | app-level error boundary |
| `not-found.tsx` | 404 页面 |
| `robots.ts` | robots route |
| `sitemap.ts` | sitemap route |
| `actions/auth.ts` | 认证 server actions |

## 全站依赖

- `components/Providers` 挂载 QueryClient、Theme、Auth、Subscription、Entitlements 等全局 provider。
- `components/PageShell` 提供导航和页面骨架；`?from=wechat` 等 WebView 流程会跳过全站导航和页脚。
- `frontend/middleware.ts` 先按 `PUBLIC_ROUTES` 做 cookie gate；权威 session 校验仍在 `/api/auth/session` 和后端 `verify_user_token`。
- `/kol` 是博主研究室总入口，公开展示 Qinbafrank 与 Serenity 研究室选择；`/kol/qinbafrank` 是 Qinbafrank 研究室 Ultra 的公开销售首页；`/kol/serenity` 是 Serenity 友好别名并重定向到 `/kol/aleabitoreddit`；`/qinbafrank` 与 `/frank-agent` 都作为 legacy redirect 保留在 `frontend/middleware.ts` 的 `PUBLIC_ROUTES`。
- `/panda`、`/for-you/monitor`、`/for-you/health` 页面已于 2026-10-17 删除；旧链接由 `middleware.ts` + `lib/feature-pause.ts` 重定向到 `/research` 或 `/for-you`。

## 首页 Landing 结构

首页由 `page.tsx` 和 `components/FeatureSections.tsx` 共同组成：

1. Hero：居中展示「你的 AI 投研团队」、四个能力标签、单一主 CTA 和「无需信用卡」说明。
2. Subscribe band：用 `SubscribeForm` inline 版本承接「收盘后复盘」场景。
3. Trust Signal：展示中文研究定位、美股标的、公开博主观点源，并说明以美股为核心，延伸覆盖港股、A 股、日股、韩国等相关市场信息。
4. Research Agent：主打三件事 -- 专业准确的股票数据和新闻、专业投研工作流、博主视角看待市场。
5. 博主研究室：当前重点介绍 `qinbafrank` 和 `Serenity`，展示博主头像，强调公开内容蒸馏、方法论和原文证据，不伪装成博主本人发言。
6. Research System：继续介绍四份日报、个股研究页、宏观仪表盘和持仓/日报/博主观点如何成为 Agent 上下文。
7. Pricing：免费 / Pro / Max 三档对比，文案围绕「先免费建立节奏，再按需要升级深度」。
8. Approach + Final CTA：介绍产品研究方式，不展示创始人姓名、头像或经历，最终 CTA 只保留投研助手主动作和盘后总览次动作。

首页支持 `/?tour=1` 触发轻量 Guided Tour：用 spotlight/coach mark 依次高亮顶部导航的「AI 研究助手 / 每日简报 / 投研 / 我的」四个入口，讲清每天看简报、需要深挖时进 Agent、从个股/宏观/博主研究室切入，以及在「我的」里添加自选股来启动专属监控。`tour=1` 是注册/首次 OAuth 后的正常入口，启动前会检查本地和后端 onboarding 完成状态；已完成用户会直接清理 URL，不再展示。`tour=home` 保留为手动强制预览入口，方便调试。Tour 完成或跳过时会 best-effort 调 `api.user.completeOnboarding()` 并写本地 marker，避免新用户随后进入工作台时被旧 onboarding gate 打断。

当前首页不展示 testimonial；Pricing 区块不展示用户数/抢先体验状态栏。Hero CTA 下方只保留「无需信用卡」短说明。首页中文说明文字应保持 `text-sm` 或更大，`text-xs` 仅用于英文 section label 等辅助标签。全页 delight 动效由 `LandingDelight` 按 `data-delight-section/card/action` 标记驱动，只做 reveal 和轻微 hover 反馈；Hero 布局保持居中版本，不放产品 preview。Guided Tour 锚点由 `components/navigation.ts` 的 `tourTarget` 驱动并渲染到 `Navbar` / `MobileMenu`，不要随意删除。

## 注意事项

- 修改 `layout.tsx` 会影响全站 hydration、字体、analytics 和 auth/onboarding provider 顺序。
- 独立 `/onboarding` 页面已移除；注册和首次 OAuth 的主 onboarding 入口是首页 `/?tour=1` 的 Guided Tour。
- 全站 `font-sans` / `font-reading` 现在使用 ChatGPT-style system UI 栈：ui-sans-serif / -apple-system / Segoe UI / Helvetica Neue / Arial / PingFang SC / Microsoft YaHei；`LXGW WenKai` 只通过 `.font-editorial` 用于 Hero、落地页和少量编辑化标题。`.font-data` 只用于价格、数字、ticker、日期和短代码。
- 首页 `page.tsx` 是 server wrapper，输出首页专属 metadata 与 Organization/WebSite JSON-LD；原交互内容在 `HomePage.tsx`，CTA 继续根据 `useAuth()` 展示不同文案。
- 首页定价入口复用 `lib/pricing.ts` 的当前月付价格，不展示折扣、划线原价或早鸟名额。
- 新增 route group 后，如属于长期维护模块，应在对应目录添加 `.context.md` 并更新 AGENTS.md 模块索引。

## 可恢复功能暂停（2026-09-04）

统一 UI 暂停配置在 `lib/feature-pause.ts`；middleware 与暂停页面 server layout 双层重定向。首页隐藏 KOL 营销模块和套餐条目，不改变整体布局。

## SEO 基础（2026-10-17）

- `lib/seo.ts` 统一正式 canonical 域名为 `https://www.themarketbrew.com`，与线上跳转目标一致；JSON-LD 序列化转义 `<`。
- canonical 按页面指定，不在根 layout 设置首页 canonical，避免子页继承。定价、联系、个股入口、宏观及日报归档有独立元信息。
- `/sitemap.xml` 是索引；`/sitemaps/[file]` 包含 static、stock、today、morning、twitter-digest，KOL 保持排除。动态列表按实际 total 分片，每片最多 1000 条；早晚报每批 100，推特归档每批 50。10 秒超时；上游失败返回 503/no-store，避免缓存不完整地图。静态页/股票页 lastmod 使用已知模板内容修订日，报告使用实际内容日期，不使用请求时间。
- middleware 精确放行 robots/sitemap；工具页通过响应头 noindex，robots 允许抓取该响应头。

## 官网基础页面（2026-10-17）

- `/about`、`/terms`、`/privacy` 为无需登录的静态信息页，复用 `InformationPage`，提供独立 metadata/canonical 并纳入 sitemap。
- `SiteFooter` 按产品、了解我们、条款与隐私分组，沿用 PageShell 的 WebView 隐藏规则；仅链接已存在页面和真实 X 账号。
- `/contact` 将 X 支持入口与现有评分反馈表单分开；保留反馈 API 和评分语义，不把咨询伪装成中性评分。反馈提交成功/错误可被辅助技术识别。
- 首页移除未经当前统计验证的活跃用户数、过时在职身份，以及未受暂停开关保护的研究室营销承诺。
- 条款与隐私依据现有功能编写，不承诺固定退款期限、即时删除、数据本地化或未验证的服务认证。

- 官网仅在页脚保留一个中性的 X / Twitter 外链；首页、关于、联系与政策页面不展示个人姓名、头像、职业经历。联系页定位到页脚社交入口。

- middleware 对裸域名保留路径和参数执行 308；若 Vercel 域名级跳转先执行，仍需在平台把原 307 改成 308。research 与所有带参数的普通页面输出 noindex，登录/research 同时设置 metadata robots。SEO 文件按精确路径放行，私有路由仍需认证。
