# Profile - 用户资料与订阅设置页

## 页面概述

`/profile` 是用户账户页，包含昵称、订阅状态、Stripe portal、邮件偏好和权益说明。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | profile 表单、订阅状态、邮件偏好编辑 |
| `__tests__/page.test.tsx` | auth/subscription/entitlement 状态回归 |

## 数据流

- `useAuth()` 提供 user、登录态和 `updateProfile()`。
- `useSubscription()` 提供 plan/status、checkout、billing portal。
- `useSubscription()` 也提供 Stripe scheduled cancellation 字段；已取消但仍在当前周期内的付费订阅继续展示会员档位，同时显示“订阅已取消 / 权益有效至 ...” indicator。
- `useEntitlements()` 决定邮件偏好是否可开启。
- 偏好保存调用 `api.subscriptions.updatePreferences(diff)`。

## 注意事项

- 未登录时跳 `/login?redirect=/profile`。
- 订阅卡直接按 API 返回的 `plan/status` 展示 Free/Pro/Max/Ultra/已取消等状态；Ultra 显示为 Max 权益 + Qinbafrank 资料包，不依赖 `isPro/isMax` 推断。
- Stripe Portal 周期末取消时仍保留付费权限到 `cancel_at` / `current_period_end`；订阅卡要显示“已取消”“权益有效至”，但仍保留管理订阅入口。
- 邮件偏好必须按 entitlement 强制约束，不能只依赖 UI disabled。
- `openBillingPortal()` 通常会页面跳转，按钮 loading 状态不要假设 promise 一定返回。
