# Auth API Route - SDK 认证路由

## 功能概述

Next.js API Route，委托给 Insforge SDK 的 `createAuthRouteHandlers` 处理所有认证操作。SDK 负责 session 管理、token 刷新、cookie 设置。

## 文件

| 文件 | 职责 |
|------|------|
| `route.ts` | 委托 SDK handler 处理 POST/GET/DELETE |

## 端点

| 方法 | 路径 | 功能 | 触发者 |
|------|------|------|--------|
| `POST` | `/api/auth` | SDK 处理登录/token 同步 | Insforge SDK |
| `GET` | `/api/auth` | SDK 处理 session 查询 | Insforge SDK |
| `DELETE` | `/api/auth` | SDK 处理登出/清除 cookie | Insforge SDK |

## 注意事项

- 纯 SDK 模式：所有认证逻辑由 `@insforge/nextjs/api` 的 `createAuthRouteHandlers` 处理
- SDK 通过 Insforge 服务器的 `Set-Cookie` 头管理 refresh token（`insforge_refresh_token`，`SameSite=None; HttpOnly; Secure`）
- 浏览器在页面刷新时自动发送 refresh token cookie 到 Insforge 服务器恢复 session
