# Pricing - 定价与 Checkout 成功页

## 页面概述

`/pricing` 展示 Pro / Max 订阅方案并触发 Stripe Checkout。`/pricing/success` 处理 Checkout 回跳后的订阅激活轮询。

## 路由

| 路由 | 页面 | 数据来源 | 认证 |
|------|------|----------|------|
| `/pricing` | 定价页 | `SubscriptionContext` + `lib/pricing.ts` | 否，checkout 需登录 |
| `/pricing/success` | Checkout 回跳/激活等待页 | `/payment/subscription-status?fresh=true` + `/payment/me/entitlements?fresh=true` | 需要用户 session |

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | Pro/Max 定价、状态 banner、checkout CTA |
| `success/page.tsx` | 轮询订阅/权益激活，刷新 React Query cache 后跳转 |
| `success/__tests__/page.test.tsx` | 激活等待、Frank Agent 回跳埋点回归 |

## 数据流

```text
/pricing
  -> 未登录点击订阅: /login?redirect=/pricing
  -> 已登录点击订阅: useSubscription().createCheckout(tier)
  -> Stripe Checkout
  -> /pricing/success?tier=<tier>&next=<path>
  -> 轮询 subscription-status + entitlements
  -> invalidate feature flags
  -> router.replace(next)
```

## 注意事项

- `normalizeNext()` 只允许站内 `/` 开头路径，防止 open redirect。
- Max 激活要求 `ai_research_engine` entitlement 到位后才跳转。
- Frank Agent landing 回跳到 `/frank-agent` 时会记录 `frank_beta_payment_completed`。
