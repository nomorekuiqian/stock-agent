# Reset Password - 重置密码页

## 页面概述

`/reset-password` 完成新密码设置。它与 `/forgot-password` 和邮件中的 reset code/link 配合使用。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 新密码输入、确认、提交重置、成功后跳 `/login` |
| `__tests__/page.test.tsx` | 成功状态和跳转回归 |

## 注意事项

- 使用共享 `PasswordField`，保持 auth 表单交互一致。
- 成功后跳回 `/login`，不要自动创建业务 session。
- 不要在 URL、日志或错误消息中暴露 reset token。
