# Sectors - 板块分析页面

## 功能概述

板块投研页面，展示各行业板块的 AI 分析摘要、成分股报价、新闻和事件。需要认证 (PaywallGuard)。

## 页面结构

| 页面 | 渲染方式 | 描述 |
|------|----------|------|
| `/sectors` | CSR | 板块列表 + 详情面板 |
| `/sectors/archive` | CSR | 板块历史分析 |

## 数据流

```
/sectors (client component)
  -> api.sectors.list()            // 板块列表
  -> api.sectors.getDigest(sector) // AI 板块分析
  -> api.getStockQuotes(symbols)   // 成分股报价
  -> SectorPanel 渲染
```

## 关键组件

- `SectorPanel` — 板块详情面板 (摘要 + 成分股 + 新闻)
- `SectorSelector` — 板块选择器
- `SectorPreview` — 板块预览卡
- `SectorDigestContent` — 板块摘要内容渲染
- `PaywallGuard` — 付费墙保护

## 注意事项

- 文件内含 `STOCK_NAMES` 硬编码映射表，与 `lib/stock-names.ts` 有重叠
- 需要认证才能访问完整内容
