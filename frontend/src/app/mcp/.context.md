# app/mcp — MCP Browser Authorization

## Purpose

Website-side pages for authorizing local MCP clients with a TheMarketBrew
account. This is not a public marketing page; it is part of the MCP
browser/device login flow.

## Routes

- `/mcp/authorize` reads `user_code` from the query string, shows the code to
  the logged-in user, and posts approval to `/api/mcp/authorize`.

## Auth

`/mcp/authorize` is intentionally not in `middleware.ts` `PUBLIC_ROUTES`. A
user without `app_access_token` or `app_refresh_token` is redirected to
`/login?redirect=/mcp/authorize?...`. The route handler then uses the normal
first-party `app_access_token` cookie to call the backend approval endpoint,
which enforces `verify_user_token`.

The page never asks for MCP tokens, website passwords, or browser cookies.
After approval it tells the user to return to the MCP client and call
`market_lens_auth_status`.
