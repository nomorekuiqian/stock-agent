# Screener - 个股筛选页面

## 页面概述

专业级 Stock Screener 前端页面，从 3,680+ 只可交易美股中通过预设策略和渐进式收窄筛选候选股。需要登录。

## 产品愿景

构建「自然语言 Agent + 预设策略 + 智能收窄」三位一体的股票筛选体验。用户可通过自然语言描述或预设策略入口快速缩至 ~30 只，再通过智能推荐维度或追问逐步收窄到 3-5 只候选，最终跳转 /stock 做深度研究。

## 数据流

### 自然语言路径
1. 用户输入自然语言 -> `api.screener.ask({ message, current_filters, history })` -> AI 解析 + 筛选 -> 展示 AiSummary + 候选
2. 用户追问 -> 累积对话历史 -> 再次 `api.screener.ask()` -> 更新结果
3. 最多 5 轮对话 (MAX_ROUNDS)

### 预设策略路径
1. 用户点击策略卡片 -> `api.screener.filter({ strategy })` -> 展示结果 + suggestions
2. 用户点击收窄 chip -> 条件累积为 custom filters -> `api.screener.filter({ strategy: 'custom', params: { filters } })` -> 更新结果

### 通用
- 每个条件 chip 可单独删除 -> 重新执行筛选
- 漏斗进度实时更新: 5,840 -> 28 -> 12 -> 5
- 切换策略时清空对话历史

## API 依赖

| 方法 | 端点 | 说明 |
|------|------|------|
| `api.screener.ask(req)` | POST `/api/screener/ask` | 自然语言选股 (Agent) |
| `api.screener.filter(req)` | POST `/api/screener/filter` | 执行预设筛选策略 |
| `api.screener.sectors()` | GET `/api/screener/sectors` | 板块列表（中英文） |
| `api.screener.status()` | GET `/api/screener/status` | 缓存状态 |

## 筛选策略

| 策略 | 动态列 |
|------|--------|
| hot_sectors | 周涨幅, 月涨幅 |
| volume_surge | 相对成交量, 30日均量 |
| value_discovery | PE, ROE, 52周位置 |
| high_dividend | 股息率, 派息率, 连续派息年 |
| momentum | 3月涨幅, RSI, >SMA50 |
| oversold_quality | RSI, ROE, 分析师评级, 上行空间 |
| by_sector | PE, 市值 |
| custom | PE, ROE |

## 条件累积机制

所有收窄操作统一转换为 `custom` 策略的 `filters[]` 列表。前端维护 `appliedFilters[]` 状态，每个 chip 对应一个 filter entry，可单独删除。删除后重新执行。

## 认证

需要登录（`PaywallGuard` + `useAuth` redirect）。暂不付费墙。

## 对话状态管理

- `chatHistory: ChatTurn[]` - 对话历史 (role + content/summary)
- `aiSummary: string` - 当前 AI 摘要
- `askLoading: boolean` - Agent 请求中
- `roundCount` - 当前对话轮次 (max 5)
- 切换策略或清除条件时重置对话状态

## 注意事项

- tvscreener 板块名称是英文（如 "Technology Services"），需要用 `SECTOR_ZH` 映射显示中文
- symbol 格式可能带交易所前缀（如 "NASDAQ:AAPL"），显示和跳转时需要 strip
- 桌面端表格列头可排序，移动端卡片模式
- 候选 < 5 只时卡片展开更多字段
- CandidateList 集成 watchlist: 每行有"加入持仓"按钮，使用 useWatchlist/useSaveWatchlist hooks，已添加的显示勾号
