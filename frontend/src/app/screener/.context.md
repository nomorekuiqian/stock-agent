# Screener - 对话引导式选股助手

## 页面概述

对话引导式 AI 选股助手。从 3,680+ 只可交易美股中，通过自然对话帮助用户（尤其是新手）找到个性化的股票。需要登录。

## 产品愿景

构建「对话引导式选股助手」— Agent 主动提问、提供动态选项，引导用户通过自然对话找到个性化的股票。用户只需点击选项或简单描述，Agent 负责把模糊偏好翻译为精确筛选条件。无轮次限制，可以一直对话直到找到满意的股票。

## 状态管理

使用 `useReducer` + `sessionStorage` 持久化（导航离开后回来恢复对话）：

```typescript
interface PickerState {
  phase: 'welcome' | 'chat';          // 页面阶段
  messages: ChatMsg[];                  // 对话历史
  accumulatedFilters: Filter[];         // 累积条件 (从后端回传)
  candidates: StockCandidate[];         // 右侧面板候选
  candidateCount: number;
  universeSize: number;
  pickReasons: { symbol, reason }[];    // 推荐理由
  funnelSteps: FilterStep[];            // 漏斗进度
  isLoading: boolean;
  error: string | null;
  hasNewResults: boolean;               // 移动端 badge
}

// Actions: SEND_MESSAGE, RECEIVE_RESPONSE, SET_ERROR, VIEW_RESULTS, RESET
// sessionStorage key: 'screener_picker_state' (tab 关闭自动清理)
// RESET action 同时清除 sessionStorage
```

## 数据流

### 一次 Chat Turn
1. 用户点击 chip 或打字 -> `dispatch(SEND_MESSAGE)` -> 添加 user bubble
2. `POST /api/screener/pick { message, history, accumulated_filters }` (需 Bearer token)
3. 后端: `StockPickerAgent.guide()` -> Agent 调用工具 -> 返回 message + options + filters + pick_reasons
4. 后端: filters 非空 -> `filter_custom(universe, filters)` -> candidates
5. 前端: `dispatch(RECEIVE_RESPONSE)` -> 添加 AI bubble + option chips -> 更新右侧面板

### Welcome -> Chat 过渡
- Welcome 页是前端硬编码 (零延迟)
- 用户点击 chip 或输入 -> `handleSend()` -> phase 切换为 'chat'
- 布局从居中 Welcome 变为 `fixed inset-x-0 top-16 bottom-0` 左右分栏（脱离文档流，避免与 layout.tsx 的 spacer+footer 冲突）
- 过渡时自动 `window.scrollTo(0, 0)` 重置滚动位置

## API 依赖

| 方法 | 端点 | 说明 |
|------|------|------|
| `api.screener.pick(req)` | POST `/api/screener/pick` | 对话引导选股 (需 auth) |
| `api.screener.status()` | GET `/api/screener/status` | 缓存状态 (DataStatus 组件) |

注：旧端点 `/filter`, `/ask`, `/sectors` 仍保留但本页面不再使用。

## 动画系统

| 交互 | CSS 类 | 说明 |
|------|--------|------|
| AI 文字 | `animate-word` | 逐字淡入 (blur(3px) -> 0, 15ms 交错) |
| AI 消息入场 | `animate-msg-enter` | translateY(12px) -> 0 |
| 选项 chips | `animate-chip-enter` | scale(0.85) -> 1, 60ms 交错 |
| 打字指示器 | `typing-dot` | 3-dot bounce |
| 右侧面板 | `animate-panel-enter` | translateX(24px) -> 0 |
| 数字更新 | `animate-number-pop` | scale(0.8) -> 1.05 -> 1 |
| Welcome icon | `animate-emerald-breathe` | box-shadow 呼吸 |

所有动画使用 `cubic-bezier(0.22, 1, 0.36, 1)` 缓动，纯 CSS 实现。

## 认证

需要登录（`PaywallGuard` + `useAuth` redirect）。`/api/screener/pick` 需要 Bearer token。

## 注意事项

- symbol 格式可能带交易所前缀（如 "NASDAQ:AAPL"），后端 execute_screener 工具已 strip 为纯 ticker；router.py 对 pick_reasons 有三层符号校验（直接匹配 → strip prefix → name→ticker 反查）
- CandidateList 集成 watchlist: 每行有"加入持仓"按钮
- Welcome chips 前端硬编码，不调 API，零延迟
- 无轮次限制，用户可以一直对话
- Agent 无显式 phase 状态机，自主决定何时提问/筛选/推荐
- Chat 模式使用 `fixed` 定位而非 `h-screen`，因为 layout.tsx 有 h-16 spacer + footer 会导致高度溢出
