# Screener - 个股筛选页面

## 页面概述

专业级 Stock Screener 前端页面，从 5,800+ 只美股中通过预设策略和渐进式收窄筛选候选股。需要登录。

## 产品愿景

构建「预设策略 + 智能收窄 + 未来自然语言 Agent」三位一体的股票筛选体验。用户从全市场出发，通过策略入口快速缩至 ~30 只，再通过智能推荐维度逐步收窄到 3-5 只候选，最终跳转 /stock 做深度研究。

## 架构

```
/screener (page.tsx, CSR, AuthGuard)
    |
    v
StrategyCards -- 8 个策略卡片，点击触发筛选
    |
    v
POST /api/screener/filter -- 返回 candidates[] + suggestions[]
    |
    v
CandidateList -- 桌面表格 / 移动卡片
    |
    v
NarrowingSuggestions -- 智能收窄 chips
    |
    v
用户点击 chip -> 累积条件 -> 再次 POST /filter (strategy=custom)
    |
    v
候选 <= 5 只 -> 提示点击进入 /stock/{symbol}
```

## 数据流

1. 用户点击策略卡片 -> `api.screener.filter({ strategy })` -> 展示结果 + suggestions
2. 用户点击收窄 chip -> 条件累积为 custom filters -> `api.screener.filter({ strategy: 'custom', params: { filters } })` -> 更新结果
3. 每个 chip 可单独删除 -> 重新执行筛选
4. 漏斗进度实时更新: 5,840 -> 28 -> 12 -> 5

## API 依赖

| 方法 | 端点 | 说明 |
|------|------|------|
| `api.screener.filter(req)` | POST `/api/screener/filter` | 执行筛选，返回候选 + 推荐 |
| `api.screener.sectors()` | GET `/api/screener/sectors` | 板块列表（中英文） |
| `api.screener.status()` | GET `/api/screener/status` | 缓存状态 |

## 筛选策略

| 策略 | 动态列 |
|------|--------|
| hot_sectors | 周涨幅, 月涨幅 |
| volume_surge | 相对成交量, 30日均量 |
| value_discovery | PE, ROE, 52周位置 |
| high_dividend | 股息率, 派息率, 连续派息年 |
| momentum | 3月涨幅, RSI, >SMA50 |
| oversold_quality | RSI, ROE, 分析师评级, 上行空间 |
| by_sector | PE, 市值 |
| custom | PE, ROE |

## 条件累积机制

所有收窄操作统一转换为 `custom` 策略的 `filters[]` 列表。前端维护 `appliedFilters[]` 状态，每个 chip 对应一个 filter entry，可单独删除。删除后重新执行。

## 注意事项

- tvscreener 板块名称是英文（如 "Technology Services"），需要用 `SECTOR_ZH` 映射显示中文
- symbol 格式可能带交易所前缀（如 "NASDAQ:AAPL"），显示和跳转时需要 strip
- 桌面端表格列头可排序，移动端卡片模式
- 候选 < 5 只时卡片展开更多字段
