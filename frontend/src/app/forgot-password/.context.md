# Forgot Password - 忘记密码页

## 页面概述

`/forgot-password` 负责发起密码重置邮件/验证码流程，并在支持 code exchange 的情况下引导用户进入下一步。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 输入邮箱、发送重置邮件、处理 code 状态和跳转 |
| `__tests__/page.test.tsx` | 成功状态和 redirect 行为回归 |

## 依赖

- `frontend/src/app/actions/auth.ts`
- `PasswordField`
- `auth-error-presentation`

## 注意事项

- 页面是公开路由，不应要求已登录。
- 成功后的跳转 timer 必须在 unmount 时清理。
- 错误文案应可恢复，不能让用户卡在无说明状态。
