# Unsubscribe - 邮件退订页

## 页面概述

`/unsubscribe` 处理邮件退订链接，调用 subscription API 取消指定 channel 的订阅。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 解析 channel/email 参数、调用退订、展示结果 |

## 数据流

```text
/unsubscribe?channel=<channel>&email=<email>
  -> api.subscriptions.unsubscribe(channel, email)
  -> 展示成功/失败
```

## 注意事项

- 页面公开访问，退订链接可能来自邮件客户端内置浏览器。
- 不要要求登录才能退订。
- channel 白名单和真实退订语义由后端 subscription 模块控制。
