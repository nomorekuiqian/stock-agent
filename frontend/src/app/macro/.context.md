# Macro - 宏观仪表盘页面

## 功能概述

宏观经济分析仪表盘，展示周报总览和四大维度（流动性、经济、通胀、情绪）的信号灯系统。主页是周报摘要，四个子页面分别深入各维度。

## 页面结构

| 页面 | 渲染方式 | 认证 | 描述 |
|------|----------|------|------|
| `/macro` | SSR + ISR (10min) | - | 周报总览 + 四维度信号灯 |
| `/macro/liquidity` | CSR | - | 流动性指标 + 净流动性图表 |
| `/macro/economy` | CSR | - | 经济基本面 (GDP/就业/消费) |
| `/macro/inflation-rates` | CSR | - | 通胀 & 利率 + 国债收益率曲线 |
| `/macro/sentiment` | CSR | - | 市场情绪 + VIX/恐贪指数 |
| `/macro/weekly` | CSR | - | 周报详情页 |

## 数据流

```
/macro (server component)
  -> fetch weekly-report API (服务端直接调)
  -> 解析 signal_lights (green/yellow/red)
  -> 渲染四维度卡片 + 各维度详细分析 (Markdown)

/macro/liquidity (client component)
  -> api.getLiquidityMetrics() 获取单个指标的最新值
  -> api.getLiquidityHistory(days) 获取净流动性历史与图表口径
  -> api.getGlobalLiquidity()
  -> api.getGlobalLiquidityHistory(days)

/macro/economy, inflation-rates, sentiment (client components)
  -> 各自调对应 api 方法
  -> 各自渲染图表和指标卡片
```

## 调用的 API

| API | 说明 |
|-----|------|
| `GET /api/weekly-report` | 周报数据 |
| `GET /api/liquidity/metrics` | 流动性指标 |
| `GET /api/liquidity/history` | 流动性历史 |
| `GET /api/liquidity/global` | 全球流动性 |
| `GET /api/macro-risk/dashboard` | 风险仪表盘 |
| `GET /api/macro-risk/economy` | 经济基本面 |
| `GET /api/macro-risk/inflation-rates` | 通胀利率 |
| `GET /api/macro-risk/sentiment` | 市场情绪 |
| `GET /api/macro-risk/cpi-breakdown` | CPI 分项 |
| `GET /api/macro-risk/treasury-commodities` | 国债 & 商品 |

所有端点公开，不需要认证。前端通过 TanStack Query hooks 缓存（staleTime 10min）。

## 注意事项

- 主页 ISR 10 分钟，服务端直接 fetch API (不走 TanStack Query)
- dashboard 和子页面的 `FredAreaChart` / `IndexAreaChart` 基于 `HistoryAreaChart`；图表请求天数由 `timeRange` 推导，不要恢复成固定 1825 天，否则 production 容易触发 FRED/YFinance 限流并导致图表随机失败
- dashboard 的关键 FRED 图表会传入指标当前值/前值作为 `fallbackData`；history API 失败时仍要避免出现 `Failed to fetch series history` 这类用户可见错误。
- `/macro/liquidity` 美国流动性核心 FRED 面板（WALCL/TGA/RRP/准备金/SOFR/EFFR/NFCI）直接使用页面已有的 `liquidity_history` 数据渲染站内 `HistoryAreaChart`，不要改回纯 TradingView iframe 或额外单序列请求；M2/全球央行资产/M2 等其他 FRED 图表走后端 `FredAreaChart`。中国/VPN 网络下外部 iframe 会出现空白/破图，FRED 即时请求也容易被 429。
- 信号灯系统: green=利好, yellow=中性, red=利空
- 四个维度用 `DIMENSION_LINKS` 常量定义，包含路由、中文名、分析 key
- 周报内容用 ReactMarkdown 渲染
- 子页面的图表组件用 `next/dynamic` + `ssr: false` 懒加载
- `/macro/liquidity` 中单个指标卡片要优先使用 `/liquidity/metrics` 的最新 series 值；`/liquidity/history` 主要服务净流动性历史图表；`/liquidity/global/history` 负责全球流动性指数 headline 与图表对齐
- 流动性金额展示要保留足够粒度：例如 `0.637B` 应显示为 `637M`，不能粗暴四舍五入成 `1B`
