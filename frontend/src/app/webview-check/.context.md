# WebView Check - WebView 登录态诊断页

## 页面概述

`/webview-check` 是微信小程序 web-view PoC 的只读诊断页，用来确认 cookie、storage、User-Agent 和 `/api/auth/session` 是否在 WebView 内正常工作。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 客户端探测 cookie/storage/session 并展示结果 |

## 注意事项

- 该页面只读，不做鉴权，不展示完整 token。
- `app_access_token` / `app_refresh_token` 是 httpOnly，`document.cookie` 读不到是正常现象。
- session 判断以 `/api/auth/session` 返回 user/accessToken 为准。
