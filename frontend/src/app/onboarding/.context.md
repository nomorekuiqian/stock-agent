# Onboarding - 新用户引导页

## 页面概述

`/onboarding` 是新用户首次进入后的引导和订阅转化页。页面读取 auth/subscription 状态，完成后写后端 onboarding 状态和本地 marker。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | onboarding step UI、Max checkout CTA、完成/跳过逻辑 |

## 数据流

```text
Onboarding page
  -> useAuth() 等待 session
  -> 未登录显示登录入口
  -> 完成/跳过: api.user.completeOnboarding()
  -> markOnboardingCompleteLocally(user.id)
  -> router.push("/today")
```

Max CTA：

```text
completeOnboarding best-effort
  -> createCheckout("max")
  -> Stripe Checkout redirect
```

## 注意事项

- `OnboardingGate` 的权威状态说明在 `frontend/src/components/.context.md` 和 `docs/constraints/auth.md`。
- 完成 onboarding 时必须同时更新后端和本地 marker；后端失败不能把用户困在页面。
