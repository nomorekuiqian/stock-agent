# Contact - 联系/用户反馈页

## 页面概述

`/contact` 是公开联系/反馈表单，直接向后端 `POST /api/feedback/user` 提交用户反馈。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 联系表单、rating/message/email 提交 |

## 数据流

```text
contact form
  -> fetch(`${NEXT_PUBLIC_API_URL}/feedback/user`, POST)
  -> 后端保存到 feedback/user 相关存储
  -> UI 展示成功或错误状态
```

## 注意事项

- 页面公开访问，不依赖登录态。
- 只使用 `NEXT_PUBLIC_API_URL` 指向后端，不要硬编码旧域名。
- 表单失败要保留用户输入，便于重试。
