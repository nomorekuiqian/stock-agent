# Request Access - 邀请资格申请页

## 页面概述

`/request-access` 收集用户背景和需求，调用后端邀请资格判断接口。当前 middleware 未把该路由列入 `PUBLIC_ROUTES`，因此实际访问会先经过 cookie gate。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 资格申请表单、`/invites/qualify` 调用、返回/提交状态 |

## 数据流

```text
request form
  -> fetch(`${NEXT_PUBLIC_API_URL}/invites/qualify`, POST)
  -> 显示资格判断/错误
```

## 注意事项

- 如果产品要求匿名申请，需要同步修改 `frontend/middleware.ts` 的 `PUBLIC_ROUTES` 并更新本文件。
- 不要在前端硬编码邀请码；资格判断由后端完成。
