# Frank Agent Legacy Redirect

## 功能概述

`/frank-agent` 是 Qinbafrank 旧 waitlist 链接的兼容入口。正式入口已迁移到 `/kol/qinbafrank`，这里只做服务端 redirect，并保留原 query string，避免旧 Twitter/UTM 外链丢失归因。

## 路由与数据流

| 路由 | 页面 | 数据来源 | 需要认证 |
| --- | --- | --- | --- |
| `/frank-agent` | Redirect to `/kol/qinbafrank` | `searchParams` | 否 |

`/frank-agent` 必须继续保留在 `frontend/middleware.ts` 的 `PUBLIC_ROUTES`，否则冷流量会先被 cookie gate 拦截，无法到达新的 Qinbafrank 页面。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `page.tsx` | 保留 query string 并 redirect 到 `/kol/qinbafrank` |
