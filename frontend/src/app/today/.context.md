# Today - 市场日报页面

## 功能概述

展示 AI 生成的每日市场分析报告。主页显示当天报告（或最新），子页面支持按 ID 查看历史报告和归档浏览。

## 页面结构

| 页面 | 渲染方式 | 描述 |
|------|----------|------|
| `/today` | SSR, fetch revalidate 5min | 当日报告，服务端获取数据 |
| `/today/[id]` | SSR + ISR (1h) | 按 ID 查看历史报告，含 SEO 元数据和 JSON-LD |
| `/today/archive` | CSR | 分页浏览历史报告列表 |

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 今日/最新日报 server page |
| `layout.tsx` | Today route layout |
| `loading.tsx` | Today loading skeleton |
| `[id]/page.tsx` | 日报详情 + metadata/JSON-LD |
| `archive/page.tsx` | 日报归档分页 |
| `_components/TodayActions.tsx` | 生成报告等客户端操作 |

## 数据流

```
/today (server component)
  -> api.reports.getByDate(today)    // 先查当天
  -> api.reports.getLatest()         // 没有则取最新
  -> api.reports.list(6, 0)          // 同时获取历史列表
  -> /api/twitter-digest/teaser/latest // 公开轻量预览，用于 Pro 转化 CTA
  -> ReportContent 组件渲染

/today/[id] (server component)
  -> api.reports.getById(id)
  -> generateMetadata() 生成 SEO
  -> generateJsonLd() 生成结构化数据
  -> ReportContent 组件渲染

/today/archive (client component)
  -> api.reports.list(pageSize, offset)
  -> 分页状态管理
```

## 调用的 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/market/reports/date/{date}` | - | 按日期获取报告 |
| `GET /api/market/reports/latest` | - | 获取最新报告 |
| `GET /api/market/reports/{id}` | - | 按 ID 获取报告 |
| `GET /api/market/reports` | - | 列表 (分页) |
| `GET /api/twitter-digest/teaser/latest` | - | 推特 KOL 日报轻量预览，渲染 Pro 转化区块 |
| `POST /api/market` | - | 生成新报告 (TodayActions 触发) |

## 关键组件

- `ReportHeroBanner` — 收盘日报主视觉 Banner，使用 `/report-banners/evening-report-banner.png`
- `ReportContent` — 报告内容渲染 (指数、新闻、摘要、日历)
- `TodayActions` — 客户端操作栏 (生成报告按钮)

## 注意事项

- 主页是 server component，使用 `force-dynamic` 避免生产构建依赖后端即时可用性；服务端 fetch 设置 10s 超时，并保留 5 分钟 revalidate hints
- `[id]` 页面有完整的 SEO 支持 (OpenGraph + Twitter Card + JSON-LD)
- `isToday` 判断用 `report_date === marketTodayStr()`，使用美西时间
- archive 页面的分页在前端维护 page 状态
- 日报页不展示 AI 投研免费次数横幅；研究配额提示只保留在 `/research` 流程内
