# Login - 登录/注册页

## 页面概述

`/login` 是邮箱密码登录、邮箱注册和 Google OAuth 入口。认证实现依赖 `AuthContext` server-cookie bridge，不使用 `@insforge/nextjs`。传入 `mode=signup` 时默认展示注册态，且无显式 redirect 时注册完成默认回到首页 `/?tour=1`。

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 登录/注册表单、Google OAuth、WebView 提示、redirect 保存 |
| `__tests__/page.test.tsx` | redirect sanitize、已登录跳转、邮箱验证注册流 |

## 数据流

```text
/login?redirect=/target
  -> mode=signup 时初始展示注册表单
  -> sanitizeRedirectPath()；登录默认 /today，注册默认 /?tour=1
  -> sessionStorage.auth_redirect = redirect
  -> AuthContext.signIn() / signUp() / signInWithGoogle()
  -> AuthContext 恢复 isAuthenticated
  -> getStoredAuthRedirect()
  -> router.push(storedRedirect)
```

注册需要邮箱验证时：

```text
signUp()
  -> storePendingVerification(email, name)
  -> /verify-email?redirect=<safe>&email=<email>
  -> 验证完成后默认进入 /?tour=1 的首页 Guided Tour
```

## 注意事项

- redirect 必须用 `sanitizeRedirectPath()`，拒绝外站 URL 和 `//`。
- OAuth 在内置浏览器中可能不可用，页面用 `isInAppBrowser()` 展示复制链接提示。
- 登录错误通过本页 `ERROR_TRANSLATIONS` 转成用户可读中文。
