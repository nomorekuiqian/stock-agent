# For You - 个性化 Brew 页面

## 功能概述

用户的个性化投资仪表盘。基于用户自选股 (watchlist) 生成个性化市场摘要 (digest)，需要登录。是前端最复杂的功能模块。

## 页面结构

| 页面 | 渲染方式 | 认证 | 描述 |
|------|----------|------|------|
| `/for-you` | CSR | 需要 | 主仪表盘：自选股管理 + 生成/查看摘要 |
| `/for-you/[id]` | SSR | 需要 | 按 ID 查看历史摘要详情 |
| `/for-you/archive` | CSR | 需要 | 分页浏览摘要历史 |
| `/for-you/watchlist` | CSR | 需要 | 自选股编辑页面 |

## 数据流

```
/for-you (client component)
  1. AuthContext 检查登录状态，未登录 -> /login?redirect=/for-you
  2. 加载用户数据 (并行):
     -> api.watchlist.get(userId)           // Bearer Token
     -> api.digests.list(userId, 10, 0)     // Bearer Token
  3. 检查今日是否已有 digest:
     -> history[0].digest_date === marketTodayStr()
  4. 用户点击"生成":
     -> api.generateDigest(symbols, userId)  // POST /api/digest
  5. 订阅检查:
     -> api.subscriptions.getStatus('personal_digest', email)
```

## 状态管理

```
symbols: string[]              // 用户自选股列表
watchlistLoadFailed: boolean   // watchlist 加载失败标记 (防止空列表覆盖)
history: UserDigestItem[]      // 摘要历史
displayDigest: DigestResponse  // 当前展示的摘要
generating: boolean            // 是否正在生成
isSubscribed: boolean          // 邮件订阅状态
```

## 调用的 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/watchlist` | Bearer | 获取自选股 |
| `PUT /api/watchlist` | Bearer | 保存自选股 |
| `GET /api/digests` | Bearer | 摘要历史列表 |
| `GET /api/digests/{id}` | Bearer | 特定摘要详情 |
| `POST /api/digest` | - | 生成摘要 (body 传 user_id) |
| `GET /api/subscriptions/personal_digest/status` | - | 检查邮件订阅 |

## 关键组件

- `DigestInlineReport` — 摘要内联渲染 (stocks/news/events/summary)
- `RecentReports` — 历史摘要列表
- `PortfolioSnapshotBar` — 自选股组合快照
- `OnboardingSection` — 新用户引导
- `PaywallGuard` — 付费墙守卫

## 注意事项

- **watchlistLoadFailed 防护**: 如果 watchlist 加载失败，不会用空列表覆盖。这是 2026-02 数据丢失事件的教训。
- 生成 digest 走 `POST /api/digest`（body 传 user_id），读取 watchlist/digests 走 Bearer Token 认证的端点
- `todayDigest` 用 `history[0].digest_date === marketTodayStr()` 判断
- `userDigestToResponse()` 工具函数将 DB 格式转换为前端渲染格式
