# For You - 个性化 Brew 页面

## 功能概述

用户的个性化投资仪表盘。基于用户的投资者画像 (profile) 和持仓 (portfolio) / 关注列表 (watchlist) 生成个性化市场摘要 (digest)。需要登录。是前端最复杂且持续进化的功能模块（当前正在向 P0/P1/P2 专属系统升级）。

## 页面结构

| 页面 | 渲染方式 | 认证 | 描述 |
|------|----------|------|------|
| `/for-you` | CSR | 需要 | 主仪表盘：展示 Action Bar (开发中)、持仓/关注概览、生成/查看摘要。包含 3 种状态（引导、空列表、已生成） |
| `/for-you/[id]` | SSR | 需要 | 按 ID 查看历史摘要详情 |
| `/for-you/archive` | CSR | 需要 | 分页浏览摘要历史 |
| `/for-you/watchlist` | CSR | 需要 | 基础自选股编辑页面（纯 Symbol 列表） |
| `/for-you/portfolio` | CSR | 需要 | 模拟持仓页（Max 会员专属），支持滑块/股数/金额精度录入 |
| `/for-you/onboarding` | CSR | 需要 | 投资画像（风格、期限、风险）引导设置页 |

## 数据流 (U0-A 基础架构)

```
/for-you (client component)
  1. AuthContext 检查登录状态，未登录 -> /login?redirect=/for-you
  2. 加载用户数据 (并行):
     -> api.watchlist.get(userId)               // Bearer Token, 获取纯列表
     -> api.portfolio.get()                     // Bearer Token, 获取带权重的模拟持仓
     -> api.investmentProfile.get()             // Bearer Token, 获取投资画像
     -> api.digests.list(userId, 10, 0)         // Bearer Token, 摘要历史
  3. 状态路由判断 (3 态):
     -> 若没有画像记录 (onboarded_at 为空) 且 没有任何 symbol -> 引导态 (Needs Onboarding)
     -> 若有 symbol 但暂无 digest -> 预览态 (Watchlist Preview)
     -> 若有 digest -> 仪表盘态 (展示 Digest 与 Recent Reports)
  4. 用户点击生成/保存:
     -> 保存画像/持仓会 invalidate TanStack Query 缓存，立即刷新 UI
```

## 状态管理 (TanStack Query)

```typescript
// 核心 Hooks:
useWatchlist()         // ['watchlist', userId]
usePortfolio()         // ['portfolio', userId]
useInvestmentProfile() // ['investment-profile', userId]
useDigestList()        // ['digests', userId]

// 派生状态:
symbols                // 用户自选股列表合集
displayDigest          // 当前首屏展示的摘要 (优先选择有 analysis 的)
isOnboarding           // 是否处于未录入画像且无持仓的状态
```

## 调用的核心 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/watchlist` | Bearer | 获取纯自选股列表 |
| `GET /api/portfolio` | Bearer | 获取持仓明细与推断的 `effective_weight_pct` |
| `PUT /api/portfolio/bulk` | Bearer | 全量更新持仓列表 (限 30 行) |
| `GET /api/profile` | Bearer | 获取投资画像 (缺失时后端会返回兜底默认值) |
| `PUT /api/profile` | Bearer | 全量/部分更新投资画像 |
| `POST /api/digest` | Bearer | 生成摘要 (后端将注入画像 prompt) |

## 关键组件

### 页面本地组件 (`_components/`)

- `ForYouContent` — 主仪表盘内容区，负责 3 态路由分发
- `ForYouContentV1` / `ForYouContentV2` — v1/v2 内容实现，便于 flag 分阶段切换
- `ForYouSkeleton` — 加载骨架屏，确保体验平滑
- `WatchlistPreview` — 自选股/持仓预览条 (无摘要时显示)
- `DigestLockedBlur` / `LockedDigestPreview` — digest locked preview / 付费墙占位

### 共享组件 (`components/for-you/`)

- `ActionBar` — 行动栏
- `ForYouBreadcrumb` — 面包屑
- `DigestInlineReport` — 摘要内联渲染 (stocks/news/events/summary)
- `RecentReports` — 历史摘要列表
- `StockDetailPanel` — 个股详情侧栏
- `StockListItem` — 自选股/持仓列表项
- `StockOverviewPanel` — 个股概览
- `HoldingsSyncDialog` — 持仓导入/同步对话框
- `PaywallGuard` — 付费墙守卫 (`requiredFeature="for_you_website"`)

## 注意事项

- **Watchlist 与 Portfolio 共存**: 当前为过渡期，旧的纯 symbol watchlist 和新的带权重 portfolio 并存，前端按需调用，后续将在 P1/P2 阶段统一合并或强化区别。
- **$CASH 现金头寸**: Portfolio 支持录入特殊的 `$CASH` symbol 代表现金仓位，前端展示为美元符号且不可点击，不请求实时行情。
- **降级处理**: 投资画像/持仓为空时系统自动退化到“等权 + 默认画像(moderate, passive, long)”，绝不会报错阻塞主流程。
- **乐观并发与状态恢复**: Watchlist/Portfolio 保存失败时会恢复到最近一次服务端确认版本，避免假成功导致后续报错。
