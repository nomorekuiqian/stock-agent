# For You - 个性化 Brew 页面

## 功能概述

用户的个性化投资仪表盘。基于用户的投资者画像 (profile) 和持仓 (portfolio) / 关注列表 (watchlist) 生成个性化市场摘要 (digest)。需要登录。是前端最复杂且持续进化的功能模块（当前正在向 P0/P1/P2 专属系统升级）。

## 页面结构

| 页面 | 渲染方式 | 认证 | 描述 |
|------|----------|------|------|
| `/for-you` | CSR | 需要 | 主仪表盘：展示 Action Bar (开发中)、持仓/关注概览、生成/查看摘要。包含 3 种状态（引导、空列表、已生成） |
| `/for-you/monitor` | CSR | 需要 + `for_you_website` | AI Watchlist Monitor beta：读取 cached ticker briefs，采用 full-width 左侧可编辑 watchlist 选择器 + 右侧单 ticker workbench 布局 |
| `/for-you/[id]` | SSR | 需要 | 按 ID 查看历史摘要详情 |
| `/for-you/archive` | CSR | 需要 | 分页浏览摘要历史 |
| `/for-you/health` | CSR | 需要 | 持仓健康度页，展示 Portfolio health 诊断、行动建议与 thesis |
| `/for-you/watchlist` | CSR | 需要 | 基础自选股编辑页面（纯 Symbol 列表） |
| `/for-you/portfolio` | CSR | 需要 | 模拟持仓页（Max 会员专属），支持滑块/股数/金额精度录入 |
| `/for-you/onboarding` | CSR | 需要 | 投资画像（风格、期限、风险）编辑页；新用户主 onboarding 由首页 `/?tour=1` Guided Tour 承接 |

## 数据流 (U0-A 基础架构)

```
/for-you (client component)
  1. AuthContext 检查登录状态，未登录 -> /login?redirect=/for-you
  2. 加载用户数据 (并行):
     -> api.watchlist.get(userId)               // Bearer Token, 获取纯列表
     -> api.portfolio.get()                     // Bearer Token, 获取带权重的模拟持仓
     -> api.investmentProfile.get()             // Bearer Token, 获取投资画像
     -> api.digests.list(userId, 10, 0)         // Bearer Token, 摘要历史
  3. 状态路由判断 (3 态):
     -> 若没有画像记录 (onboarded_at 为空) 且没有任何 symbol -> 引导态，CTA 指向 `/for-you/watchlist`
     -> 若有 symbol 但暂无 digest -> 预览态 (Watchlist Preview)
     -> 若有 digest -> 仪表盘态 (展示 Digest 与 Recent Reports)
  4. 用户点击生成/保存:
     -> 保存画像/持仓会 invalidate TanStack Query 缓存，立即刷新 UI
```

## 状态管理 (TanStack Query)

```typescript
// 核心 Hooks:
useWatchlist()         // ['watchlist', userId]
usePortfolio()         // ['portfolio', userId]
useInvestmentProfile() // ['investment-profile', userId]
useDigestList()        // ['digests', userId]

// 派生状态:
symbols                // 用户自选股列表合集
displayDigest          // 当前首屏展示的摘要 (优先选择有 analysis 的)
isOnboarding           // 是否处于未录入画像且无持仓的状态
```

## 调用的核心 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/watchlist` | Bearer | 获取纯自选股列表 |
| `PUT /api/watchlist` | Bearer | 保存纯自选股列表；Monitor 侧栏内联添加/删除 ticker 复用该接口 |
| `GET /api/watchlist-monitor` | Bearer + `for_you_website` | 获取 cached watchlist monitor，不触发 LLM |
| `GET /api/twitter/ticker-discussion` | Bearer | 获取 selected ticker 过去 24 小时缓存 Twitter/KOL 讨论，不触发外部抓取 |
| `GET /api/portfolio` | Bearer | 获取持仓明细与推断的 `effective_weight_pct` |
| `PUT /api/portfolio/bulk` | Bearer | 全量更新持仓列表 (限 30 行) |
| `GET /api/profile` | Bearer | 获取投资画像 (缺失时后端会返回兜底默认值) |
| `PUT /api/profile` | Bearer | 全量/部分更新投资画像 |
| `POST /api/digest` | Bearer | 生成摘要 (后端将注入画像 prompt) |

## 关键组件

### 页面本地组件 (`_components/`)

- `ForYouContent` — 主仪表盘内容区，负责 3 态路由分发
- `ForYouContentV1` / `ForYouContentV2` — v1/v2 内容实现，便于 flag 分阶段切换
- `ForYouSkeleton` — 加载骨架屏，确保体验平滑
- `WatchlistPreview` — 自选股/持仓预览条 (无摘要时显示)
- `DigestLockedBlur` / `LockedDigestPreview` — digest locked preview / 付费墙占位

### 共享组件 (`components/for-you/`)

- `ActionBar` — 行动栏
- `ForYouBreadcrumb` — 面包屑
- `DigestInlineReport` — 摘要内联渲染 (stocks/news/events/summary)
- `RecentReports` — 历史摘要列表
- `StockDetailPanel` — 个股详情侧栏
- `StockListItem` — 自选股/持仓列表项
- `StockOverviewPanel` — 个股概览
- `HoldingsSyncDialog` — 持仓导入/同步对话框
- `PaywallGuard` — 付费墙守卫 (`requiredFeature="for_you_website"`)

## 注意事项

- **新用户承接**: 新注册用户先走首页 `/?tour=1` Guided Tour；专属日报的自选股设置在 `/for-you/watchlist`，投资画像设置在 `/for-you/onboarding`。
- **Monitor beta**: `/for-you/monitor` 是 ticker-first 工作台 beta，和专属日报共用 `for_you_website` entitlement；前端外层使用 `PaywallGuard requiredFeature="for_you_website"`，后端 `GET /api/watchlist-monitor` 也会做同一权限校验。它调用 `api.getWatchlistMonitor()` 读取后端已生成的 `ticker_daily_briefs`；页面刷新不会触发 per-user LLM。页面是 full-width workbench：左侧展示当前 watchlist ticker 列表，并直接支持搜索添加 ticker、删除 ticker 和本地搜索过滤；侧栏不再展示“今日概览”汇总块。增删复用 `useWatchlist()` / `useSaveWatchlist()` 的 optimistic update，保存成功后 invalidate monitor cache；新加入但尚无 brief 的 ticker 会显示 pending 占位；已有旧日期 brief 的 ticker 会显示“显示上次监控”并保留旧 brief 内容。左侧保存状态有轻量 inline feedback（保存中、已加入、已移除、已定位、错误），页面入场、tab 切换和列表选择使用 `monitor-*` CSS-only motion，全部通过 transform/opacity 并由全局 `prefers-reduced-motion` 兜底。右侧顶部只展示 selected ticker summary 和“今日盯盘结论”；结论卡左侧通过 `useStockQuotes([symbol])` 展示当前价与今日涨跌幅，当前价失败时回退到 `technical_monitor.key_levels.current_price`，右侧展示 `ai_take`。详情用 3 个 Tab 组织：`新闻事件`（新闻总结、新闻来源、未来事件、财报）、`技术面`（先展示完整 K 线/RSI/MACD/成交量图表，复用个股页 `TechnicalChart` 并通过 `useTechnicalData(symbol, "daily")` 获取完整数据；图表下方展示当前价、支撑/阻力和 MA20/50/200；旧缓存没有 `technical_monitor.key_levels` 时会用实时 technical-data endpoint 兜底；随后展示一段较完整的技术面判断和趋势/动能/位置/波动四个模块）、`市场讨论`（仅在用户打开该 tab 时通过 `useTwitterTickerDiscussion(symbol, activeTab === "market_discussion")` 读取过去 24 小时缓存 Twitter/KOL 讨论，避免选中 ticker 时立即触发重摘要；顶部用 `overview`、`themes` 和代表观点派生多段中文讨论摘要，覆盖样本量、多空结构、主要主题和代表观点；下方按 `themes` 渲染话题卡，每张卡展示 Title、较详尽 Summary、代表观点和 evidence 推文原文链接；没有主题时用单条推文生成同结构兜底卡；最底部保留完整 Twitter 讨论原文列表作为 verification，不再混入 monitor brief 内的社交 signal；较长原文默认折叠，用户点击“展开原文”后才显示完整正文）。新闻板块展示 `news_summary` 和最多 15 条新闻来源；后端会保留原英文标题和 URL，同时在 `source_refs.title_zh` 写入 LLM 翻译标题，前端优先显示中文标题并链接到原文，且从 URL 提取 MarketBeat、StocksToTrade、FXEmpire 等站点名作为来源标签，用户点击前能知道会跳转到哪个网站。未来事件板块优先渲染 `event_candidates`：有明确日期的 future events 排在前面，unknown-date 的 tentative watch items 排在后面，旧 `watchpoints` 只作为兼容 fallback；展示前会对 `event_candidates`、event/macro signals 和 `watchpoints` 做跨来源 dedupe，FOMC 这类同一宏观事件以 candidate 为准只展示一次。页面保留跳转 `/stock/[symbol]` 的入口。
- **Watchlist 与 Portfolio 共存**: 当前为过渡期，旧的纯 symbol watchlist 和新的带权重 portfolio 并存，前端按需调用，后续将在 P1/P2 阶段统一合并或强化区别。
- **$CASH 现金头寸**: Portfolio 支持录入特殊的 `$CASH` symbol 代表现金仓位，前端展示为美元符号且不可点击，不请求实时行情。
- **降级处理**: 投资画像/持仓为空时系统自动退化到“等权 + 默认画像(moderate, passive, long)”，绝不会报错阻塞主流程。
- **乐观并发与状态恢复**: Watchlist/Portfolio 保存失败时会恢复到最近一次服务端确认版本，避免假成功导致后续报错。
