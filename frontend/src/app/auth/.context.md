# Auth Callback - OAuth 回调路由

## 页面概述

`/auth/callback` 是 Google OAuth / Insforge OAuth code exchange 的 server route。它读取 OAuth code 和 PKCE verifier，调用 Insforge server SDK 换取 session，并写入本域 auth cookies。

## 文件结构

| 文件 | 职责 |
|------|------|
| `callback/route.ts` | OAuth code exchange、cookie 写入、onboarding probe、最终 redirect |

## 数据流

```text
Google / Insforge callback
  -> /auth/callback?insforge_code=...
  -> getAndClearOAuthCodeVerifier()
  -> createServerClient().auth.exchangeOAuthCode()
  -> setAuthCookies(accessToken, refreshToken)
  -> GET /user/onboarding-status (non-blocking)
  -> redirect to /?tour=1 for first-time users, otherwise safe redirect
```

## 注意事项

- `redirect` 只能接受站内路径，外站或 `//` 必须回退到 `/today`。
- onboarding probe 失败不能阻断登录完成。
- `completed:false` 代表首次用户，落点必须是首页 `/?tour=1` 的 Guided Tour，不再是独立 `/onboarding`。
- 不要把 OAuth callback 改回浏览器端 SDK 流程；当前 auth 可靠性依赖 server-cookie bridge。

## 可恢复功能暂停（2026-09-04）

OAuth callback 不再请求已暂停的 onboarding-status；回跳通过 sanitizeRedirectPath，暂停目标重定向至可用页面。
