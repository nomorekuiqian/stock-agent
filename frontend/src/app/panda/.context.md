# Panda Agent Page

## 功能概述

`/panda` 是潘大私域社群成员专属 Agent 页面。页面锁定
`persona_username=pandacircle`，不展示主站导航、定价 CTA 或主站其它功能入口。
通过访问校验后，它直接复用 `/research` 的完整 `ResearchWorkspace`
工作台，而不是维护一套独立轻量聊天 UI。

用户可见名称使用 `潘大科技圈专属投研助手`。登录/注册 gate、未授权提示等
面向社群成员的文案不要直接称为 `Panda Agent`。
gate 标题区使用 `/kol-avatars/pandacircle.png` 作为潘大头像。

## 访问控制

页面必须登录。未登录用户留在 `/panda`，看到 Panda 专属登录/注册引导，不再只依赖
自动跳转；按钮复用现有 `/login` 页，并带 `redirect=/panda`。后端以
`community_access_grants` 的 active email grant 为准：

```text
not logged in
  -> /panda login/register gate
  -> /login?redirect=/panda or /login?mode=signup&redirect=/panda
  -> back to /panda after auth
user.email normalized
  -> GET /api/community/panda/me
  -> active grant 才能显示 Agent
```

未授权的已登录用户只显示当前登录 email 和切换账号入口，不提供公开访问码。
如果 `/api/community/panda/me` 网络失败或后端不可达，页面显示“暂时无法验证访问权限”
和重试按钮；不要把这类系统错误渲染成“当前账号未开通”。
`/panda` 不使用主站 Navbar tabs，但会渲染一个 Panda 专属顶部栏。已授权进入
Agent 后，顶部栏展示潘大科技圈品牌、当前账号名/email，并提供“退出登录”。退出成功后
停留在 `/panda`，显示“重新登录”入口，不展示注册按钮或主站导航 tabs。

## API 依赖

| 方法 | 端点 | 说明 |
|------|------|------|
| `api.communityPanda.me()` | `GET /api/community/panda/me` | 读取当前用户 Panda access |
| `api.communityPanda.chatStream()` | `POST /api/community/panda/chat/stream` | Panda 专属 SSE chat |
| `api.communityPanda.conversations.*` | `/api/community/panda/conversations*` | Panda 对话保存、搜索、置顶 |

## 前端结构

- `page.tsx` — Panda 专属顶部栏 + 未登录登录/注册 gate + Panda email grant gate；通过后渲染
  `ResearchWorkspace variant="community_panda"`，工作区从顶部栏下方开始
- `ResearchWorkspace` 复用主 Agent 的分屏、历史侧栏、搜索、保存、KOL evidence
  panel、canvas/content stack 和移动端 tab 逻辑
- Panda 变体使用独立 `storageKey` / `conversationScope`，避免和普通 `/research`
  的 sessionStorage、React Query key、localStorage 历史缓存串数据
- `lockedPersonaUsername="pandacircle"` 且 `allowDefaultAssistant={false}`，所以用户不能切到默认 Research Agent 或其它 persona
- 退出登录后由 `/panda` 本页展示重新登录 gate；不要依赖全站 middleware 跳转，否则用户会失去
  Panda 专属上下文。

## 注意事项

- 不要把 `/panda` 改回通用 `/research` deep link；普通 research endpoint 会拒绝
  `pandacircle`，且会绕过 Panda email grant gate。
- `ChatPanel` 在该页面必须传 `showPersonaUpsell={false}`，避免出现 Max 升级文案。
- Panda 对话读写和置顶必须走 `api.communityPanda.conversations.*`，不能走
  `api.research.conversations.*` 或 `api.kolResearch.conversations.*`。
