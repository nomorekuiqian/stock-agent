# Morning - 盘前早报页面

## 功能概述

展示 AI 生成的盘前市场简报。主页显示当天早报（或最新），子页面支持按 ID 查看历史和归档浏览。

## 页面结构

| 页面 | 渲染方式 | 描述 |
|------|----------|------|
| `/morning` | SSR, fetch revalidate 5min | 当日早报，服务端获取数据 |
| `/morning/[id]` | 按用户动态 SSR | 按 ID 查看历史早报，含 SEO 元数据 |
| `/morning/archive` | CSR | 分页浏览历史早报列表 |

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | 当日/最新早报 server page |
| `layout.tsx` | Morning route layout |
| `loading.tsx` | Morning loading skeleton |
| `[id]/page.tsx` | 早报详情 + metadata |
| `archive/page.tsx` | 早报归档分页 |
| `_components/MorningReportBody.tsx` | client-side entitlement/locked body wrapper |
| `_components/LockedBlur.tsx` | locked AI 文本占位 |
| `_components/MorningActions.tsx` | 订阅/发送/生成操作 |

## 数据流

```
/morning (server component)
  -> api.morningReports.getByDate(today)  // 先查当天
  -> api.morningReports.getLatest()       // 没有则取最新
  -> api.morningReports.list(6, 0)        // 同时获取历史列表
  -> MorningReportContent 组件渲染

/morning/[id] (server component)
  -> api.morningReports.getById(id)
  -> generateMetadata() 生成 SEO
  -> MorningReportContent 组件渲染

/morning/archive (client component)
  -> api.morningReports.list(pageSize, offset)
  -> 分页状态管理
```

## 调用的 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/morning/reports/date/{date}` | - | 按日期获取早报 |
| `GET /api/morning/reports/latest` | - | 获取最新早报 |
| `GET /api/morning/reports/{id}` | - | 按 ID 获取早报 |
| `GET /api/morning/reports` | - | 列表 (分页) |
| `POST /api/morning` | Bearer | 生成新早报 (MorningActions 触发) |

## 关键组件

- `ReportHeroBanner` -- 早报主视觉 Banner，使用 `/report-banners/morning-brief-banner.png`
- `MorningReportContent` -- 早报内容渲染 (期货、全球市场、隔夜新闻、今日焦点、总结)。支持 `locked` prop：locked 模式下保留期货卡片和全球市场表格的真实行情，AI 文本（futures_analysis、global_markets_analysis、隔夜要闻、今日焦点、总结）一律替换为 `LockedBlur` 占位
- `MorningReportBody` -- client wrapper，根据 `useAuth` + `useEntitlements('morning_website')` 判定 `locked`，渲染 `UpgradeBanner` 与 locked 版面，避免再用全屏挡板覆盖整页
- `LockedBlur` / `UpgradeBanner` -- amber 主题的模糊占位条 + 顶部升级条幅，模式参考 `twitter-digest/_components/LockedBlur`
- `MorningActions` -- 客户端操作栏 (订阅/发送邮件/生成报告)
- `ReportTabs` -- 早报/晚报切换标签 (共享组件)

## 注意事项

- 主页是 server component，使用 `force-dynamic` 避免生产构建依赖后端即时可用性；服务端 fetch 设置 10s 超时，并保留 5 分钟 revalidate hints
- 主题色为 amber (区别于晚报的 emerald)
- 订阅频道统一使用 `daily_report`，早报和晚报共享同一订阅列表
- 付费墙策略：早报和归档页对未订阅用户开放结构 + 行情快照，AI 文本通过 `MorningReportBody` + `LockedBlur` 在 client 侧 gate；归档列表沿用推特日报开放浏览 + 顶部条幅的模式，已移除原 `PaywallGuard requiredFeature="morning_website"` 全屏挡板
- archive 页面的分页在前端维护 page 状态

SEO：归档页有独立 canonical；公开早报详情进入 sitemap，未授权请求仍只获得公开字段。详情 JSON-LD 使用 www 正式域名并转义 HTML 特殊字符。

## SEO 链路修复（2026-10-17）

- `lib/report-url.ts` 统一标题和日期地址；`/morning/[id]` 同时接收 UUID 与日期 slug，按日期调用已有 API。UUID 在 middleware 查询公开报告日期后返回 HTTP 308，避免流式页面把跳转降级为 HTTP 200。源服务失败返回 503，不生成错误永久跳转。
- 页面 canonical、Article URL、归档链接和 sitemap 使用相同地址。标题明确全市场/盘前范围及报告日期，不臆造板块分类。
- 顶部 `MarketSummary` 输出行情快照、报告日期和三个要点；早报仅从公开数值生成要点，不使用付费分析。缺失字段明确标注，不将缺失涨跌转换为 0。早报现有数据源未提供美债收益率。
- `StockLinkedText` 将已知股票代码转为内链；AI 等歧义词要求美元符号或括号。
