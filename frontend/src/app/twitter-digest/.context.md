# Twitter Digest - 推特 KOL 观点日报页面

## 页面概述

`/twitter-digest` 展示每日金融 KOL 观点摘要。页面可公开浏览 teaser；完整内容、归档全文和邮件偏好需要 Max entitlement `twitter_digest`。

## 路由

| 路由 | 页面 | 数据来源 | 认证 |
|------|------|----------|------|
| `/twitter-digest` | 最新一期 | `api.twitterDigest.getLatest()` / entitlement gated response | 公开浏览，全文需 Max |
| `/twitter-digest/[date]` | 指定日期详情 | `api.twitterDigest.getByDate(date)` | 公开浏览，全文需 Max |
| `/twitter-digest/archive` | 归档列表 | `api.twitterDigest.listArchive(limit, offset)` | 公开浏览，全文需 Max |

## 权益逻辑

- `useAuth()` + `useEntitlements().has("twitter_digest")` 决定是否展示完整态。
- 匿名 / 非 Max 用户仍可加载 teaser，由后端响应控制可见字段。
- `TwitterDigestActions` 订阅邮件偏好时匿名用户跳 `/login?redirect=/twitter-digest`。

## 注意事项

- 日期使用后端返回的业务日期字段；历史无 `date` 的行才回退到 `generated_at.slice(0, 10)`。
- archive 日期显示用 UTC anchor，避免用户本地时区导致星期错位。
- locked preview 必须继续可索引/可分享，但不要泄露 Max-only 正文。
