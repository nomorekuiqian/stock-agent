# KOL Persona Pages

## 功能概述

KOL 专属投研驾驶舱页面，路由 `/kol/[username]`。首个 persona 是 qinbafrank，把已蒸馏的方法论 + 真实推文历史包装成可浏览、可下钻的前端入口。

不是普通博主页，也不声称代表博主本人；它是 TheMarketBrew 基于公开推文蒸馏 + 聚合的研究界面。

## 路由结构

| 路径                      | 页面                   | 用途                                                                                  |
| ------------------------- | ---------------------- | ------------------------------------------------------------------------------------- |
| `/kol/[username]`         | Overview（首页）       | qinbafrank 5 板块总览 + 他的精华 / 个股验证 / 原文证据；其他 persona 保持 2x2 mini 模块网格 |
| `/kol/[username]/latest`  | Content Library / Latest | qinbafrank 全量内容库：过往精华 + 全量 Live Feed；其他 persona 保持全量原文流        |
| `/kol/[username]/sectors` | Sector Opinions / Sectors | qinbafrank 板块观点：5 个大板块的深度框架与观点时间线，AI 产业额外提供子板块拆解；其他 persona 保持 Sector Atlas |
| `/kol/[username]/highlights` | qinbafrank Highlights  | qinbafrank 旧过往精华阅读器：7 个主题板块 + 子话题组 + 原文 reader；其他 persona 兼容 Sector Atlas |
| `/kol/[username]/macro`   | Macro Content / Macro  | qinbafrank 宏观内容：流动性 / 财政扩张 / 贸易战与地缘；其他 persona 保持宏观主题浏览 |
| `/kol/[username]/history` | Redirect               | qinbafrank 旧美股规律入口，重定向到 `/highlights?topic=market-rules`                |
| `/kol/[username]/stocks`  | Company Recommendations | qinbafrank 个股：推荐档案 + 价格验证 + 原文时间线；其他 persona 保持标的列表          |
| `/kol/[username]/chat`    | Chat                   | 手动追问启动页；页面内 CTA / chips 跳 `/research` 执行真实对话                        |

整体 chrome 在 `layout.tsx`：`PersonaHero`（顶部）+ `SubNav`（PC 60px 侧边栏 / 移动端横向 strip）。

## 首页（page.tsx）结构

```
[Hero]                                    ← layout 渲染
[qinbafrank 首页]
[标题与价值定位]                          ← qinbafrank研究室；用他的框架理解产业、个股和市场风险
[右侧统计]                                ← 板块观点 / 个股档 / 入库推文
[主行动]                                  ← 问 Frank 问题（Max）
[5 个板块总览]                            ← AI / 加密 RWA / 美股调整与行情 / 宏观地缘 / 过往推荐公司
[三强入口]
  ① 他的精华  │  ② 个股验证  │  ③ 原文证据

[其他 persona 首页]
[博主研究室一句话定位]
[Chat 按钮]
[2x2 模块网格]
  ① 最新观点    │  ② 宏观视角
  ③ 板块视角    │  ④ 个股视角
```

## 关键设计决策

- **粉丝优先 + 驾驶舱质感**：首页 dashboard 用 2x2 mini grid（每卡有 mini 数据：价格涨跌 / mention 次数）；追问入口收敛为单个 Chat 按钮，避免首页出现重复输入框。
- **追问入口保持轻量**：首页按钮和 `SubNav` 里的 Chat 入口只跳 `/research?agent=kol&persona=X`，不带 `q` 或 `symbol`，让研究工具首页负责承接真实输入；`/chat` 子页仍可用重点 CTA 区解释方法论 / 数据 / 原文三类上下文。
- **ChatComposer 不接 SSE**：如果页面内使用 ChatComposer，只收集输入并跳到 `/research` 触发真实对话（research 页 useEffect 监听 `q=` 自动 handleSend）。首页已简化为单个 Chat 按钮，不再内嵌输入框。
- **带问题深链只用于明确上下文**：板块 / 宏观主题等具体追问入口可使用 `buildKolAgentHref()` 生成 `/research?agent=kol&persona=X&q=...`，保留对应上下文；首页主 CTA 和 `SubNav` Chat 入口只进入研究工具首页，不自动发送问题。个股详情页不放顶部追问按钮。
- **ticker 抽取靠中文名字典**：qinbafrank 不用 `$cashtag`、按中文名写公司，后端 `cockpit.TICKER_ALIASES` 维护 `{ticker: [中文名,英文别名]}` (~24 个核心标的) 匹配原文。不依赖 enrichment。
- **多空上色 MVP 不做**：提及点单色；stance 留后续。
- **写死 username 形参，前端不抽 persona 路由**：后端端点保留 `{username}`。
- **qinbafrank 主入口改为 5 板块总览**：`/kol/qinbafrank` 首屏直接对应新版 `/sectors` 的 5 个板块，让用户先按产业/市场主题进入观点体系，而不是先看功能入口拼图。
- **板块观点成为新的 sectors 主入口**：`/kol/qinbafrank/sectors` 渲染 `FrankSectorOpinions`，把原精华内容归并为 5 个大板块；所有板块按「核心判断 / 分析维度切换 / 可展开原观点逻辑 / 倒序观点时间线」呈现，AI 产业进一步拆成 8 个子板块。
- **旧过往精华阅读器移到 highlights**：`/kol/qinbafrank/highlights` 渲染 `FrankHighlights`，完整保留 7 个主题 tab、左侧检索卡片和右侧导读 + 原文 reader。
- **旧精华阅读器中 AI 大趋势与资本开支战争分开**：`/highlights` 仍让 AI 大趋势独立承载渗透率、产业进化和竞争格局；资本开支战争独立承载 capex、算力瓶颈、存储、光、CPU、800V HVDC、电力和边缘/端侧 AI。新版 `/sectors` 会把二者归并到「AI 产业」。
- **美股规律并入过往精华**：`/kol/qinbafrank/history` 只保留为旧链接 redirect，跳到 `/highlights?topic=market-rules`。导航里不再出现独立“美股规律” section。
- **公司推荐结合 stocks 页面**：`/kol/qinbafrank/stocks` 保留价格、提及时间线和 ticker 搜索，同时新增推荐档案，避免另起一个孤立公司页。
- **全量内容库结合 latest 页面**：`/kol/qinbafrank/latest` 从单纯时间流升级为“过往精华 + 全量原文”，避免同时维护 library 和 latest 两套入口。
- **qinbafrank 宏观页保留兼容**：`/kol/qinbafrank/macro` 仍可承载宏观传导地图，但宏观与地缘的主动反馈内容同时进入过往精华主题。非 qinbafrank persona 仍走旧 `MacroPerspectivePanel`。
- **缺失推文不占位**：`researchMapData.ts` 只放当前已命中的 tweet id；qinbafrank 反馈里暂未入库的早期推文后续补齐后再接入，不显示“缺失卡”。
- **板块页改为 Atlas 而不是左侧列表（non-frank / legacy）**：非 qinbafrank `/sectors` 仍列出产品顶层板块。当前语料中的 HBM / 电力 / Fintech 文件作为子主题并入顶层板块，不单独成为入口。
- **板块页避免文章化阅读（non-frank / legacy）**：旧 `SectorExplorer` 首屏用 icon / badge / attention bar 区分 4 条主线；正文按「他的观点 → 过往评论 → 打脸条件 → 下钻产业链」组织。用户界面不暴露内部语料版本词。
- **宏观内容独立入口**：旧宏观页从 `/sectors` 抽出到 `/macro`。qinbafrank 的 `/macro` 暴露为「宏观内容」，承接流动性、财政扩张、贸易战和地缘政治；非 qinbafrank 仍使用旧宏观主题框架。
- **宏观框架页只保留主题下钻（non-frank / legacy）**：旧宏观页首屏引导用户在 4 个宏观主题间切换；每个主题只回答「看什么数据」「怎么判断」「有哪些历史原文」三件事。
- **移动端 Atlas 优先（non-frank / legacy）**：`SectorExplorer` 在移动端先显示板块地图，再逐个展示 narrative panel；展开态只保留一个板块，避免长文堆叠。qinbafrank 过往精华移动端以主题 tab、检索卡片和阅读器纵向展开，点选卡片后滚动到 reader。
- **移动端个股页先露出详情**：`StockExplorer` 在移动端把 ticker rail 限高为可滚动面板，避免 80+ 标的列表把个股详情推到页面深处。
- **SubNav Chat 入口要和内容项区分**：`SubNav` 的 Chat/追问入口使用实心 `primary`（emerald）按钮样式，PC 侧边栏表现为绿色实心图标按钮，移动端横向导航表现为绿色实心入口。

## 注意事项

- qinbafrank 主页 `/kol/qinbafrank` 浏览公开；所有 qinbafrank 子页（`/sectors` / `/highlights` / `/stocks` / `/latest` / `/macro` / `/history` / `/chat`）由 `LoginGate` 包裹，**必须登录后才能查看**（注册免费，无付费墙）。守卫逻辑在 `layout.tsx` 里按 `pathname` 判断；其他博主页面不受影响。**注意**：`frontend/middleware.ts` 的 `PUBLIC_ROUTES` 必须包含 `/kol`，否则 Next.js middleware 会在 SSR 阶段把未登录用户整段重定向到 `/login`，根本到不了客户端 `LoginGate`（生产踩过的坑）。
- `/research` 使用 KOL agent 不再需要 `kol_research_agent` flag — 已 fully rolled out（前端 `kolPersonaEnabled` hardcode 为 true；后端 `require_kol_research_flag` 不再检查 flag，只校验登录 token）。flag 定义和回滚口子保留，详见 `backend/app/features/kol_research/.context.md`。
- 方法论内容标「已蒸馏,非本人发言」；个股摘录均为原文逐字 + 原文链接。
- 不把回答写成「qinbafrank 本人认为」；命中原推才说「原文支持」。
- 后端聚合见 `backend/app/features/kol_research/cockpit.py` + `.context.md`。
- 字号 / 字体严格遵守 `docs/constraints/design-system.md`。
