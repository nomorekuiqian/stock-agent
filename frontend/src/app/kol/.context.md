# KOL Persona Pages

## 功能概述

KOL 专属投研驾驶舱页面。首个页面是 `/kol/qinbafrank`,把已蒸馏的 qinbafrank 方法论 + 真实推文历史包装成可浏览、可下钻的前端入口。

不是普通博主页,也不声称代表博主本人;它是 TheMarketBrew 基于公开推文蒸馏 + 聚合的研究界面。

## 页面结构(四层)

| 层 | 内容 | 数据来源 |
|----|------|----------|
| ① 方法论内核 | 一句话画像 / 5 条核心原则 / 可证伪指纹 / 明确不做 + 大 CTA | `GET /personas/{u}/profile`(后端 `cockpit.PROFILE_CORE`,源自 `overview.md`) |
| ② 板块卡片 | AI 算力链细分 5 子卡(算力底座/HBM·存储/数据中心·Newcloud/电力·物理基建/应用·Agent)+ 加密 + 宏观;点开看「他怎么看 / 分析路径 / 会盯哪些数据 / 代表观点(真实原文)」 | `/profile`(卡片正面)+ `GET /personas/{u}/sectors/{key}`(详情) |
| ③ 个股历史观点 | 左 ticker 列表(频次排序+搜索)+ 右详情:价格×提及时间线(recharts)+ 基本面行 + 原文摘录(最新/高赞) | `GET /personas/{u}/tickers` + `GET /personas/{u}/tickers/{ticker}` |
| ④ 对话 Agent CTA | 大按钮跳 `/research?agent=kol&persona=qinbafrank`;板块/个股详情各有上下文化追问入口 | `AskFrankButton`(无需后端) |

## 组件(`qinbafrank/_components/`)

- `QinbaFrankPage.tsx` — 编排:挂载时拉 `cockpitProfile` + `cockpitTickers`,组合三层 + 透明度 footer
- `MethodologyCore.tsx` — ① 方法论内核
- `AskFrankButton.tsx` — ④ CTA(`buildResearchHref` 构造深链;未登录跳 login)
- `SectorExplorer.tsx` — ② 板块卡片 + 详情面板(lens body 用 ReactMarkdown 展开)
- `TickerExplorer.tsx` — ③ 个股列表 + 详情
- `MentionTimelineChart.tsx` — recharts ComposedChart:价格线 + 提及散点(点大小=赞数,**MVP 不按多空上色**)
- `TweetCard.tsx` — 逐字推文卡(日期/♥赞/原文链接),③② 复用

## 关键设计决策

- **ticker 抽取靠中文名字典**:qinbafrank 不用 `$cashtag`、按中文名写公司(美光/英伟达),所以后端 `cockpit.TICKER_ALIASES` 维护 `{ticker: [中文名,英文别名]}`(~24 个核心标的)匹配原文。**不依赖 enrichment / 不回填**。覆盖字典内标的(MVP 可接受)。
- **多空上色 MVP 不做**:提及点单色;stance 留作后续(届时按需 enrich 详情页展示的少数推文)。
- **写死 qinbafrank**:前端不做多 persona 路由抽象;后端端点保留 `{username}` 形参。
- 价格/基本面来自 FMP(`shared/fmp_service.py`),失败优雅降级(只显示提及时间线)。

## 数据流

```
/kol/qinbafrank (公开,无需登录)
  -> api.kolResearch.cockpitProfile('qinbafrank')   // ① 内核 + ② 卡片正面
  -> api.kolResearch.cockpitTickers('qinbafrank')   // ③ 列表 + 当前价
  -> (点击板块) cockpitSector(u, key)               // ② 详情 + 代表原文
  -> (点击个股) cockpitTickerDetail(u, ticker)      // ③ 价格线 + 原文摘录
  -> (CTA) /research?agent=kol&persona=qinbafrank   // ④ 对话(需登录 + flag)
```

## 注意事项

- 浏览公开;只有 ④ 对话需登录 + `kol_research_agent` flag。
- 方法论内容标「已蒸馏,非本人发言」;个股摘录均为原文逐字 + 原文链接。
- 不把回答写成「Frank 本人认为」;命中原推才说「原文支持」。
- 全页 **非投资建议** banner(footer)。
- 后端聚合见 `backend/app/features/kol_research/cockpit.py` + `.context.md`;工程 plan 见 `docs/plans/active/kol-persona-cockpit.md`。
