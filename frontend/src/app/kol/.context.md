# KOL Persona Pages

## 功能概述

KOL 专属投研驾驶舱页面，路由 `/kol/[username]`。首个 persona 是 qinbafrank，把已蒸馏的方法论 + 真实推文历史包装成可浏览、可下钻的前端入口。

不是普通博主页，也不声称代表博主本人；它是 TheMarketBrew 基于公开推文蒸馏 + 聚合的研究界面。

## 路由结构

| 路径 | 页面 | 用途 |
|------|------|------|
| `/kol/[username]` | Overview（首页） | ChatComposer 前置 + 2x2 mini 模块网格 |
| `/kol/[username]/latest` | Latest | 全量 Live Feed（含分页 / 过滤） |
| `/kol/[username]/sectors` | Sectors | 板块分层 + 产业链 / 详情；只展示真正板块 |
| `/kol/[username]/macro` | Macro View（宏观视角） | Frank 宏观框架 + 6 个关键指标 + 折叠证据 |
| `/kol/[username]/stocks` | Stocks | 标的列表 + 个股观点详情 |
| `/kol/[username]/chat` | Chat | 跳 /research 的中转 |

整体 chrome 在 `layout.tsx`：`PersonaHero`（顶部）+ `SubNav`（PC 60px 侧边栏 / 移动端横向 strip）+ `TransparencyFooter`。

## 首页（page.tsx）结构

```
[Hero]                                    ← layout 渲染
[Frank Lens 一句话定位]                    ← 公开观点 → 可查询/可验证/可持续跟踪
[ChatComposer]                            ← 用户日常打开就能输入,前置
[2x2 模块网格]                            ← dashboard 质感:4 个均匀 mini 卡
  ① 最新观点    │  ② 板块机会
  ③ 个股观点    │  ④ 追问视角
[TransparencyFooter]                      ← layout 渲染
```

| 模块 | 内容 | 数据来源 |
|----|------|----------|
| Frank Lens 定位 | `把 qinbafrank 的公开观点整理成可查询、可验证、可持续跟踪的股票研究框架。` | 静态产品定位文案 |
| ChatComposer | 受控 textarea + emerald 圆形发送 + 3 个动态 suggestion chip。Enter / 点击 → `/research?agent=kol&persona=X&q=...` | suggestions 用 `core.principles[0].title` + `sectors[0].label` 动态拼，兜底通用问题 |
| ① 最新观点 | 3 条 mini 推文（时间 + tickers + 2 行截断文本） | `cockpitFeed(limit:3)` |
| ② 板块机会 | 3 个板块（eyebrow + label + stance + mention 次数） | `cockpitProfile.sectors` |
| ③ 个股观点 | 6 只标的 2 列网格（ticker + 提及次数 + **价格 + 涨跌幅**） | `cockpitTickers` |
| ④ 追问视角 | 3 个 starter 问题（与 ChatComposer suggestions 共享） | `buildSuggestions(profile)` |

> ChatComposer 与 Module ④ 的 starter 列表**共享 `buildSuggestions(profile)`** 计算结果，保持一致。前者是"立即输入"，后者是"卡片化的引导入口"。

> 不保留：「这个驾驶舱是什么·怎么用」教程卡 —— 老用户冗余,新用户应被价值打动而非教程。

## 数据流

```
/kol/[username]                       (公开,无需登录)
  layout: cockpitProfile + cockpitTickers + cockpitFeed(limit:1)
  page:   cockpitProfile + cockpitTickers + cockpitFeed(limit:3)
  CTA:    /research?agent=kol&persona=X[&q=...]    (需登录 + flag, q 自动发送)

/kol/[username]/sectors
  SectorExplorerV3: cockpitSectorsV3 + selected key
  SectorListV3: 只渲染 layer=sector
  SectorDetailV3 / IndustryChainView: cockpitSectorV3 / cockpitIndustryChain

/kol/[username]/macro
  MacroPerspectivePanel: cockpitSectorV3(username, "macro-regime")
  MacroRegimeFramework: 复用 Macro hooks 读取当前指标
    - liquidity metrics / global liquidity
    - macro-risk economy / inflation-rates / sentiment
    - treasury-commodities
  Legacy: /sectors?key=macro-regime 客户端 replace 到 /macro，同时直接渲染 MacroPerspectivePanel 避免空白
```

## 关键设计决策

- **粉丝优先 + 驾驶舱质感**：首页 dashboard 用 2x2 mini grid（每卡有 mini 数据：价格涨跌 / mention 次数）；ChatComposer 前置作为核心动作入口。
- **ChatComposer 不接 SSE**：本页只收集输入，跳到 `/research` 触发真实对话（research 页 useEffect 监听 `q=` 自动 handleSend）。本页保持简单、无状态机。
- **ticker 抽取靠中文名字典**：qinbafrank 不用 `$cashtag`、按中文名写公司，后端 `cockpit.TICKER_ALIASES` 维护 `{ticker: [中文名,英文别名]}` (~24 个核心标的) 匹配原文。不依赖 enrichment。
- **多空上色 MVP 不做**：提及点单色；stance 留后续。
- **写死 username 形参，前端不抽 persona 路由**：后端端点保留 `{username}`。
- **宏观视角独立 panel**：宏观不是传统板块，已从 `/sectors` 左侧列表抽出到 `/macro`。SubNav 增加「宏观视角」，旧 `/sectors?key=macro-regime` 保持兼容跳转。
- **宏观框架页不是 Macro 仪表盘复制**：首屏只回答「当前框架读数、判断路径、最关键 6 个信号」。完整 Evidence Map / Guardrails / 原推 / 完整框架原文默认折叠，避免把方法论全文压到首屏。
- **移动端详情优先**：`SectorExplorerV3` 在移动端先渲染 selected detail，再渲染板块列表；桌面仍保持左侧列表 + 右侧详情。宏观深链由独立 panel 承接。

## 注意事项

- 浏览公开；只有 ChatComposer 跳 `/research` 时才需登录 + `kol_research_agent` flag。
- 方法论内容标「已蒸馏,非本人发言」；个股摘录均为原文逐字 + 原文链接。
- 不把回答写成「Frank 本人认为」；命中原推才说「原文支持」。
- 全页 **非投资建议** banner（footer）。
- 后端聚合见 `backend/app/features/kol_research/cockpit.py` + `.context.md`。
- 字号 / 字体严格遵守 `docs/constraints/design-system.md`。
