# KOL Persona Pages

## 功能概述

KOL 专属投研驾驶舱页面，路由 `/kol/[username]`。首个 persona 是 qinbafrank，把已蒸馏的方法论 + 真实推文历史包装成可浏览、可下钻的前端入口。

不是普通博主页，也不声称代表博主本人；它是 TheMarketBrew 基于公开推文蒸馏 + 聚合的研究界面。

## 路由结构

| 路径                      | 页面                   | 用途                                                                                  |
| ------------------------- | ---------------------- | ------------------------------------------------------------------------------------- |
| `/kol/[username]`         | Overview（首页）       | 追问核心入口前置 + 2x2 mini 模块网格                                                  |
| `/kol/[username]/latest`  | Latest                 | 全量 Live Feed（含分页 / 过滤）                                                       |
| `/kol/[username]/sectors` | Sectors                | qinbafrank Sector Atlas：4 个顶层板块地图 + 每个板块的过往观点 / 原文 comments / 总结 |
| `/kol/[username]/macro`   | Macro View（宏观视角） | qinbafrank 宏观主题浏览：数据 / 判断 / 历史原文检索                                   |
| `/kol/[username]/stocks`  | Stocks                 | 标的列表 + 个股视角详情                                                               |
| `/kol/[username]/chat`    | Chat                   | 手动追问启动页；页面内 CTA / chips 跳 `/research` 执行真实对话                        |

整体 chrome 在 `layout.tsx`：`PersonaHero`（顶部）+ `SubNav`（PC 60px 侧边栏 / 移动端横向 strip）+ `TransparencyFooter`。

## 首页（page.tsx）结构

```
[Hero]                                    ← layout 渲染
[博主研究室一句话定位]                    ← 公开观点 → 可查询/可验证/可持续跟踪
[Chat 按钮]                               ← 直接进入研究工具，不在首页放输入框
[2x2 模块网格]                            ← dashboard 质感:4 个均匀 mini 卡
  ① 最新观点    │  ② 宏观视角
  ③ 板块视角    │  ④ 个股视角
[TransparencyFooter]                      ← layout 渲染
```

| 模块           | 内容                                                                          | 数据来源                           |
| -------------- | ----------------------------------------------------------------------------- | ---------------------------------- |
| 博主研究室定位 | `把 @qinbafrank 的公开观点、原文证据和当前数据，整理成一张可追问的研究地图。` | 静态产品定位文案                   |
| Chat 按钮      | 单个大按钮，点击进入 `/research?agent=kol&persona=X`，不自动发送问题          | 静态 CTA                           |
| ① 最新观点     | 3 条 mini 推文（时间 + tickers + 2 行截断文本）                               | `cockpitFeed(limit:3)`             |
| ② 宏观视角     | 宏观框架摘要 + 4 个主题入口                                                   | `cockpitSectors` 的 `macro-regime` |
| ③ 板块视角     | 3-4 个板块（eyebrow + label + mention 次数）                                  | `cockpitSectors` 的 sector layer   |
| ④ 个股视角     | 6 只标的 2 列网格（ticker + 提及次数 + **价格 + 涨跌幅**）                    | `cockpitTickers`                   |

> 不保留：「这个驾驶舱是什么·怎么用」教程卡 —— 老用户冗余,新用户应被价值打动而非教程。

## 数据流

```
/kol/[username]                       (公开,无需登录)
  layout: cockpitProfile + cockpitTickers + cockpitFeed(limit:1)
  page:   cockpitProfile + cockpitTickers + cockpitFeed(limit:3)
  CTA:    /research?agent=kol&persona=X             (需登录 + flag, 不自动发送)

/kol/[username]/sectors
  SectorExplorer: cockpitSectors + useQueries(cockpitSector for every layer=sector)
  Top: 4 个 qinbafrank 顶层 sector 地图（AI 基建 / 加密金融 / 国防太空 / 软件板块）+ 3 步判断方法条
  Middle: 每个板块一条 narrative panel（他的观点 / 代表原文 comments / 打脸条件 / 快捷标的）
  Expand: AI / Crypto / Defense 使用 IndustryChainView；其余 sector 使用 compact framework detail
  Bottom: 聚合总结（注意力最密集板块 / 打脸条件数量 / 可下钻标的与原文数量）

/kol/[username]/macro
  MacroPerspectivePanel: cockpitSector(username, "macro-regime")
  MacroRegimeFramework: cockpitSector + cockpitFeed(limit:80, sector="macro") + Macro hooks
    - 4 个可点击观点：流动性体制 / 政策经济学 / 通胀就业 / 地缘与市场结构
    - 每个观点固定展示三块：看什么数据 / 怎么判断 / 历史观点检索
    - 历史观点检索包含：观点摘要 + 可搜索过往原文
    - 历史来源：skill rule evidence + macro-regime 代表原文 + macro feed
    - 移动端主题入口为 2x2 compact grid，桌面为左侧主题 rail；chip / 原文链接保持 44px 触控高度
    - liquidity metrics / global liquidity
    - macro-risk economy / inflation-rates / sentiment
    - treasury-commodities
  Legacy: /sectors?key=macro-regime 客户端 replace 到 /macro，同时直接渲染 MacroPerspectivePanel 避免空白
```

## 关键设计决策

- **粉丝优先 + 驾驶舱质感**：首页 dashboard 用 2x2 mini grid（每卡有 mini 数据：价格涨跌 / mention 次数）；追问入口收敛为单个 Chat 按钮，避免首页出现重复输入框。
- **追问入口保持轻量**：首页按钮和 `SubNav` 里的 Chat 入口只跳 `/research?agent=kol&persona=X`，不带 `q` 或 `symbol`，让研究工具首页负责承接真实输入；`/chat` 子页仍可用重点 CTA 区解释方法论 / 数据 / 原文三类上下文。
- **ChatComposer 不接 SSE**：如果页面内使用 ChatComposer，只收集输入并跳到 `/research` 触发真实对话（research 页 useEffect 监听 `q=` 自动 handleSend）。首页已简化为单个 Chat 按钮，不再内嵌输入框。
- **带问题深链只用于明确上下文**：板块 / 宏观主题 / 个股详情顶部 CTA 等具体追问入口可使用 `buildKolAgentHref()` 生成 `/research?agent=kol&persona=X&q=...`，保留对应上下文；首页主 CTA 和 `SubNav` Chat 入口只进入研究工具首页，不自动发送问题。
- **ticker 抽取靠中文名字典**：qinbafrank 不用 `$cashtag`、按中文名写公司，后端 `cockpit.TICKER_ALIASES` 维护 `{ticker: [中文名,英文别名]}` (~24 个核心标的) 匹配原文。不依赖 enrichment。
- **多空上色 MVP 不做**：提及点单色；stance 留后续。
- **写死 username 形参，前端不抽 persona 路由**：后端端点保留 `{username}`。
- **板块页改为 Atlas 而不是左侧列表**：`/sectors` 首屏只列出 4 个产品顶层板块：AI 基建、加密金融、国防太空、软件板块。当前语料中的 HBM / 电力 / Fintech 文件作为子主题并入顶层板块，不单独成为入口。`?key=` 仍用于默认展开某个板块；旧 `/sectors?key=macro-regime` 继续跳 `/macro`。
- **板块页避免文章化阅读**：首屏用 icon / badge / attention bar 区分 4 条主线；正文按「他的观点 → 过往评论 → 打脸条件 → 下钻产业链」组织。用户界面不暴露内部语料版本词。
- **宏观视角独立 panel**：宏观不是传统板块，已从 `/sectors` 抽出到 `/macro`。SubNav 增加「宏观视角」，旧 `/sectors?key=macro-regime` 保持兼容跳转。
- **宏观框架页只保留主题下钻**：首屏引导用户在 4 个宏观主题间切换；每个主题只回答「看什么数据」「怎么判断」「有哪些历史原文」三件事。避免额外教程、风险梯、矩阵和重复证据区块。
- **移动端 Atlas 优先**：`SectorExplorer` 在移动端先显示板块地图，再逐个展示 narrative panel；展开态只保留一个板块，避免长文堆叠。宏观深链由独立 panel 承接。
- **移动端个股页先露出详情**：`StockExplorer` 在移动端把 ticker rail 限高为可滚动面板，避免 80+ 标的列表把个股详情推到页面深处。
- **SubNav Chat 入口要和其他五项区分**：`SubNav` 的 Chat/追问入口使用实心 `primary`（emerald）按钮样式，PC 侧边栏表现为绿色实心图标按钮，移动端横向导航表现为绿色实心入口。

## 注意事项

- 浏览公开；只有进入 `/research` 使用 KOL agent 时才需登录 + `kol_research_agent` flag。
- 方法论内容标「已蒸馏,非本人发言」；个股摘录均为原文逐字 + 原文链接。
- 不把回答写成「qinbafrank 本人认为」；命中原推才说「原文支持」。
- 全页 **非投资建议** banner（footer）。
- 后端聚合见 `backend/app/features/kol_research/cockpit.py` + `.context.md`。
- 字号 / 字体严格遵守 `docs/constraints/design-system.md`。
