# Qinbafrank Legacy Entry

## 功能概述

`/qinbafrank` 是 Qinbafrank 研究室的兼容入口，不再承载销售页正文。

真实销售首页已经合并到博主研究室首页：

`/kol/qinbafrank`

该 route 只负责把旧链接、UTM 和 `checkout=ultra` 等 query 参数原样带到 `/kol/qinbafrank`。

## 路由与数据流

| 路由 | 页面 | 数据来源 | 需要认证 |
| --- | --- | --- | --- |
| `/qinbafrank` | legacy redirect | `redirect('/kol/qinbafrank?...')` | 否 |

## 文件结构

| 文件 | 职责 |
|------|------|
| `page.tsx` | Server redirect wrapper，保留 query 参数 |

## 注意事项

- `/qinbafrank` 必须保留在 `frontend/middleware.ts` 的 `PUBLIC_ROUTES`，否则旧外链会被 middleware 先拦截。
- 不要在这里重新放销售页正文；Qinbafrank 资料包销售页的唯一主承载是 `/kol/qinbafrank`。
- 旧 `/frank-agent` route 已删除，不再作为兼容入口。
