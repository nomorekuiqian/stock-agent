# Stock - 个股研究页面

## 功能概述

股票搜索与研究中心。提供预设的股票分组 (Tracks)、搜索功能、实时报价和最近浏览记录。个股相关页面由页面级 `PaywallGuard` 统一控制访问，详情页内部的 AI 区块不再重复做 Pro/Max 二次判断。

## 页面结构

| 页面 | 渲染方式 | 认证 | 描述 |
|------|----------|------|------|
| `/stock` | CSR | PaywallGuard (`stock_research`) | 主页：搜索 + Tracks + 最近浏览 |
| `/stock` (loading) | - | - | 骨架屏 loading 状态 |
| `/stock/[symbol]` | CSR | PaywallGuard (`stock_research`) | 个股详情：报价 + AI 分析 + 技术分析 |

## 关键子组件

- `[symbol]/_components/StockDetailContent` — 个股详情页的客户端主体组件 (报价 + 图表 + AI 分析 + 技术分析)
- `[symbol]/_components/FundamentalsReport` — 基本面 AI 报告区块，依赖页面级 paywall，不再单独检查订阅档位
- `[symbol]/_components/FundamentalsEnhancements` — 基本面增强展示
- `[symbol]/_components/NewsEnhancements` — 新闻增强展示
- `[symbol]/_components/EarningsTab` — 财报标签页
- `[symbol]/_components/MarketTab` — 市场标签页
- `[symbol]/_components/OverviewTab` — 概览标签页
- `[symbol]/_components/TechnicalTab` — 技术分析标签页
- `[symbol]/_components/EventCalendarCard` — 事件日历卡片
- `[symbol]/_components/shared` — 共享类型/工具

## 数据流

```
/stock (client component)
  -> 预设 Tracks (Mag7, AI芯片, 企业软件, 金融, 中概, 消费)
  -> 搜索: api.searchStocks(query)
  -> 报价: api.getStockQuotes(symbols)
  -> 最近浏览: localStorage 'recent-stocks'

/stock/[symbol] (client component)
  -> api.getStockQuotes([symbol])
  -> api.stocks.analysis(symbol)        // AI 分析
  -> api.stocks.technical(symbol)       // 技术分析
  -> api.stocks.technicalSnapshot(symbol)
```

## 调用的 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/stocks/search` | - | 搜索股票 |
| `GET /api/stocks/quotes` | - | 批量报价 |
| `GET /api/stocks/{symbol}` | - | 个股详情 |
| `POST /api/stocks/{symbol}/analysis` | - | AI 分析 |
| `POST /api/stocks/{symbol}/technical` | - | 技术分析 |

## 关键组件

- `StockCard` — 股票卡片 (报价 + 涨跌)
- `StockAnalysisCard` — AI 分析结果展示
- `StockPriceChart` — 价格图表 (lightweight-charts)

## 注意事项

- Tracks 数据硬编码在 page.tsx 中 (STOCK_TRACKS 常量)
- 最近浏览存在 localStorage `recent-stocks`，最多 10 个
- 股票名称映射使用 `lib/stock-names.ts` 的 STOCK_NAMES 常量
- 所有端点公开，不需要认证
