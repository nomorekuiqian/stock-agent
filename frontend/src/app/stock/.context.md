# Stock - 个股研究页面

## 功能概述

股票搜索与研究中心。提供预设的股票分组 (Tracks)、搜索功能、实时报价和最近浏览记录。页面本身可公开浏览；AI 内容缓存读取和生成接口必须带 Bearer token，并通过 `stock_research` entitlement。

## 页面结构

| 页面 | 渲染方式 | 认证 | 描述 |
|------|----------|------|------|
| `/stock` | CSR | 否 | 主页：搜索 + Tracks + 最近浏览 |
| `/stock` (loading) | - | - | 骨架屏 loading 状态 |
| `/stock/[symbol]` | CSR | 浏览否；AI 需 `stock_research` | 个股详情：报价 + AI 分析 + 技术分析 |

## 关键子组件

- `[symbol]/_components/StockDetailContent` — 个股详情页的客户端主体组件 (报价 + 图表 + AI 分析 + 技术分析)
- `[symbol]/_components/FundamentalsReport` — 基本面 AI 报告区块，依赖页面级 paywall，不再单独检查订阅档位
- `[symbol]/_components/FundamentalsEnhancements` — 基本面增强展示
- `[symbol]/_components/NewsEnhancements` — 新闻增强展示
- `[symbol]/_components/EarningsTab` — 财报标签页
- `[symbol]/_components/MarketTab` — 市场标签页：AI 市场解读 + 精简 KPI + 新闻/公告时间线
- `[symbol]/_components/OverviewTab` — 概览标签页
- `[symbol]/_components/TechnicalTab` — 技术分析标签页
- `[symbol]/_components/EventCalendarCard` — 事件日历卡片
- `[symbol]/_components/shared` — 共享类型/工具

## 数据流

```
/stock (client component)
  -> 预设 Tracks (Mag7, AI芯片, 企业软件, 金融, 中概, 消费)
  -> 搜索: api.searchStocks(query)
  -> 报价: api.getStockQuotes(symbols)
  -> 最近浏览: localStorage 'recent-stocks'

/stock/[symbol] (client component)
  -> api.getStockQuotes([symbol])
  -> api.stocks.analysis(symbol)        // AI 分析
  -> api.stocks.technical(symbol)       // 技术分析
  -> api.stocks.technicalData(symbol, timeframe)
  -> MarketTab:
     -> GET /api/stocks/{symbol}/market-overview
     -> GET /api/stocks/{symbol}/news-feed
     -> GET /api/stocks/{symbol}/press-releases
     -> GET/POST /api/stocks/{symbol}/market-analysis (Bearer + stock_research)
```

## 调用的 API

| API | 认证 | 说明 |
|-----|------|------|
| `GET /api/stocks/search` | - | 搜索股票 |
| `GET /api/stocks/quotes` | - | 批量报价 |
| `GET /api/stocks/{symbol}` | - | 个股详情 |
| `GET /api/stocks/{symbol}/analysis/cache` | Bearer + `stock_research` | 缓存 AI 分析 |
| `POST /api/stocks/{symbol}/analysis` | Bearer + `stock_research` | AI 分析 |
| `GET /api/stocks/{symbol}/technical-data?timeframe=daily` | - | 技术图表和指标数据 |
| `POST /api/stocks/{symbol}/technical` | Bearer + `stock_research` | 技术分析 |
| `POST /api/stocks/{symbol}/news` | Bearer + `stock_research` | AI 新闻面分析 |
| `POST /api/stocks/{symbol}/macro` | Bearer + `stock_research` | AI 宏观面分析 |
| `GET /api/stocks/{symbol}/earnings-data` | - | 财报三表、EPS surprise、分部营收 |
| `POST /api/stocks/{symbol}/earnings` | Bearer + `stock_research` | AI 财报分析 |
| `GET /api/stocks/{symbol}/transcript?year=&quarter=` | - | Earnings call transcript |
| `GET /api/stocks/{symbol}/market-overview` | - | Market Tab 精简 KPI |
| `GET /api/stocks/{symbol}/press-releases` | - | 公司公告/新闻稿 |
| `GET /api/stocks/{symbol}/market-analysis` | Bearer + `stock_research` | 缓存 AI 市场面综合解读 |
| `POST /api/stocks/{symbol}/market-analysis` | Bearer + `stock_research` | AI 市场面综合解读 |

## 关键组件

## 注意事项

- Tracks 数据硬编码在 page.tsx 中 (STOCK_TRACKS 常量)
- 最近浏览存在 localStorage `recent-stocks`，最多 10 个
- 股票名称映射使用 `lib/stock-names.ts` 的 STOCK_NAMES 常量
- 原始行情/财报/新闻端点公开；AI 分析端点和 AI 缓存端点需要认证 + `stock_research` entitlement。`use-stock-data.ts` 和 `AIMarketAnalysisCard` 会发送 Bearer token；无 `stock_research` 时前端查询应 `enabled=false`，但不能依赖页面级 PaywallGuard 作为唯一保护。
- 财报 Tab 用 income statement 作为季度选择权威来源；EPS surprise 由 `earnings_history` 匹配同月份，后端会在 yfinance 滞后时用 FMP earnings-calendar 兜底。
- Market Tab 已移除旧的分析师评级、市场热度、同行比较子 Tab；`/analyst-activity` 不再存在。
