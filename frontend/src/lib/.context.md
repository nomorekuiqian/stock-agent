# Lib - 共享工具库

## 功能概述

前端所有页面共享的核心工具库，包含 API 客户端、认证、数据库连接、工具函数。

## 核心文件

| 文件 | 职责 | 大小 |
|------|------|------|
| `api.ts` | 统一 API 客户端，所有后端调用入口 | ~1300 行 |
| `auth.ts` | 认证逻辑 (登录/注册/OAuth/密码重置) | ~400 行 |
| `insforge.ts` | Insforge SDK 客户端 + 认证 token 管理 | ~80 行 |
| `digest-utils.ts` | Digest 数据格式转换 | 小 |
| `stock-names.ts` | 股票代码→名称映射常量 | 小 |
| `portfolio-templates.ts` | 预设投资组合模板 | 小 |
| `timezone.ts` | 时区工具 (美西时间为主) | 小 |
| `utils.ts` | 通用工具函数 | 小 |

## api.ts 架构

```
cachedFetch<T>(key, fetcher, ttl)   // 客户端缓存层 (5min 默认)
_authHeaders(base)                   // 认证 header 工具 (Bearer Token)

api.reports.*                        // 日报 (公开)
api.watchlist.*                      // 自选股 (需认证)
api.digests.*                        // 摘要历史 (需认证)
api.generateDigest()                 // 生成摘要 (body 传 user_id)
api.subscriptions.*                  // 订阅管理
api.sectors.*                        // 板块
api.searchStocks() / getStockQuotes() // 股票
api.getLiquidityMetrics() / ...      // 宏观
api.weeklyReport.*                   // 周报
```

**缓存机制**:
- `cachedFetch` 维护内存 Map，最多 100 个 key
- 相同 key 的并发请求会合并 (inflight dedup)
- SSR 时跳过缓存 (`typeof window === 'undefined'`)
- `invalidateCache(key?)` 可手动清除

## auth.ts → insforge.ts 关系

```
auth.ts                          insforge.ts
  signIn/signUp/signOut            insforge SDK client
  getCurrentUser()  ──────────→    setAuthCache(token)
  getAccessToken()  ──────────→    insforge.auth.getCurrentSession()

Token 恢复链:
  1. SDK 内存 session
  2. httpOnly Cookie (/api/auth/session)
  3. localStorage (insforge-auth-token)
```

**关键函数**:
- `getAccessToken()` — 获取当前 JWT，供 `_authHeaders()` 使用
- `getCurrentUser()` — 获取用户信息 + 刷新 token 缓存
- `setAuthCache(token)` — 共享 token 给 insforge.ts 的 ensureAuth

## 注意事项

- `api.ts` 的类型定义和 API 方法在同一文件，修改接口时注意同步
- 需要认证的 API 方法用 `_authHeaders()`，不需要认证的直接 fetch
- `cachedFetch` 只在客户端生效，server component 每次都重新 fetch
- `insforge.ts` 现在只负责 auth token 管理，不再有数据库操作（已迁移到后端 API）
