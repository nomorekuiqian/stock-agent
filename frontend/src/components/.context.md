# Components - 共享组件库

## 功能概述

全局共享的 React 组件，被多个页面复用。分为根级组件、子目录组件、UI 基础组件三层。

## 目录结构

```
components/
├── __tests__/           # 组件测试
├── for-you/             # For-You 页面专用组件
├── technical/           # 技术分析专用组件
├── ui/                  # shadcn/ui 基础组件
└── *.tsx                # 根级共享组件
```

## 根级组件

### 导航与布局

| 组件 | 职责 |
|------|------|
| `Navbar` | 顶部导航栏，使用 `navigation.ts` 共享配置渲染「每日简报 / AI 研究助手 / 投研 / 我的 / 定价」；“我的”下拉包含专属日报、AI 监控台、关注列表/持仓相关入口；包含 X logo 外链 (`https://x.com/golden_pan1`) + NavAuth + ThemeToggle + MobileMenu；通过 `useIsAdmin()` 条件渲染管理员下拉（含用户管理、活跃、灰度、LLM 用量、用户反馈、邮件预览）；注册后 Guided Tour 的桌面锚点来自 `NavSection.tourTarget` |
| `NavAuth` | 导航栏认证区 (登录按钮/用户菜单) |
| `MobileMenu` | 移动端汉堡菜单，复用 `navigation.ts` 共享导航配置；通过 `useIsAdmin()` 在汉堡菜单内追加管理员入口；移动端 `?tour=1` 会自动展开菜单以暴露四个 tour 锚点 |
| `ThemeToggle` | 明暗主题切换 |
| `Logo` | 品牌 Logo |
| `LogoMarquee` | Logo 滚动展示条 |
| `HomeGuidedTour` | 首页 `/?tour=1` 的注册后 spotlight/coach-mark 导览；启动前会跳过已完成用户，`?tour=home` 可强制预览，完成/跳过时 best-effort 标记 onboarding complete |
| `PageShell` | 页面通用容器；默认提供导航和页脚，`?from=wechat` 等 WebView 流程会跳过全站 chrome |
| `Providers` | 全局 Provider 组合 (QueryClient + Theme + Auth + Subscription)，并通过 `seedClientAuthFromServer()` 做最小 token 恢复兼容 |
| `PostHogProvider` | PostHog client provider |
| `OnboardingGate` | 全局 onboarding 守卫；本地 marker 已完成时跳过后端查询，仅当 `api.user.onboardingStatus()` 明确返回 `completed:false` 时跳首页 `/?tour=1` |
| `AuthSubscriptionSync` | 登录后执行订阅同步/自动订阅 side effect，不参与 auth 内核 |
| `LoginGate` | 页面/片段级登录态守卫 |
| `PasswordField` | 认证表单共用密码输入框，内置显示/隐藏切换 |
| `PaywallGuard` | 付费墙守卫，根据订阅状态或 entitlement 显示/隐藏内容；`twitter_digest` 属于 Pro 权益，Qinbafrank 研究室子页属于 Max 权益；已有付费订阅升级由 `SubscriptionContext.createCheckout()` 自动切到 Billing Portal |

### 图表组件

| 组件 | 数据源 | 库 |
|------|--------|-----|
| `IndexAreaChart` | 指数历史数据 | lightweight-charts |
| `HistoryAreaChart` | 通用历史数据 | lightweight-charts |
| `StockPriceChart` | 个股价格 | lightweight-charts |
| `CommodityAreaChart` | 大宗商品 | lightweight-charts |
| `FredAreaChart` | FRED 面积图 | lightweight-charts |
| `FredBarChart` | FRED 柱状图 | lightweight-charts |
| `GlobalLiquidityChart` | 全球流动性 | lightweight-charts |
| `NetLiquidityChart` | 净流动性 | lightweight-charts |
| `YieldCurveChart` | 收益率曲线 | lightweight-charts |
| `TradingViewWidget` | TradingView 嵌入 | 外部 embed script |

所有 lightweight-charts 组件用 `next/dynamic` + `ssr: false` 懒加载。`HistoryAreaChart` 会按当前 `timeRange`
计算实际拉取窗口（带少量 padding，最短 180 天，最长 1825 天），避免 dashboard 上短周期图表全部请求 5 年 FRED/YFinance 历史而触发外部数据源限流。`HistoryAreaChart` 支持 `fallbackData`：外部 history API 失败或返回空数据时用调用方传入的已知指标点绘图，完全无数据时显示中性占位，不把后端错误文案直接显示给用户。宏观流动性页的核心美国 FRED 图表从页面已有 `liquidity_history` 映射到 `HistoryAreaChart`，其他 FRED 图表走后端 `FredAreaChart`，只把 FX 图表留给 `TradingViewWidget`。

## 注意事项

- 图表组件必须用 `dynamic(() => import(...), { ssr: false })` 加载
- `ReportTabs` 包含早报 / 晚报 / 推特三个入口，`/twitter-digest/*` 会高亮推特 tab
- `ReportContent` / `MorningReportContent` / `DigestInlineReport` 现在会在新闻条目下渲染低视觉权重的时间 metadata；依赖后端新闻项提供 `published_at`
- `Navbar` 与 `MobileMenu` 共用 `navigation.ts`，测试时注意同一导航文案可能在桌面和移动 DOM 中重复
- `PageShell` 仅对 `?from=wechat` 等 WebView 流程跳过全站 chrome；独立 `/onboarding` 页面已移除。
- `HomeGuidedTour` 用 `data-guided-tour-target` 查找导航锚点；新增/调整主导航时要保持「AI 研究助手 / 每日简报 / 投研 / 我的」对应的 `tourTarget` 可用。`?tour=1` 是注册后的正常入口，会尊重本地/后端完成状态；需要调试时用 `?tour=home` 强制显示。
- `Navbar` 右侧有 mature SaaS 风格的 icon-only X logo 外链按钮，面向站外关注入口
- `OnboardingGate` 包在全站 `Providers` 内，但仅对没有 `onboarding_completed:{userId}` marker 的登录用户查询后端。查询失败必须保持原页；不要把 401、5xx、网络错误转成 `completed:false`，否则已完成用户会被误带回首页 tour。
- 顶部导航把「博主研究室」收纳在「投研」下，入口指向 `/kol` 总入口，由该页选择 Qinbafrank 或 Serenity；不要再把导航直连到单个 persona，也不要使用「KOL 对话」或「产业派」作为展示名
- `PaywallGuard` 依赖 `PAYWALL_ENABLED` 模块级常量，测试中无法 mock
- `StockCard` 双击触发删除确认，需要 `onRemove` 回调
- `StockSearchDropdown` 有两种模式：`navigate` (跳转) 和 `watchlist` (添加)
