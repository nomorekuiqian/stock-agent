## 商业模式

### Paywall 策略

全站功能付费。免费用户只能通过邮件订阅获取日报。

| | 免费（邮件订阅） | Pro（付费） |
|--|-----------------|------------|
| 邮件日报 | 完整版 | 完整版 |
| /today 网页日报 | 锁定 | 完整访问 |
| /morning 盘前早报 | 锁定 | 完整访问 |
| /stock 个股分析 | 锁定 | AI 四维分析 |
| /for-you 专属日报 | 锁定 | 个性化摘要 |
| /macro 宏观仪表盘 | 锁定 | 完整访问 |
| /screener AI 选股 | 锁定 | Research Desk |

### 定价

| | 月付 |
|--|------|
| 早鸟价（限前 50 人永久锁定） | $9.99/月 |
| 标准价 | $19.99/月 |

年付延后推出（计划：早鸟 $79.99/年，标准 $149.99/年）。

### 获客路径

```
邮件订阅（免费日报获客）
  → 邀请码兑换（14 天免费试用全部功能）
  → 被邀请者自动获得专属推荐码（裂变）
  → 14 天后付费转化（$9.99 早鸟 / $19.99 标准）
```

邀请码两种类型：
- **通用码**：小红书等渠道发布，任何人可用（环境变量 `INVITE_CODES` 控制）
- **专属推荐码**：每个用户一个，追踪拉新（`subscriptions.referral_code`）

### 定价逻辑

- $19.99 标准价：在用户已有付费习惯（$10-30/月）的中位
- $9.99 早鸟价：标准价 50% off，限 50 人，制造稀缺感 + 降低首次付费门槛
- AI 对话成本可忽略（flash-lite ~$0.001/次，flash ~$0.006/次），不需要积分制
- 后端设 soft cap（每日 50 条消息）防滥用，99.9% 用户碰不到

## 产品模块规划

> 以持仓为中心（Portfolio-centric），不是以内容为中心。
> 用户打开产品时回答的问题是"我的钱怎么了"，不是"今天市场怎么了"。

```
用户输入: 实仓 + 关注列表 + 投资画像
                 |
     +-----------+-----------+
     |           |           |
   日常陪伴     深度服务     主动守护
     |           |           |
   +-+-+     +--+--+        |
   |   |     |  |  |        |
   v   v     v  v  v        v
  日报 周检  组合 个股 机会  预警
```

| # | 模块 | 用户在问什么 | 页面 | 状态 |
|---|------|-------------|------|------|
| 1 | 持仓日报 | 今天有什么跟我的钱有关的事？ | /for-you | 基础版已上线 |
| 2 | 持仓体检 | 我的持仓整体健康吗？ | 待建 | **完全缺失** |
| 3 | 个股深研 | 这只股票到底怎么样？ | /stock | 基础版已上线，DAU ~0 |
| 4 | 机会发现 | 有什么值得关注的投资机会？ | /screener(部分) | Research Desk 在做 |
| 5 | 风险预警 | 有危险能第一时间告诉我？ | 待建 | **完全缺失** |
| 6 | 投资者画像 | （基础设施，驱动个性化） | 待建 | **完全缺失** |

### 模块 1: 持仓日报

每日核心触点，串联其他模块的枢纽。

三层能力：
- **替你读**（已实现）：持仓个股当日表现，压缩信息获取时间
- **替你判断**（需升级）：这条新闻是噪音还是信号？需不需要在意？
- **替你连线**（完全缺失）：跨持仓关联分析、集中度风险、板块联动提示

枢纽作用：持仓部分链接「持仓体检」，个股部分链接「个股深研」，关注列表由「机会发现」填充，风险提示由「风险预警」触发。

### 模块 2: 持仓体检

真人顾问最核心的工作 — 定期 portfolio review。**当前完全缺失，但用户价值最大。**

关键能力：
- 板块分布可视化 + 集中度风险识别（"5 只股票里 4 只是半导体链"）
- 相关性分析（"GOOGL 和 META 走势高度相关，持有两只 = 双倍押注"）
- 表现归因（哪只贡献/拖累了多少，vs SPY/QQQ）
- AI 一键诊断生成组合健康报告
- 宏观敏感度（组合对加息、通胀、流动性收紧有多敏感）

### 模块 3: 个股深研

基础版已有但 DAU ~0。需要做深，并注入组合语境。

关键升级：
- 新闻/事件解读：AI 判断信号 vs 噪音
- 宏观关联：当前利率/流动性环境对这只股票意味着什么
- 组合语境："你已经持有 3 只半导体股了，再买 AMD 会加重集中度"
- 多空视角：Bull case vs Bear case，避免确认偏误

### 模块 4: 机会发现

基于关注列表 + 用户画像，主动发现和推送机会。

设计原则：沉默即信号 — 没有机会不推送，本身就传递了"现在不急"。有事才推，无事不扰。

### 模块 5: 风险预警

把 AI 从"每天看一次"升级为"24 小时在线守护"。

关键设计：不只是通知，而是**带 context 的分析**。
> "NVDA 跌了 5%，受芯片出口限制消息影响。但实际限制范围远小于预期。历史上类似情况平均 X 天恢复。建议：暂不操作。"

### 模块 6: 投资者画像

基础设施，让上面 5 个模块真正个性化。没有画像，所有分析都是通用的；有了画像，分析才能说"对**你**来说意味着什么"。

渐进收集：注册选模板（1 次点击）→ 使用 1 周后问风格（30 秒）→ 主动开启高级配置。

## 里程碑

```
新用户上手        持仓全貌         个股做深         AI 全天在线       越用越聪明
+ 日报升级       组合诊断上线      注入组合语境     预警 + 机会发现    反馈闭环
   |                |                 |                |                |
   v                v                 v                v                v
  MS1 --------->  MS2 ----------->  MS3 ----------->  MS4 ----------->  MS5
```

**MS1 — 新用户上手 + 日报升级**
- Onboarding 模板系统（30 秒完成设置）
- 日报从"替你读"升级为"替你判断"（信号 vs 噪音、跨持仓关联、宏观翻译）
- 纯 Prompt 改动，成本最低但感知最直接

**MS2 — 持仓体检上线**
- 板块分布可视化、集中度分析、表现归因
- AI 一键诊断、周度邮件摘要
- 当前完全缺失但用户价值最大，是和竞品拉开差距的关键

**MS3 — 个股深研升级**
- 新闻/事件解读、宏观关联、组合语境、多空辩论
- 从 DAU ~0 到真正有用

**MS4 — 风险预警 + 机会发现**
- 预警规则引擎、带分析的预警推送、Telegram Bot
- 产品从"工具"变为"助手"的跃迁

**MS5 — 反馈闭环**
- 建议追踪系统（T+7/T+30 回填结果）
- 用户反馈收集、准确率看板、Agent 自我调优

**依赖关系**：MS1 是所有后续的前提。MS2/MS3 可以有一定并行。MS4 依赖 MS1+MS2/MS3 的分析能力。MS5 需要积累数据。

## 方向三：统一研究台

方向三是方向一的**交付界面**。方向一解决"持仓 + 宏观 → 诊断"的分析引擎，方向三解决"用户怎么消费这些分析"的交互形态。

```
+----------------------+----------------------+
|    Agent Chat         |   Content Panel      |
|    (固定)             |   (动态切换)          |
|                       |   - 选股结果          |
|  自动感知右边内容      |   - 个股研究          |
|  用户可以追问         |   - 日报              |
|  Agent 可切换右边      |   - 宏观周报          |
|                       |   - 板块分析          |
+----------------------+----------------------+
```

## 现有模块 → 未来模块映射

每个网站页面的当前定位和未来演进方向。

### /today — 市场日报

- **当前**：Free 层获客工具。每日 AI 全市场分析，邮件推送拉新
- **未来**：完整日报作为付费功能（网页端），邮件推送保持给所有订阅者
- **对应模块**：无直接对应。是获客入口，不属于持仓中心的模块体系

### /for-you — 个性化摘要 (MyBrew)

- **当前**：按用户自选股生成个性化每日摘要，是"持仓日报"基础版
- **未来**：判断层（信号 vs 噪音）+ 连线层（集中度风险、板块联动）+ 宏观翻译
- **对应模块**：**模块 1 — 持仓日报**

### /stock — 个股研究

- **当前**：按需的个股深度研究，四维分析（基本面+技术面+新闻面+宏观面），DAU ~0
- **未来**：新闻解读 + 宏观关联 + 组合语境 + 多空视角
- **对应模块**：**模块 3 — 个股深研**

### /macro — 宏观仪表盘

- **当前**：四维度风险评估（流动性/经济/通胀/情绪）+ AI 周报
- **未来**：降低门槛（大白话翻译）+ 持仓关联（"宏观对你的持仓如何"）
- **对应模块**：**模块 2（持仓体检）** 和 **模块 5（风险预警）** 的数据基础设施

### /sectors — 板块分析

- **当前**：12 个预定义板块的每日 AI 分析
- **未来**：板块轮动信号 + 持仓集中度提醒 + 机会发现信号源
- **对应模块**：与 **模块 4（机会发现）** 有交集

### /screener — AI 选股助手

- **当前**：对话式选股 + Research Desk 多内容面板
- **未来**：独立为 /research 通用研究台，成为产品主入口
- **对应模块**：**模块 4（机会发现）** 的交互载体 + 方向三的实现

## 设计原则

1. **顺应行为，不改变行为** — 被动投资者用模板，主动用户深度自定义
2. **零摩擦个性化** — 一键选模板 → 简单问卷 → 高级自定义，渐进递增
3. **AI 主动服务，用户被动接收** — 替用户研究好了送到面前
4. **沉默即信号** — 没有异常不推送，本身就是价值
5. **日报走邮件，预警走即时** — 邮件深度阅读，Telegram 实时触达
6. **决策辅助 ≠ 投资建议** — 输出判断和分析框架，不输出具体交易指令
