# TheMarketBrew 产品路线图

> 最后更新：2026-04-11
>
> 核心认知：帮用户赚钱，而非堆积信息。
> 产品愿景：一个持续运行的 AI 私人投资分析师——有记忆、有日程、会主动工作。

---

## 商业模式

### Paywall 策略

全站功能付费。免费用户只能通过邮件订阅获取日报。

| | 免费（邮件订阅） | Pro（付费） |
|--|-----------------|------------|
| 邮件日报 | 完整版 | 完整版 |
| /today 网页日报 | 锁定 | 完整访问 |
| /morning 盘前早报 | 锁定 | 完整访问 |
| /stock 个股分析 | 锁定 | AI 四维分析 |
| /for-you 专属日报 | 锁定 | 个性化摘要 |
| /macro 宏观仪表盘 | 锁定 | 完整访问 |
| /research AI 研究台 | 锁定 | Research Agent |

### 定价

| | 月付 |
|--|------|
| Pro | $10/月 |
| Max | $20/月 |

暂不展示年付、早鸟价、划线原价或促销标签。

### 获客路径

```
邮件订阅（免费日报获客）
  → 邀请码兑换（14 天免费试用全部功能）
  → 被邀请者自动获得专属推荐码（裂变）
  → 14 天后按需转化到 Pro $10/月 或 Max $20/月
```

### 增长策略

```
Agent 惊艳体验 → 截图/录屏 → 社媒传播 → 新用户注册
                                              ↓
                        14 天试用期内每日专属报告 → 形成习惯
                                              ↓
                                    试用期结束 → 付费转化
```

**Agent = 橱窗**（让路人停下脚步），**专属 = 店铺**（让进来的人买单）。

## 产品架构：三大支柱

```
┌────────────────────────────────────────────────────────┐
│                    TheMarketBrew                        │
├──────────────┬──────────────────┬──────────────────────┤
│   专属系统    │   研究引擎        │   市场数据层          │
│  (Personal)  │  (Research)      │  (Market Intel)      │
│              │                  │                      │
│  为你服务     │  帮你研究         │  原材料              │
│  有记忆       │  有深度           │  有广度              │
│  会主动       │  按需调用         │  持续更新            │
└──────────────┴──────────────────┴──────────────────────┘
```

- **市场数据层**是基础设施，供上面两个消费
- **研究引擎**是按需深度能力，被专属系统调用，也被用户直接调用
- **专属系统**是面向用户的核心体验，以用户为中心组合一切

## 支柱 1：专属系统（Personal）

### 目的

让用户感觉自己有一个 7x24 在线的私人投资分析师。不需要主动做任何事——把实仓交给系统，系统就会替你监控、分析、判断、提醒。

### 用户感受

> "我每天早上打开手机，它已经帮我看完了所有跟我的钱有关的事。有重要的事会提前告诉我，没事的时候不打扰我。用了三个月后，它比我自己还了解我的持仓。"

### 核心模块

| 模块 | 一句话 |
|------|--------|
| **持仓管理** | 用户录入真实仓位（symbol + 数量 + 成本），系统知道你的钱在哪 |
| **记忆系统** | 持续积累用户数据（偏好、历史、行为），越用越懂你 |
| **投资者画像** | 知道你的风格（成长/价值/均衡）、期限、风险偏好 |
| **每日专属报告** | 每天告诉你"今天跟你的钱有关的事"，带判断不只是罗列 |
| **持仓体检** | 周度组合诊断：健康分 + 问题识别 + 行动建议 |
| **机会雷达** | 基于你的画像和持仓缺口，系统主动发现并推荐机会 |
| **风险守护** | 持续监控，有风险时带分析地通知你（不是裸推价格变动） |
| **建议追踪** | 记录每次推荐的结果，系统自我评估，形成信任闭环 |

## 支柱 2：研究引擎（Research）

### 目的

为用户提供按需的深度研究能力。它是用户主动与产品交互的主入口——用户想深入了解某个问题时，通过对话式研究台获得专业级分析。同时，它也是专属系统的"大脑"，被后台任务调用完成深度分析。

### 用户感受

> "我问它'我的持仓有什么风险'，它不只是给通用答案，而是真的分析了我持有的 5 只股票，告诉我科技集中度太高、对利率敏感。我再问'有什么解法'，它帮我筛了几只防御性标的。"

### 核心模块

| 模块 | 一句话 |
|------|--------|
| **对话式研究** | 多轮对话 Agent，用户自然语言提问，Agent 调用工具回答 |
| **选股筛选** | 多条件量化筛选（71 字段 + 5800 股票宇宙） |
| **实时搜索** | Web 搜索能力，回答"今天为什么跌了"这类实时问题 |
| **个股深研** | 基本面/技术面/新闻面/宏观面四维分析，带组合语境 |
| **知识库** | 财报/研究结果持久化存储，支持跨会话语义检索 |
| **持仓感知** | Agent 知道你的持仓，所有回答都从你的视角出发 |

### 短期路线图（3-5 天，获客重点）

三个维度同步升级：能力、个性化、体验。

**能力升级 — 新增 7 个工具，解锁已有数据给 Agent 用：**

| 新增 Tool | 用户能问什么 | 来源 |
|-----------|------------|------|
| `web_search` | "NVDA 今天为什么跌了"、"最新芯片政策" | Gemini grounding / Perplexity |
| `get_stock_news` | "AAPL 最近有什么新闻" | data_tools/news.py |
| `get_stock_quote` | "NVDA 现在多少钱"、"我的持仓今天涨跌" | data_tools/market_data.py |
| `get_technical_analysis` | "TSLA 技术面怎么样" | data_tools/technical.py |
| `get_stock_fundamentals` | "MSFT 的 PE 是多少" | yfinance_service.py |
| `get_earnings_calendar` | "下周有哪些重要财报" | data_tools/earnings.py |
| `get_market_overview` | "今天大盘怎么样" | data_tools/market_data.py |

**个性化升级 — Agent 知道你是谁：**
- Agent 启动时读取用户 watchlist，所有回答自动带持仓视角
- 用户问"有什么风险"→ 分析的是他自己的股票，不是泛泛而谈

**体验升级 — SSE 事件分级，让 Agent 看起来更高级：**
- 工具调用时前端显示"正在查询 NVDA 实时行情..."
- 完成后显示"已获取数据"
- 用户感知到 Agent 在"工作"，不是黑盒等待

## 支柱 3：市场数据层（Market Intel）

### 目的

底层数据基础设施。本身不直接面向用户，而是为专属系统和研究引擎提供"原材料"。覆盖面要广，更新要及时，可靠性要高。

### 用户感受

用户不直接感知这一层。但当 Agent 能即时回答"NVDA 本季度 EPS 多少"、"下周有什么重要经济数据"、"过去三个月我的组合波动率多大"时，背后就是这一层在支撑。

### 核心模块

| 模块 | 一句话 | 状态 |
|------|--------|------|
| **行情数据** | 实时报价、历史价格、盘前盘后 | 已有 |
| **财经新闻** | 新闻获取、按 symbol 过滤 | 已有 |
| **宏观指标** | 利率、流动性、经济数据（FRED 30+） | 已有 |
| **技术分析** | 30+ 技术指标、趋势信号 | 已有 |
| **日历事件** | 财报日历、经济数据日历 | 已有 |
| **板块分析** | 12 板块归类与分析 | 已有 |
| **SEC 财报** | 10-K/10-Q 原文获取与摘要 | 待建 |
| **事件匹配** | 新闻/事件自动关联用户持仓 | 待建 |
| **宏观翻译** | 宏观数据转化为对个人持仓的影响 | 待建 |

## Phase 路线图

### Phase 1：Agent 惊艳 + 地基（2-4 周）

> 目标：Research Agent 变得惊艳且可分享（获客），同时搭建专属系统的数据地基。

**研究引擎（获客重点）**：
- [ ] Agent 接入 watchlist 上下文，回答带个人语境
- [ ] 新增 Web 搜索能力（回答"为什么跌了"这类实时问题）
- [ ] 新增新闻查询工具
- [ ] 输出格式优化（适合截图分享到社媒）

**专属系统（地基）**：
- [ ] 持仓管理 V1：在 watchlist 基础上增加数量和成本价
- [ ] 记忆系统 DB schema 设计与建表
- [ ] Agent 交互自动写入记忆

### Phase 2：个性化启动（4-8 周）

> 目标：用户开始感受到"它懂我"，每日报告从信息罗列变成决策辅助。

**专属系统**：
- [ ] 每日报告升级：信号 vs 噪音判断、跨持仓关联、宏观翻译
- [ ] 投资者画像 V1：Onboarding 模板 + 行为推断
- [ ] 报告输出读取记忆做个性化

**研究引擎**：
- [ ] 流式工具事件（"正在查询..."增强信任感）
- [ ] 个股深研注入组合语境

### Phase 3：深度能力（8-12 周）

> 目标：持仓体检上线，知识库建立，系统开始有记忆地持续工作。

**专属系统**：
- [ ] 持仓体检 V1（健康分 + 归因 + 诊断 + 处方）
- [ ] 任务系统框架（支持定时生成、周度体检、自动邮件）
- [ ] 体检 insights 回流每日报告

**研究引擎**：
- [ ] SEC 财报获取与摘要工具
- [ ] 向量知识库（研究结果持久化 + 语义检索）

### Phase 4：主动智能（12-18 周）

> 目标：系统从"被动工具"变为"主动助手"——有事找你，没事不扰。

**专属系统**：
- [ ] 机会雷达：系统主动推荐（基于画像 + 持仓缺口）
- [ ] 风险守护：事件监控 + 影响评估 + 智能推送
- [ ] 推送判断引擎（重要性 x 相关性 x 频率控制）

**研究引擎**：
- [ ] 多 LLM 供应商支持（深度分析用强模型）
- [ ] Agent 升级为多步推理模式

### Phase 5：闭环进化（18+ 周）

> 目标：系统越用越聪明，用户越来越信任。

- [ ] 建议追踪系统（T+7/T+30 结果回填）
- [ ] 准确率看板（系统自我评估）
- [ ] 时间线界面（/for-you 演进为完整时间线）
- [ ] 月度回顾（建议回顾 + 画像更新）

## 设计原则

1. **Agent 获客，专属留人** — Agent 提供即时惊艳用于传播；专属形成习惯驱动转化
2. **顺应行为，不改变行为** — 被动投资者用模板，主动用户深度自定义
3. **零摩擦个性化** — 一键模板 → 简单问卷 → 高级自定义，渐进递增
4. **AI 主动服务，用户被动接收** — 替用户研究好了送到面前
5. **沉默即信号** — 没有异常不推送，本身就是价值
6. **记忆驱动一切** — 每次交互写入，每次输出读取，越用越精准
7. **决策辅助 ≠ 投资建议** — 输出判断框架，不输出具体交易指令
