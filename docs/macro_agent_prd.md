## 1. 产品概述

### 1.1 产品名称
**Stock Agent** - AI 驱动的美股市场分析助手

### 1.2 产品定位
面向**中文美股投资者**的**每日市场分析工具**，用通俗易懂的语言帮助用户**看懂市场**。

### 1.3 核心价值主张
> "让每一个中文投资者都能像专业分析师一样理解美股市场"

- **不是**告诉你买什么卖什么
- **而是**帮你理解市场正在发生什么，以及背后的逻辑

### 1.4 目标用户
| 用户画像 | 特征 | 痛点 |
|---------|------|-----|
| **主要用户** | 持有美股的中文投资者 | 英文财经信息获取成本高，专业术语看不懂 |
| **次要用户** | 关注美股的潜在投资者 | 想入门但觉得门槛高，不知道从哪看起 |
| **延伸用户** | 财经内容创作者 | 需要快速获取市场概况作为创作素材 |

## 2. 产品阶段规划

### Phase 1: 宏观市场分析 (当前)
**目标**: 把宏观市场分析做到极致，建立用户信任

**核心功能**:
- 每日市场全景分析
- 多维度数据覆盖（股指、利率、商品、货币、波动率）
- AI 生成中文科普式解读
- 风险信号聚合与预警

**成功指标**:
- 分析报告质量评分 ≥ 4.5/5
- 用户日活留存率 ≥ 40%
- 报告生成成功率 ≥ 99%

### Phase 2: 个股分析
**目标**: 扩展到个股层面，满足更具体的投资需求

**核心功能**:
- 输入 ticker 获取个股分析报告
- 基本面数据（估值、财务、增长）
- 技术面简析（趋势、支撑阻力）
- 与宏观环境的关联解读

### Phase 3: 辅助决策
**目标**: 从"看懂市场"升级到"辅助决策"

**核心功能**:
- 行业轮动分析
- 投资组合健康度检查
- 风险敞口提示
- 个性化关注清单

### 3.3 风险信号系统

| 信号 | 触发条件 | 含义 |
|-----|---------|-----|
| 收益率曲线倒挂 | 10Y-3M < 0 | 历史上最可靠的衰退预警 |
| 信用市场压力 | HYG 周跑输 LQD > 1% | 市场开始规避风险 |
| 银行板块压力 | KRE 周跌幅 > 5% | 流动性风险信号 |
| 高波动环境 | VIX > 25 | 市场剧烈波动 |
| 避险情绪 | 黄金涨 + VIX 高 | 资金涌入避风港 |

**综合风险等级**:
- 🟢 **低风险**: 0 个信号触发
- 🟡 **中等风险**: 1-2 个信号触发
- 🔴 **高风险**: 3+ 个信号触发

### 3.4 写作风格规范

**核心原则**:
1. **科普式表达** - 每个专业术语首次出现时用通俗语言解释
2. **比喻先行** - 用"温度计"、"晴雨表"等比喻帮助理解
3. **数据为证** - 所有观点必须有数据支撑，不编造
4. **中立客观** - 只做环境判断，不给买卖建议
5. **亲和专业** - 像懂行的朋友在解释，不是教科书

**禁止事项**:
- ❌ 具体买卖建议（"应该买入XX"）
- ❌ 仓位建议（"建议减仓"）
- ❌ 价格预测（"明天会涨到XX"）
- ❌ 编造数据
- ❌ 过度恐慌或过度乐观的语气
