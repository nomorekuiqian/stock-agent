# Brief 02：小众/新兴股「{X}是什么公司」模块模板（以 CRWV 为样板，批量用于 20+ 只）
- **URL**：/stock/{T}#about（不另开 URL，一个意图对应一个页面）
- **适用代码与需求**（美国「是什么公司」类月量合计）：NBIS 200、SOFI 180、CRCL 180、RKLB 160、OKLO 140、CRWV 130、MSTR 130、SMR 100、LITE 100、VRT 100、IONQ 90、SNDK 80、ALAB/APP/NOW/VST 各 70、RGTI 60、GEV 60、HIMS 50、TEM/RDDT 40。全部数字见 keywords_clustered.csv。
- **同页同时承接**：{t} 股票（crcl 1,900、rklb 1,000、smr 1,000、crwv 880、nbis 880、Oklo股票 720）。
- **SERP 观察**（前次 kw_niche 抽样）：「CoreWeave为什么跌」「pltr为什么一直跌」的中文结果偏向社媒/视频，缺少结构化的中文解释页（这是推断，样本有限）。
- **写作结构**（每只 150–300 字，存入数据库）：
  1. 一句话定义：`{中文名/英文名}（{T}）是一家……的公司，总部位于……，在 {交易所} 上市。`
  2. 怎么赚钱：主要收入来源 2–3 点（来源：10-K / 公司简介）。
  3. 为什么最近被关注：所属主题（AI 算力租赁、小型核反应堆、稳定币、量子计算……），链接到 /today 中最近提到它的报告。
  4. 主要竞争对手/同类：链接到同行的 /stock 页（例如 CRWV ↔ NBIS）。
  5. 主要风险（中性、不带建议）：例如客户集中度、负债、尚未盈利。
- **繁体别名**：在别名行写 `CoreWeave / CRWV / 是什麼公司`（承接 crwv 是什麼公司 10、nbis 是什麼公司 40、oklo 是什麼公司 30）。
- **FAQ**：{X}是什么公司？｜{X}靠什么赚钱？｜{X}和{同行}有什么区别？｜{X}最近为什么涨/跌？
- **质量**：LLM 生成后，人工抽检 10%；事实（总部、上市时间、交易所）必须与数据层或 10-K 一致；不得出现「推荐」「值得买」。
- **验收**：样本组中 niche 代码全部有 #about；GSC 4 周内出现「{t} 是什么公司」类查询的展示。
