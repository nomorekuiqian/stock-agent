## 统一验证证据

- 前端：85 项 Vitest（5 个测试文件）、改动范围 ESLint、TypeScript、完整生产构建均通过。
- 后端：26 项隔离 pytest 通过（6 条已有依赖警告）；禁止网络的应用导入和路由注册通过，未启动生产 lifespan 或真实生成。
- HTTP：46 个页面/路由通过，见 `plan-http-acceptance.json`；sitemap：6 个分片、87 个 URL 全部通过，见 `plan-sitemap-acceptance.json`，逐 URL 检查状态/canonical/robots。
- 浏览器：18 组通过，见 `plan-browser/results.json`，桌面 1440 与手机 390 宽；检查 H1、JS 异常、横向溢出、实际正文与质量分母。
- 爬虫/结构化数据：`plan-cross-route-checks.json`，四个页面、六种 UA 共 24 组正文一致、可见 FAQ 与 JSON-LD 一致、无禁止 schema。流式 HTML 的页脚顺序不是正文差异。
- 公司资料：`plan-company-lengths.json`（70 篇 150–300 汉字）；`plan-company-review.json`（六篇重点和额外抽样/修订的来源核对）。人工签字未伪称完成。
- 构建审计：`plan-content-audit.json` 是合成数据验收，不能用其中通过数量推断生产页质量。旧文件仍保留历史证据，旧统计不代表新计划结果。
- 最终机器汇总与检查数量见 `plan-verification-summary.json`。
