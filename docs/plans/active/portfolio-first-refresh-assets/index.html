01 可信事实

同一事件处理一次，合并转载；保留来源、时间与实质更新。

02 关联持仓

说明为什么与你有关；没有提供权重或理由，就承认未知。

03 简短交付

默认展示 1–3 条重点；无重大新增可为空，关键事件不因条数上限漏掉。

04 检查结果

无重要新增、覆盖不全、处理失败分开；用漏报、误报、复用与成本验证。
