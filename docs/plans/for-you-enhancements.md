### 2. 持仓基准对比

**一句话**: 在持仓市值旁展示 vs SPY/QQQ 的收益对比，回答"我今天跑赢大盘了吗"。

**解决的问题**: 散户很难直观感受自己组合的表现好坏，需要一个参照系。

**展示方式**: 嵌入持仓总览卡片内，一行文字："vs SPY +0.52%, vs QQQ +1.21%"。跑赢绿色，跑输红色。

**计算方式**:
- 用户组合日收益 = Σ(持仓权重 × 个股日涨跌)
- 对比 SPY/QQQ 同期涨跌
- V1 只做今日对比，后续可扩展周/月

**技术要点**:
- V1 纯前端计算：已有 useStockQuotes，额外请求 SPY/QQQ 报价即可
- 不需要新后端端点
- 只在有真实持仓（shares 数据）时展示，纯 watchlist 不展示（motivate 用户录入持仓）

**难度**: 低 | **价值**: 中 | **依赖**: 持仓拆分（需要 shares 数据做加权计算）

---

### 3. "今天该关注什么" AI 焦点

**一句话**: 页面顶部 1-3 条 AI 筛选的今日最重要事项，digest 的"电梯演讲版"。

**解决的问题**: Digest 信息量大但阅读成本高，用户日常只想 10 秒扫一眼有没有大事。

**展示方式**:
```
⚡ NVDA 盘后跌 4.2% — 你持有 100 股，影响约 $3,400
📊 美国 CPI 今晚公布 — 你 88% 仓位在科技股，需关注
✅ 持仓今日 +1.89%，跑赢 SPY — TSLA 贡献最大涨幅
```

**焦点类型与优先级**（从高到低）:
1. 突发事件 — 持仓股盘后/盘前波动 >3%
2. 当日宏观数据 — CPI、Fed、非农等
3. 财报临近 — 持仓股 3 天内有财报
4. 异常信号 — 成交量异常等
5. 组合表现汇总 — 兜底项，总有内容

**技术要点**:
- V1 用规则引擎（零 AI 成本）：从已有报价 + 事件数据中按规则筛选
- V2 升级：在 digest agent 中追加 `daily_focus` 输出字段
- 新增端点 `GET /api/brew/focus`

**难度**: 中偏低（V1 规则）/ 中（V2 AI） | **价值**: 高 | **依赖**: 持仓拆分（用于计算影响金额）

### 4. 持仓健康度检查

**一句话**: 每周或每次查看时，展示持仓的集中度、相关性、板块盲区等健康指标。

**解决的问题**: 散户容易过度集中在熟悉的板块（如全买科技股），缺乏风险意识。

**展示方式**: 持仓总览下方的折叠面板，展示 2-3 条诊断结论：
```
⚠️ 集中度：68% 仓位在科技股（SPY 仅 32%）
⚠️ 相关性：NVDA 与 AMD 相关性 0.85，下跌时会同步
💡 盲区：无防御性板块（公用事业、医疗），市场回调时缺乏缓冲
```

**诊断维度**:
- 板块集中度 vs SPY 基准
- 持仓间相关性（top correlated pairs）
- 板块覆盖盲区
- 单股占比过高警告（>30%）

**技术要点**:
- 板块数据来自 FMP company profile（持仓拆分 plan 已规划）
- 相关性需要历史价格数据（yfinance 30 天日收益率），计算量不大
- 可以在 `GET /api/portfolio/summary` 中追加 `health_check` 字段
- 建议缓存 24h（持仓不频繁变化）

**难度**: 中 | **价值**: 高 | **依赖**: 持仓拆分 + 板块数据

### 5. 信息流/主题订阅

**一句话**: 让用户自选关注的板块或主题，digest 中增加对应内容段落。

**解决的问题**: 当前 digest 只围绕个股，但投资者还关心板块趋势、宏观主题、竞争对手动态等。

**可订阅的主题类型**:
- 板块主题：AI 芯片、新能源、中概股、生物医药…
- 宏观指标：CPI、非农、Fed 动态、国债利率…
- 竞争对手：持有 AMD 的人关注 NVDA/Intel 动态
- 自定义关键词（V2）：如 "tariff"、"AI regulation"

**技术要点**:
- 新增 `user_interests` 表（user_id + topics JSON array）
- Digest agent 的 instruction 中注入用户关注主题
- Agent 输出中新增 `topic_insights` 段落
- 前端：主题选择页面（预设主题 + 自定义）

**难度**: 中 | **价值**: 中高 | **依赖**: 无，可独立实施，但最好配合 digest 改版

---

### 6. 个人投资笔记

**一句话**: 让用户在每只股票旁记录买入理由、目标价、止损价等个人笔记。

**解决的问题**: 投资者经常忘记自己买入的理由，导致情绪化交易。笔记功能帮助维持投资纪律。

**使用场景**:
- 记录买入理由："看好 AI 资本开支周期"
- 设定目标："目标价 $1000，跌破 $750 止损"
- Digest 生成时 AI 可以引用笔记："你设的目标价 $1000，当前 $850，还差 17%"

**技术要点**:
- 新增 `user_stock_notes` 表（user_id + symbol + note_text + target_price + stop_loss）
- 前端：股票卡片上的笔记图标，点击展开编辑
- Digest agent 可选读取笔记作为上下文
- 简单 CRUD，无复杂逻辑

**难度**: 低 | **价值**: 中 | **依赖**: 无，完全独立
