# Email Conversion Hooks Engineering Plan

> Status: Planning
> Related: backend/app/features/subscription/email_templates.py, backend/app/features/notification/.context.md
> Vision: 优化免费日报邮件的转化路径，在内容中设计钩子引导用户进入网站并升级付费

## 目标

在免费日报邮件的关键位置插入 5 个转化钩子，引导订阅用户访问网站、设置自选股、升级 Pro/Max。

## 现状

当前免费日报邮件内容流：

```
1. Header            品牌 + 日期
2. Title Card        个性化问候 + 标题（可点击进网站）
3. 市场概览          6 大指数卡片（S&P 500, Nasdaq, 10Y, VIX, Gold, USD）
4. 今日要点          Agent 生成的市场要点摘要
5. 新闻              头条（2-4 条深度分析）+ 快讯（8-12 条）
6. 近期事件          经济日历
7. 总结与展望        多段落市场展望
8. 反馈调查          "有帮助 / 没帮助" 两个按钮
9. Digest CTA        唯一的转化入口 — "获取我的专属日报"
10. Footer           Disclaimer + Unsubscribe
```

### 核心问题

| 问题 | 说明 |
|------|------|
| CTA 太少太晚 | 唯一的转化入口在邮件末尾，大部分用户在新闻区就停止滚动了 |
| 只推一个功能 | 只推专属日报，没有展示 Pro/Max 的完整价值 |
| 内容与转化割裂 | 内容区没有任何钩子，阅读体验好但不引导行动 |
| 没有差异化体验 | 免费用户看到的和付费用户完全一样，没有"还有更多"的感觉 |

## 设计

### 5 个钩子的插入位置

```
Header
Title Card
市场概览 ← Hook 1: 指数区之后（注意力最高点）
今日要点
新闻·头条  ← Hook 2: 头条和快讯之间（阅读中段）
新闻·快讯
近期事件
总结与展望 ← Hook 3: 展望末尾（决策冲动点）
反馈调查   ← Hook 4: 反馈按钮升级（已有交互意愿）
Digest CTA ← Hook 5: 底部 CTA 升级（现有位置优化）
Footer
```

### Hook 1: 市场概览后 — "个股追踪"暗示条

**位置**：市场概览（6 大指数）卡片的正下方
**设计**：一行淡色提示文字，不是独立卡片，视觉上是市场概览的延伸

```
────────────────────────────────────
 S&P 500    Nasdaq    10Y Treasury
 5,243      16,432    4.21
 +0.83%     +1.12%    -3 bps

 VIX        Gold      US Dollar
 18.23      3,124     103.47
 -5.21%     +0.41%    -0.18%

 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
 想看你持仓的涨跌? -> 添加自选股
────────────────────────────────────
```

- **逻辑**：用户刚看完大盘数据，自然会想"我的股票呢？" — 这是转化意图最强的瞬间
- **链接**：`/for-you/watchlist`
- **实现**：在指数 grid 下方加一行 12px 灰色文字 + 绿色链接，不需要独立卡片

### Hook 2: 头条与快讯之间 — "AI 深度分析"内容截断

**位置**：新闻头条区的最后一条之后，快讯区之前
**设计**：模拟一条"被截断"的深度分析条目，用模糊渐变暗示还有更多内容

```
────────────────────────────────────
 头条

 [新闻标题 1]  深度分析: xxxxxxx
 [新闻标题 2]  深度分析: xxxxxxx

 ┌─────────────────────────────────┐
 │  TSLA 特斯拉 +3.2%             │
 │  Q1 交付量超预期，但毛利...     │
 │  (渐变模糊遮罩)                 │
 │                                 │
 │  解锁 AI 个股深度分析 ->        │
 └─────────────────────────────────┘

 快讯
 ...
────────────────────────────────────
```

- **逻辑**：头条分析是邮件最有价值的内容，用户读完后注意力仍在。展示一条"差一点就能看到"的个股分析，利用好奇心驱动点击
- **链接**：`/stock`（个股分析页）
- **数据来源**：从当天 agent 数据中取 top mover 股票名 + 变化百分比 + 一句话开头。不需要真实完整内容，只需要真实股票名和数据
- **实现**：底部用 CSS `linear-gradient(to bottom, rgba(255,255,255,0), #fff)` 遮罩 + CTA 链接

### Hook 3: 总结与展望末尾 — "宏观仪表盘"数据预览

**位置**：总结与展望 section 的最后一段之后
**设计**：一个小型信号灯面板，展示 4 个宏观维度的状态

```
────────────────────────────────────
 总结与展望
 xxxxxxxxxxxxxxxxxxxxxxxxxx

 ┌─────────────────────────────────┐
 │  宏观仪表盘                     │
 │                                 │
 │  流动性  ● 宽松    经济  ● 稳健 │
 │  通胀    ● 降温    情绪  ● 贪婪 │
 │                                 │
 │  查看完整仪表盘 ->              │
 └─────────────────────────────────┘
────────────────────────────────────
```

- **逻辑**：用户刚读完文字展望，心里在想"现在到底什么环境？" — 用 4 个信号灯给一个极简答案，但要看细节就得进网站
- **链接**：`/macro`
- **数据来源**：可以从 macro/risk 的最新数据中取 4 个维度的状态标签和颜色。初版可用静态文案，后续动态化

### Hook 4: 反馈区升级 — 加入"Pro 功能"提示

**位置**：现有反馈 section 内部，反馈按钮下方
**设计**：在"有帮助/没帮助"按钮下方加一行文字

```
────────────────────────────────────
 今天的日报对你有帮助吗?

 [有帮助]    [没帮助]

 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
 升级 Pro 解锁: AI 个股分析 · 宏观仪表盘 · 盘前早报
 $4.99/月 (早鸟价) ->
────────────────────────────────────
```

- **逻辑**：用户点完"有帮助"后心理认同度最高，是推升级的好时机。即使不点反馈按钮，扫到这行文字也能种下印象
- **链接**：`/pricing`
- **实现**：在 `get_feedback_section()` 底部加一行 11px 灰色文字 + 绿色价格链接

### Hook 5: 底部 CTA 升级 — 从单一推广变为双栏

**位置**：替换现有 `get_digest_cta_section()`
**设计**：双栏布局，左边推专属日报（免费功能，低门槛），右边推 Pro 升级

```
────────────────────────────────────
┌───────────────┬───────────────────┐
│  专属日报      │  升级 Pro          │
│               │                   │
│  每天一份只分析 │ AI 个股分析        │
│  你持仓的报告  │ 宏观仪表盘         │
│               │ 盘前早报           │
│               │ 自选股 25 只       │
│               │                   │
│ [添加自选股]   │ [$4.99/月 开通]    │
│  免费          │  限时早鸟价        │
└───────────────┴───────────────────┘
────────────────────────────────────
```

- **逻辑**：给两条路径 — 不想花钱的先设 watchlist（进入产品，后续再转化），愿意付费的直接 checkout
- **链接**：左 -> `/for-you/watchlist`，右 -> `/pricing`

## 待定问题

- **Hook 2 数据源**：top mover 数据从哪里取？可选方案：(a) 从当天 daily_report agent 的 indices 数据中取涨幅最大的；(b) 从 screener 取当日 top gainer；(c) 硬编码几个热门标的轮换
- **Hook 3 动态化**：宏观信号灯是否值得接入 macro/risk 实时数据？还是静态文案 + 链接就够了？
- **A/B 测试**：是否需要对有钩子 vs 无钩子的邮件做对比？Resend 是否支持 segment 级别的模板切换？
- **邮件客户端兼容性**：CSS gradient 遮罩（Hook 2）在 Outlook 中可能不支持，需要 fallback 方案
