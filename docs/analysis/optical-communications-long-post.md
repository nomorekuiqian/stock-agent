# Optical Communications Long Post Draft

## 可发布版本

光通信板块这波，还能不能继续看？

$LITE、$AAOI、$COHR、$AXTI、$SIVE 这些票，到底是在炒概念，还是 AI 算力链真的出了新瓶颈？

我把过去 72 小时 X 上关于光通信 / CPO / 800G / 1.6T / InP 的高质量讨论梳理了一遍。

结论先说：

这轮讨论的重点不是“光模块涨没涨”。

而是 AI 基建的瓶颈，正在从 GPU 往光互联、材料、激光器和上游衬底移动。

这轮被反复提到的名字主要是：

$LITE、$AAOI、$COHR、$AXTI、$SIVE、$NOK、$MRVL、$CIEN。

我看到的高质量讨论，主要集中在 5 条线。

第一条：AI 数据中心的连接瓶颈开始被重新定价。

很多讨论都在讲同一个底层变化：

GPU 集群越来越大，机柜密度越来越高，数据在芯片、服务器、机柜之间高速流动。

传统铜连接在距离、功耗、发热上开始吃力。

所以市场重新看光互联、CPO、800G、1.6T。

@Ariston_Macro 和 @WealthCode99978 都把这个逻辑拆到了 InP：

光互联需要激光器、调制器、探测器这些主动光器件，而 InP 是其中非常关键的材料。

原帖：
https://x.com/Ariston_Macro/status/2065101015670743322
https://x.com/WealthCode99978/status/2065540793629061632
https://x.com/WealthCode99978/status/2065805041420677228

这说明市场不只是在买“光模块”三个字。

它开始往上游追：

谁有 InP？

谁有激光器？

谁有外延、衬底、PIC、封装和测试能力？

第二条：InP 成了这轮讨论的关键词。

过去 72 小时里，InP 相关讨论特别密。

@LIWEI_TWCapital 提到 VPEC 对客户通知 Epi Wafer 涨价，尤其是 AI optical 相关的 InP-based wafer。

讨论里同时提到 Rubin、CPO、800G/1.6T，以及 InP 供应紧张。

@wallstengine、@ParadisLabs、@aleabitoreddit 也都把中国 InP 出口审批 / 控制和 AI 数据中心 buildout 联系起来。

这条线里，市场反复提到：

$AXTI、$LITE、$COHR、$AAOI、$SIVE、$NOK。

原帖：
https://x.com/LIWEI_TWCapital/status/2065320470615130137
https://x.com/LIWEI_TWCapital/status/2064925639124353024
https://x.com/LIWEI_TWCapital/status/2064918463064519106
https://x.com/wallstengine/status/2064942274266775718
https://x.com/ParadisLabs/status/2065510031773061331
https://x.com/aleabitoreddit/status/2064942505553170886

这条线最重要的不是“哪个小票最猛”。

而是市场开始把光通信拆成供应链问题：

材料卡在哪里，涨价在哪里，出口限制在哪里，谁最接近瓶颈。

第三条：800G / 1.6T 的供需紧张，开始从财报电话会里被拼出来。

@KawzInvests 做了一件很有价值的事：

他把 800G 和 1.6T 供应链上的 earnings call 过了一遍，试图拼出真实的供需关系。

其中一个关键点是，$LITE 管理层提到需求明显超过出货能力。

这类讨论的价值在于，它不是只看股价。

它在问：

800G/1.6T 这一轮，到底是短期情绪，还是订单和产能真的跟不上？

另外，中文讨论里也有人把瓶颈进一步拆到泵浦激光器，认为 1.6T 对部分上游环节的需求会显著高于 800G。

原帖：
https://x.com/KawzInvests/status/2065886285160444225
https://x.com/tuolaji2024/status/2065658382934294744

这条线会影响 $LITE、$AAOI、$FN、$CIEN、$COHR，也会影响更上游的材料和设备公司。

第四条：市场不是一致看多，分歧集中在“CPO 什么时候兑现”。

这是这轮讨论里很关键的一点。

光通信不是没有争议。

@cherryPayment 讨论的是，市场被一篇偏情绪重置的报告影响后，很多光学相关股票一起下跌。

他的核心分歧点是：

“CPO 推迟到 2027”这种说法可能过于粗糙。

更准确的问题不是 CPO 有没有延迟，而是不同环节什么时候兑现收入，哪些公司先受益。

@ParadisLabs 对 $SIVE 的讨论更谨慎。

他不是简单看空，而是在提醒：信息发现优势和前瞻 bull narrative 可能已经被部分定价，真正要看的是 Sivers 在 CPO / ELS / 未来供应链里的实际卡位。

原帖：
https://x.com/cherryPayment/status/2064945251408568486
https://x.com/ParadisLabs/status/2065058856909131778
https://x.com/cherryPayment/status/2065074258485575959

这条线很重要。

因为它说明市场不是在无脑买光通信。

它开始区分：

概念、订单、产能、良率、时间表、客户导入，哪个已经发生，哪个还只是叙事。

第五条：资金开始往“更靠近瓶颈”的层级找。

@SpermCapital 把 CPO 产业链拆成几层。

他的核心问题不是“谁做了 CPO”，而是哪一层的壁垒更硬，钱会留在哪一层。

@Michael_QQQ2025 则把视角放到 $NOK / Infinera。

讨论重点不是传统光模块业务，而是 InP PIC 平台、垂直整合和材料/芯片层面的稀缺性。

@crux_capital_ 也在补充 InP substrate 的细节，尤其是 $AXTI 和 $COHR 相关的供应链关系。

原帖：
https://x.com/SpermCapital/status/2065111400297759210
https://x.com/Michael_QQQ2025/status/2065322393242042879
https://x.com/crux_capital_/status/2065071647456141655
https://x.com/crux_capital_/status/2065362722238365828

所以我觉得这轮光通信讨论，真正有用的结论是：

市场正在从“AI 算力 = GPU”往外扩。

先扩到网络。

再扩到光模块。

再扩到激光器、InP、外延片、衬底、PIC、封装和测试。

第一阶段，市场买的是 AI 光通信这个大词。

第二阶段，市场会问谁最接近瓶颈。

接下来真正要看三件事：

1. 800G / 1.6T 需求是否继续从 earnings call 和客户订单里被验证。
2. InP、泵浦激光器、EML、ELS 这些上游环节的涨价和供应紧张是否继续扩散。
3. CPO 的时间表是被推迟，还是部分环节先兑现收入。

如果后面只是所有光通信票一起涨，那它更像情绪交易。

如果资金开始顺着产业链往上找真正的瓶颈，光通信才会从“AI 概念分支”变成一条更清晰的主线。

这不是涨跌预测。

这是过去 72 小时高质量讨论给出的地图。
