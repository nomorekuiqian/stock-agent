# for_you module

Pure aggregation layer that reads from brew/portfolio/profile to produce the Action Bar.

- **No DB tables** — ActionBar is a derived view computed on each request.
- **No Insforge writes** — only reads existing data via portfolio DB and shared data_tools.
- **Access control** — `GET /api/for-you/action-bar` requires Bearer auth plus `for_you_website` entitlement. Frontend locked previews are not a backend security boundary.
- Inputs: digest data (brew), holdings + profile (portfolio), top_event (U1-A, optional), health (U1-B, optional).
- Output: `ActionBar` with severity (green/yellow/red), headline, and up to 3 action chips.
- V1 uses template-based headlines only; `source` field supports future LLM integration.

## 文件结构

| 文件 | 职责 |
|------|------|
| `router.py` | `GET /api/for-you/action-bar`，Bearer + `for_you_website` entitlement gate |
| `service.py` | Action Bar 聚合与 legacy rule-engine helper |
| `models.py` | ActionBar / ActionChip Pydantic models |
| `action_items.py` | Agent action items whitelist 和路由目标校验 |
| `templates.py` | V1 template-based headline/chip 文案 |

## V2 round 2 changes (2026-04-25)

- `build_action_bar` no longer drives chips from drawdown/staleness/health rules.
- All chips come from `digest.action_items` (agent output) after whitelist
  validation in `action_items.py`. Legacy rule-engine functions remain in
  service.py as dead code — do not import from them.
- `ActionBar.visibility` signals the frontend to hide the entire component on
  quiet days (no chips + no portfolio_summary).
- `ActionChip.target` is the source of truth for routing; `link` is a legacy
  fallback URL populated server-side for backwards compat.
- Frontend `DigestInlineReport` accepts a `variant: 'v1' | 'v2'` prop so the
  new "给你的复盘笔记" layout is gated to V2 callers only; V1 keeps the legacy
  总结-at-bottom placement. Cleanup when `for_you_v2` ships 100%: drop the
  prop and delete the V1 branch (see
  `docs/superpowers/plans/2026-04-25-for-you-v2-round2-flag-review.md`).

## 可恢复功能暂停（2026-09-04）

Action Bar 不再显示 target=health 的动作，含历史简报产生的动作。个性化简报、手动股票列表和持仓编辑继续保留。
