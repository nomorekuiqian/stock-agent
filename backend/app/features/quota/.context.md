# Quota Module

Research AI usage quota tracking.

## Purpose

Rate-limit free/anonymous/Pro users to 5 AI questions per day across all research conversations. Max subscribers get unlimited access.

## Files

- `service.py` — `check_quota()` / `consume_quota()` business logic
- `db.py` — Insforge Edge Function calls for `research_quota` table

## Data Flow

`screener/router.py` -> `quota/service.py` -> `quota/db.py` -> Insforge `research-quota` Edge Function

## Quota Rules

- Anonymous (no auth): 5/day, tracked by IP via `X-Forwarded-For`
- Free / Pro users: 5/day, tracked by user_id
- Max subscribers: unlimited (checked via `payment/db.get_subscription`)
- Daily reset at midnight UTC
- Fail-open on DB errors (allow request if quota DB is unreachable)
