# Quota Module

Research AI usage quota tracking.

## Purpose

Rate-limit free/anonymous/Pro users to 2 AI questions per day across all
Research and KOL Research conversations. Users with Max research entitlement
get unlimited access.

## Files

- `service.py` — `check_quota()` / `consume_quota()` business logic; unlimited access is checked entitlement-first
- `db.py` — Insforge Edge Function calls for `research_quota` table

## Data Flow

`screener/router.py` and `kol_research/router.py` -> `quota/service.py` ->
`quota/db.py` -> Insforge `research-quota` Edge Function

## Quota Rules

- Anonymous (no auth): 2/day, tracked by IP via `X-Forwarded-For`
- Free / Pro users: 2/day, tracked by user_id
- Users with `ai_research_engine` entitlement: unlimited
- Lifetime users inherit Max entitlements and are unlimited
- Legacy/dev Max rows without synced entitlements still get unlimited when `plan=max` and `status=active`
- Daily reset at midnight UTC
- Fail-open on DB errors (allow request if quota DB is unreachable)
