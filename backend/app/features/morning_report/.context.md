# Morning Report - 盘前早报

## 功能概述

每日盘前生成 AI 驱动的市场早报，面向美股投资者。定位为"战前简报"（3-5 分钟扫读），与日报（收盘后深度分析）互补。核心数据维度：期货、全球市场、隔夜新闻、今日焦点。使用 Gemini Pro 分析盘前数据，输出结构化中文报告。按日缓存，同一天重复请求直接返回缓存。

## API 端点

| 端点                               | 方法 | 描述                                 | 认证          |
| ---------------------------------- | ---- | ------------------------------------ | ------------- |
| `/api/morning`                     | POST | 生成/获取当日早报                    | Bearer        |
| `/api/morning/broadcast`           | POST | 广播早报到 daily_report 受众         | X-Cron-Secret |
| `/api/morning/latest`              | GET  | 只读获取当日缓存早报，无缓存返回 404 | 无            |
| `/api/morning/reports`             | GET  | 历史早报列表 (分页: limit + offset)  | 无            |
| `/api/morning/reports/latest`      | GET  | 获取最新一篇早报 (不限日期)          | 无            |
| `/api/morning/reports/date/{date}` | GET  | 按日期获取早报 (YYYY-MM-DD)          | 无            |
| `/api/morning/reports/{report_id}` | GET  | 按 UUID 获取早报                     | 无            |

**POST 请求参数**: `{ "force": false }` -- `force=true` 强制重新生成

**GET /api/morning/reports**: 分页参数 `limit` (1-100, 默认 20) + `offset` (默认 0)。返回 `{ data, total, limit, offset }`。

**响应结构**:

```json
{
  "title": "简短中文标题",
  "market_pulse": "一句话市场展望",
  "futures": [{"name", "value", "daily_change"}],
  "global_markets": {
    "asia": [{"name", "value", "daily_change"}],
    "europe": [{"name", "value", "daily_change"}],
    "other": [{"name", "value", "daily_change"}]
  },
  "overnight_news": [{"title", "analysis", "url?"}],
  "today_focus": [{"title", "analysis", "time?"}],
  "summary": [{"title", "content"}],
  "market_data": {},
  "from_cache": true,
  "report_id": "uuid",
  "timestamp": "ISO-8601"
}
```

## 数据流

```
POST /api/morning
  |
  +-- 检查缓存 (DB 按日期查询, ET 时区)
  |   +-- 命中且当天 -> 直接返回
  |   +-- 未命中/force=true -> 生成新报告
  |
  +-- MorningReportAgent.analyze()
  |   +-- 并行获取: 盘前数据 + 新闻 + 经济日历 + 财报日历
  |   +-- 加载最近 5 篇历史早报 (叙事连续性)
  |   +-- 数据清洗 (日历/财报只保留今天)
  |   +-- Gemini Pro 生成结构化报告
  |   +-- 后处理: article_id -> 真实 URL
  |
  +-- 保存到 DB (按日期 upsert)
  +-- 返回响应
```

## 关键业务逻辑

### 与日报的区别

| 维度     | 早报                     | 日报                         |
| -------- | ------------------------ | ---------------------------- |
| 时间     | 盘前 8:00 AM ET          | 收盘后                       |
| 阅读量   | 3-5 分钟                 | 10-15 分钟                   |
| 核心数据 | 期货、全球市场、隔夜新闻 | 收盘数据、全天新闻、深度叙事 |
| 语言     | 中文                     | 中文                         |
| 缓存键   | ET 时区日期              | Pacific 时区日期             |

### Agent 指令核心规则

- 身份: 盘前简报分析师，3-5 分钟阅读量
- futures/global_markets: 从输入数据复制真实数值，不编造
- overnight_news: 3-5 条，从输入新闻中选，每条 title + 1-2 句 analysis
- today_focus: 3-6 条混合型 (经济数据/财报/新闻)，按重要性排序
- summary: 两节 -- "overnight_review" + "today_outlook"
- 叙事连续性: 如果有 previous_reports，放入过去几天的脉络中

### URL 解析机制

与日报相同的 article_id -> 真实 URL 映射机制，用于 overnight_news 的 url 字段。

### 数据清洗 (\_prepare_data_for_morning_agent)

- 经济日历: 只保留今天的事件
- 财报日历: 只保留今天的，保留 time 字段 (BMO/AMC)
- 新闻: 复用日报的垃圾过滤逻辑 + article_id 机制
- 附加 5 篇最近早报用于叙事连续性

## 邮件广播

- 订阅频道: `daily_report`（与日报共享同一受众 TheMarketBrew Daily）
- 广播端点: `POST /api/morning/broadcast?force=true`
- GitHub Action: `.github/workflows/morning-report.yml`，UTC 12:00 (ET 8:00 AM) 周一至周五
- 邮件模板: 独立 HTML 模板 (期货 grid + 全球市场表格 + 新闻 + 焦点 + 总结)

## 注意事项

- Agent 是单例模式，模块生命周期内复用同一个 MorningReportAgent 实例
- DB 操作全部走 Edge Function HTTP 调用，不是直接 SQL
- 缓存使用 ET 时区判断"今天"（与日报的 Pacific 时区不同）
- router.py 使用模块级 `morning_agent` 单例，而非 lazy import

## 可靠性保障

### Agent 错误处理

- `MorningReportAgent.analyze()` 外层 `except` 返回 `None`（不返回假成功数据）
- 调用方（router.py）检查返回值为 `None` 时返回 500

### 广播质量门禁

- `_is_morning_report_valid(data)` 检查 title、overnight_news、summary 三个必填字段
- 广播前必须通过质量门禁，防止空报告/错误报告发送给用户
- 2026-03-02 事件：Gemini API 故障导致 agent 返回空内容，质量门禁可拦截此类问题

### 测试覆盖

- 8 个单元测试覆盖 `_is_morning_report_valid` 各种边界情况
- 5 个 E2E 测试覆盖广播端点：认证、质量门禁拒绝、正常广播
