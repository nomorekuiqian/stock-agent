# Memory / Feedback Module

## Purpose

Owns the lightweight memory endpoints around runtime feedback compatibility and
suggestion outcome tracking. Runtime assistant thumbs up/down are stored on
`agent_session_events`; this module keeps the public `/api/feedback` endpoint
that routes Research/KOL answer feedback into that runtime store.

## Architecture

- **router.py** — `POST /api/feedback`, `GET /api/suggestion-tracking/recent`
- **service.py** — `get_user_memory()` aggregation (<=1050 tokens)
- **db.py** — Insforge Edge Function wrapper (`memory` EF) for suggestion tracking
- **outcome.py** — Pure function `compute_outcome()` for T+7 evaluation
- **models.py** — Pydantic schemas

## Tables

- `suggestion_tracking` — health check suggestion follow-ups
- `ai_feedback` — retired by `u4c_drop_ai_feedback.sql`; do not recreate it.

## Feedback Targets

`POST /api/feedback` accepts per-message feedback from `/research` assistant and
KOL assistant answers. `sentiment` uses `1` for thumbs up, `-1` for thumbs down,
and `0` to clear the user's previous choice. Requests with `target_type =
research_agent_answer` and runtime identifiers are routed to the Agent Runtime
store and update the matching `agent_session_events` `assistant_message` row
using `session_id` + `agent_id` + `turn_id` / `client_event_id` /
`message_event_id`. `sentiment: 0` sets `feedback_sentiment` and
`feedback_reason` back to `null`. The answer preview and UI metadata are stored
in that row's `feedback_payload`. Legacy non-runtime feedback targets are
accepted for compatibility but ignored; they are no longer persisted.

## Cross-feature Dependencies

- Reads `portfolio.db.list_portfolio()` for thesis data
- Memory block is not currently wired into active agents; keep it limited to
  thesis and suggestion tracking if reused.

## Key Constraints

- All DB failures degrade gracefully (return empty, never crash)
- `get_user_memory()` total <= 1050 tokens (~2100 chars)
- Feedback POST always returns 200 (even if DB not deployed)
- All user-facing text in Chinese
