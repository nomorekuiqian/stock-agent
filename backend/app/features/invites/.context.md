# invites feature context

## 功能概述

Freemium 转型后（见 `docs/constraints/subscription-model.md`）, 邀请码 / 自动试用
机制已退役. 本模块现在只承担两件事:

1. **/redeem, /auto-trial** — 维持 410 Gone, 防止旧客户端崩
2. **/request, /qualify** — 收集"申请访问"问卷数据 (落 access_requests 表)

新用户注册不再自动开 14 天 Max trial, 也不再消费邀请码.

## API 端点

| 路由 | 方法 | 认证 | 当前行为 |
|------|------|------|------|
| `/api/invites/redeem` | POST | Bearer | **410 Gone** `redeem_deprecated` |
| `/api/invites/auto-trial` | POST | Bearer | **410 Gone** `auto_trial_deprecated` |
| `/api/invites/request` | POST | Public | 接受申请表单, 通过 Resend 发欢迎邮件 (不含 trial 承诺) |
| `/api/invites/qualify` | POST | 可选 Bearer | 落库问卷答卷, 返回 INVITE_CODES[0] (历史兼容; 实际无激活作用); 可选 `source` 用于 PostHog 归因 |

## 数据库字段

`subscriptions.invite_code` / `access_expires_at` 仍然保留, 为以下两类用户服务:
- 转型前的活跃 trial 用户 — 走完剩余天数后 entitlements 自然清空
- Admin 手动赠送 (CRM `/api/admin/users/:id/grant-subscription`) 仍可写这两个字段

新注册用户写不进 (没有 create_trial_subscription 调用路径).

## 相关文件

- `models.py` — Pydantic 模型 (`RedeemInviteRequest` / `AccessRequestInput` / `QualifyInput` / `QualifyResponse` 等; `AutoTrialResponse` 留作历史兼容)
- `db.py` — 只剩 `save_qualify_response()`. `create_trial_subscription()` 已删除.
- `router.py` — 路由实现; redeem / auto-trial 返回 410.
- `../payment/db.py` — `upsert_subscription()` 仍支持 `invite_code` / `access_expires_at` (admin 赠送)
- `../subscription/cta_tier.py` — `is_real_paid_sub()` 不再读 `access_expires_at`, 只看 `entitlements` + `is_lifetime`

## isPro 判断逻辑

```
isPro = plan in ('pro', 'max') AND status === 'active'
        AND (access_expires_at IS NULL OR access_expires_at > NOW())
```

付费订阅 `access_expires_at` 为 null. 仅剩遗留 trial / admin 赠送会带具体日期.

## 依赖关系

- `app.core.deps.verify_user_token` — /redeem, /auto-trial 仍要求 Bearer (即便返回 410)
- `app.core.deps.get_optional_user_email` — /qualify 获取可选 email
- `app.core.config.INVITE_CODES`, `RESEND_API_KEY` — /request, /qualify 仍读取
