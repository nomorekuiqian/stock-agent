# Payment 模块

## 功能

Stripe 订阅支付 + Entitlements 权限管理。Stripe 是唯一真相源，Insforge `subscriptions.entitlements` 列是派生缓存。

## 架构 (四层数据流)

```
Layer 1: Stripe (真相源)
  Customer → Subscription → Active Entitlements (10 个 feature)
       |
       | webhook: entitlements.active_entitlement_summary.updated
       v
Layer 2: Insforge subscriptions 表 (快速读缓存)
  entitlements JSONB 列 + 5 分钟内存 TTL
       |
       | 同一 webhook handler 顺序写
       v
Layer 3: Resend Segments (发送缓存)
  sync_resend_segments(email, entitlements) — 唯一写入点
       |
       v
Layer 4: Frontend EntitlementsContext
  has(feature) 判断，PaywallGuard requiredFeature
```

## API 端点

| 端点 | 方法 | 认证 | 描述 |
|------|------|------|------|
| `/api/payment/checkout-session` | POST | Bearer | 创建 Stripe Checkout Session |
| `/api/payment/subscription-status` | GET | Bearer | 查询用户订阅状态 |
| `/api/payment/me/entitlements` | GET | Bearer | 查询用户 feature entitlements (`?fresh=true` 旁路缓存) |
| `/api/payment/portal-session` | POST | Bearer | 创建 Stripe 管理 Portal |
| `/api/payment/sync` | POST | Cron | 手动同步 Stripe 订阅 |
| `/api/payment/webhook` | POST | Stripe Signature | Webhook 回调 |

## 文件结构

- `router.py` — 路由 + Webhook (checkout.session.completed / subscription.updated / subscription.deleted / entitlements.active_entitlement_summary.updated)
- `entitlements.py` — Entitlements Gateway (`has_entitlement` / `get_user_entitlements`，只查 entitlements 列，无 fallback)
- `service.py` — Stripe API 封装 (checkout / portal / customer 管理)
- `models.py` — Pydantic 模型
- `db.py` — subscriptions Edge Function 操作 + 缓存 + `get_subscription_by_customer`

## 依赖

- `stripe` SDK (同步调用通过 `asyncio.to_thread` 包装)
- Edge Function: `subscriptions` (get / get_by_customer / upsert)
- 环境变量: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRO_PRICE_ID`, `STRIPE_MAX_PRICE_ID`

## 注意事项

- entitlements webhook 是权限变更的唯一入口，customer.subscription.* handler 只同步 identity (sub_id, status, period_end)
- `has_entitlement()` 无 fallback — entitlements 列为空则无权限
- Checkout success_url 指向 `/pricing/success`，前端用 `?fresh=true` 旁路缓存确保即时生效
- 邀请码兑换通过 Stripe Trial Subscription 实现，到期自动 cancel + webhook 清权限

## Lifetime 终身用户

`subscriptions.is_lifetime: true` 的用户绕开整条 Stripe 链路：
- 三处 webhook (`subscription.deleted` / `subscription.updated` / `entitlements.active_entitlement_summary.updated`) 进入函数后先读 sub，is_lifetime=true 直接 return，不写库
- `has_entitlement()` / `get_user_entitlements()` 检测 is_lifetime=true 时直接返回完整 MAX_FEATURES（双保险，即使 entitlements 列被意外清空也不影响）
- 开通工具：`python -m scripts.grant_lifetime <email>`（`--revoke` 取消）
- DB 字段：`is_lifetime BOOLEAN DEFAULT FALSE`
- 设计文档：`docs/plans/active/lifetime-max-system.md`
