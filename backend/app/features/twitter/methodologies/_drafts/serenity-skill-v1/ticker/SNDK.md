# Ticker: SNDK

## 公司或产业是什么

**SanDisk** (NASDAQ: SNDK) — NAND flash 存储公司. 经历过大幅涨幅(2025-2026), 但 Serenity 明确称其为 **"meme stock"**, 不是核心结构性持仓.

## 她看什么信息

- NAND 周期性供需
- 2D NAND 短缺 (2026-05 新瓶颈, 但 SNDK 不一定主受益)
- 财报盈利波动

## 她如何理解

### 明确称为 "meme stock"

> "Nobody can convince me $SNDK isn't a meme stock at this point. But as I've said, bottlenecks with multi-year visibility like $HPS.A or $LITE tend to perform better." (id: 2052784100784922983, 2026-05-08)

她明确把 SNDK 归为**短期 cycle / meme** 而非 multi-year visibility bottleneck.

### 在瓶颈迁移路径中是中间节点

```
GPU (NVDA) → HBM (MU) → 电力 (IREN) → EML (LITE) → 内存 (SNDK) → ...
```

SNDK 在她的瓶颈链条中是一站, 但不是 chokepoint.

### Q3-Q4 ratings 中常出现

她在 Friday Market Close ratings 中 SNDK 偶尔出现 Hold 或 Buy, 但很少 Strong Buy.

## 决策框架

| 信号 | 操作 |
|---|---|
| NAND 周期性涨价 | Hold (不重仓) |
| 2D NAND 短缺持续 | medium (但她明确归为 meme cycle) |

## 减仓与轮动信号

1. **NAND 周期反转**
2. **HBM4 / HBM5 / 玻璃基板 HBM ramp** → 更上游有更好选择

| 误读 | 实际 |
|---|---|
