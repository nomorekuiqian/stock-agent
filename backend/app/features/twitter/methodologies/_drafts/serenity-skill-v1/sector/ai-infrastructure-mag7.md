# Sector: ai-infrastructure-mag7

## 适用问题

- 「她怎么看 NVDA / GOOGL / MSFT / META / AMZN / AVGO / MRVL / TSM?」
- 「Mag7 AI 持仓里她最看好哪个?」「定制 ASIC 会不会替代 NVDA?」
- 「TPU v7 / Trainium / MAIA 谁受益最大?」

## 核心问题

**Mag7 anchor 在 Serenity 的体系里是"配置型"还是"重仓"? 谁的 BOM 漏斗外溢最大?**

## 公司或产业是什么

**Mag7 AI 算力 anchor**: Mag7 自己的算力 cap-ex 是整个 AI 漏斗的源头. 她不重仓 Mag7 本身, 但用它们作为 anchor 配置:

- **NVDA** (Blackwell, Rubin, Vera Rubin) — GPU 主线; 她持仓 anchor 但不是核心重仓
- **GOOGL** — TPU v7 Ironwood + Gemini + Waymo + Suncatcher; "AI search drop $170 → $144 → $257" (恢复 case)
- **MSFT** — Azure AI + MAIA 300 ASIC ($17B with NBIS deal)
- **META** — Llama + MTIA ASIC ($14B with CRWV, $3B with NBIS); "Fire Sale" 列表常客
- **AMZN** — AWS + Trainium v3/4 + Alchip 合作; FSD Zoox
- **TSM** — 整个 AI 半导体 backbone, "next center of every AI thing"
- **AVGO** — 定制 ASIC 设计 (GOOGL TPU + MSFT MAIA + AMZN Trainium); 但她有"竞争被 MRVL 抢"的 worry
- **MRVL** — Maia ASIC 主受益方; UBS est. 1M+ Maia by 2027 → $8-12B revenue

## 她看什么信息

- **Mag7 财报 cap-ex 指引数字** (反复加仓的依据)
- **定制 ASIC ramp 时间表** (GOOGL TPU v7, MSFT MAIA 300, AMZN Trainium v3/4)
- **NVDA Blackwell / Rubin / Vera 量产时间表**
- **Mag7 与 Neocloud 签的 GW 容量合同**
- **TPU / Trainium / MAIA 的 BOM 供应商**
- **AVGO vs MRVL ASIC 竞争**

## 她如何理解

### Mag7 是 anchor 不是 alpha

她明确把 Mag7 当 anchor:

> "I entered $ALAB, $NBIS, $TSM, and $LITE because of Mag7 funneling revenue numbers into them." (id: 1999240464420250042, 2025-12-11)

Mag7 是"漏斗起点", 真正的 alpha 在漏斗下游小盘. NVDA / META / MSFT 在 ratings 里出现频繁, 但单仓位 % 远低于 NBIS / SIVE / AXTI.

### 定制 ASIC 是 NVDA 的中期威胁

> "Nvidia ( $NVDA ) reported a blowout Q3 FY2026 revenue. Despite that, the stock dropped 12%. $GOOGL TPU's progress threatens NVDA pricing power long-term." (id: 1994555219607523362, 2025-11-28)

她明确指出 NVDA 长期面临定制 ASIC 替代风险. 短期仍持有, 但仓位 < TPU / Trainium / MAIA 链的供应商 (LITE / AAOI / AVGO / MRVL).

### MRVL > AVGO (在 Maia 链上)

她对 MRVL 的看好基于 BOM 分析:

> "Marvell is modeled to take in $10-12B in revenue (~30-40% margin) as prime beneficiary of Maia ASIC ramp." (id: 2006301094394335399, 2025-12-31)

MRVL 在 MAIA ASIC 上比 AVGO 受益更大, 因为 MRVL 设计 + 协助 + IP 比例更高.

### TSM 是"半导体 backbone"

> "TSM blowout earnings as expected. They're the center of the whole Neocloud trade and AI Buildout. TSM is easily going to $450+ with 46% EPS y/y." (id: 1978716322453492060, 2025-10-16)

TSM 是她 5 年 anchor 持仓, 不轮出. 她从 $120 一直持到 $400+.

### TPU v7 Ironwood 供应链她明确画过

```
Critical Design/IP: AVGO (co-designs TPU ASIC)
EML 激光独占: LITE
封装: AMKR
内存: SK Hynix + Samsung
代工: TSM
光纤连接: AAOI (部分)
```

## 减仓与轮动信号

1. **定制 ASIC 全面替代 NVDA**: 概率低但实质风险, 减 NVDA 加 MRVL
2. **TSM 政治 / 地缘风险**: 台湾局势恶化 → TSM 流动性差
3. **Mag7 cap-ex 转向 in-house data center**: 但 cap-ex 已经超过自家容量, 短期不可能逆转
4. **NVDA Blackwell 量产失败 / 跳票**: 已避免, Rubin 接力

## 常见误读

| 误读 | 实际 |
|---|---|
| NVDA 是她重仓 | 她 anchor 配置, 不是核心重仓 (NBIS / SIVE / AXTI 才是) |
| Mag7 全要买 | 她明确区分 anchor (TSM / GOOGL) vs 不太喜欢 (Apple 几乎不持仓) |
| AVGO > MRVL | 她在 Maia 上明确 MRVL > AVGO |
| TPU 替代 NVDA | 短期不会, GOOGL 自己也用 NVDA; 但长期定价权转移 |

## 回答注意

- 先说明 Mag7 是 AI capex 漏斗的 anchor 和方向验证器,不是 Serenity 小盘 alpha 的全部来源。
- 问 NVDA / AVGO / MRVL / hyperscaler 时,重点解释它们在定制 ASIC、光互连或 capex 外溢中的角色。
- 显式判断当前变化压的是估值、验证,还是逻辑;不要把 anchor 配置翻译成追逐大盘龙头。
- 分清 Serenity 历史配置、当前数据和方法推断,尤其不要把 5+ 年长持写成今天的买卖指令。
