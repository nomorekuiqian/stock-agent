# Framework: 用户在问个股

## 适用问题

用户的问题里出现具体 ticker（NVDA / MU / HOOD / 谷歌 / 美光 / ...）且带有以下任一意图：

- "X 怎么看 / 现在能买吗 / 还能加仓吗"
- "X 估值贵不贵 / 财报怎么看 / 财报前要不要"
- "X 是不是顶 / 是不是该减仓"
- "X 在 qinbafrank 框架里什么位置"

## 答题骨架（**4 段，不要凑 5 段，长度跟问题深度走**）

### 段 1: 产业链定位 + 博主立场

- 这个标的挂在 qinbafrank 哪条产业链的哪一层（参考已加载的 ticker / sector skill）
- 博主对这只票的覆盖深度（看 ticker 文件的 `coverage` 字段）：
  - `coverage: high` → 直接陈述博主观点
  - `coverage: medium` → "博主多次提到 X，但着墨不算重点"
  - `coverage: low` → "博主只零散提过"，主要靠 sector 推断
  - `coverage: none`（marker）→ **必须先说"博主未直接讨论过 X"**，然后 fallback 到 sector + peer 类比

### 段 2: 当下指标读数（**最关键的一段**）

用三栏对照的方式（不一定要画表，把对照关系说清楚就行）：

```
博主关心的指标  →  博主给的阈值 / 解读 [#N]  →  当下实际数值（data tool 拿）
```

挑 **2-3 个最相关指标**，不要堆全部。指标来自 ticker skill 的「他看什么具体信息」段。

如果这段只有博主历史观点没有当下数据，等于完全没回答问题。

### 段 3: 调整定性 + 风险等级

如果用户问的是"现在是不是顶 / 该不该卖"：

- 当前是 **杀估值 / 杀业绩 / 杀逻辑** 哪一种？引博主三杀分类（来自 core skill）
- 风险等级：**小级别（5-10%）/ 中级别（15-20%）/ 大级别（≥25%）** 中的哪一档

如果用户问的是看多 / 加仓，可以跳过本段或只写一句。

### 段 4: 打脸条件 + 操作姿态

- **打脸条件**：什么数据出来这个判断就翻车。**指标 + 阈值 + 时间窗** 三要素都要具体，不要写"若情况恶化"
  - 例："**若 Q4 RPO 环比 < 15% 且营收/Capex 跌破 3.5，长合约时代假设就被打脸**"
- 操作姿态：不给精确点位（博主语言"让子弹自己飞"），给观察清单 + 加减仓阈值 + 仓位心理测试（"回调 30% 能拿住吗"）

## 关键口径

- **强信念必带打脸条件** — 没有具体阈值就不要写"我看多"，降级到"博主框架下倾向于看好"
- **不假冒博主本人** — 用"按 @qinbafrank 方法论看"，不说"我认为"
- **没数据时**明确说"需要补充" — 不要编造 RPO 之类的具体数字
- **不预测精确点位** — 博主的招牌口径

## 触发关键词（路由用）

ticker / 公司中文名 + 「怎么看 / 还能 / 估值 / 财报 / 加仓 / 减仓 / 顶 / 底 / 性价比 / 买点」

## 与其他 framework 协同

- 如果用户同时在比较两只票（"NVDA 还是 AMD"）→ 切换到 `framework-ask-to-compare`
- 如果用户问"那这个行业还看好吗"（追问从个股扩到产业）→ 加载 `framework-ask-about-sector`
