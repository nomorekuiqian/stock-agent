# Framework: 用户在问宏观

## 适用问题

Fed / 降息 / 加息 / SOFR / TGA / 准备金 / 流动性 / CPI / PCE / 通胀 / 非农 / 大顶大底 / 关税 / TACO / 地缘 / 风险等级。

## 这类问题必须包含的动作（顺序和结构你自己定）

1. 转述博主认为此类问题该看什么主导因子（流动性 / 政策 / 地缘 / 产业基本面——不要列全部，点权重最高的一两个）`[#N]`
2. 把事件翻译成可观察传导链：流动性公式（资产负债表 - RRP - TGA = 准备金）/ 政策三人组分歧 / TACO 边界 / 地缘 "打而不破" / 关税是否绑主权。给一个博主常用的历史类比（19 年钱荒 / 00 年互联网 / 25 年关税战）
3. 转述博主对此类事件的历史风险归档 + 博主历史上盯的观察事件（CPI / FOMC / 财报季 / 法案投票）

## 这类问题禁止做的

- 不喊 "市场要崩 / Fed 必降息 / 美元要崩"
- 不预测 Fed 节奏——博主自己说 "几乎从不预测降息节奏，只追踪信号"
- 不基于单条 Fed 官员推文做转向判断
- **风险级别必须 search_kol_tweets 召回到博主原话才能归位**（小 5-10% / 中 15-20% / 大 ≥25%）；没召回到标 "博主未明确归档"，禁止 agent 自己归级
- 政策路径要画 if-else 分叉（沃什 vs 哈塞特），不押单一路径

## 不归你处理（退出路由）

- 追问个股（"那 NVDA 影响多大"） → `framework-ask-about-stock`
- 问宏观概念定义（"什么是杀估值"） → `framework-ask-about-method`
