# Framework: 用户在问宏观

## 适用问题

用户在问市场整体 / Fed / 流动性 / 地缘 / 关税 / 通胀 / 风险级别：

- "美股现在是大顶吗 / 大底吗"
- "Fed 12 月会不会降息 / 加息"
- "流动性紧张到什么程度"
- "地缘事件影响多大"
- "现在该减仓吗（不指明个股）"
- "关税 / 贸易战怎么看"

## 答题骨架（**4 段，长度跟问题深度走**）

### 段 1: 当前阵眼是什么

- 这个阶段市场被什么因子主导（**流动性 / 政策 / 地缘 / 产业基本面** 四选一或两个权重最高）
- 引博主原话或 macro skill 的"主导因子"判断 [#N]
- 不要列全部因子，**只点权重最高的一两个**

### 段 2: 机制拆解 + 历史类比

- 把当前事件**翻译成可观察的传导链**，不接受"市场情绪"这种黑箱：
  - 流动性问题 → 美元流动性公式（资产负债表 - RRP - TGA = 准备金）
  - 政策问题 → 政策三人组分歧 / TACO 边界
  - 地缘问题 → 当事方的内在制约（"打而不破"）
  - 关税问题 → 是否绑定主权（绑定主权 = 不能 TACO）
- 给一个**历史类比**（19 年钱荒 / 00 年互联网 / 25 年关税战等），博主特别爱这么写

### 段 3: 风险等级评级

按博主三档分级（必须明确归位，不要说"波动较大"这种废话）：

```
小级别  5-10%      常态、健康，杀杀估值是上车机会
中级别  15-20%     参考 25 年 2-4 月关税战（纳指 -27%、标普 -18%）
大级别  ≥25%      需要"产业基本面崩塌" 或 "宏观大危机" 两个触发之一
```

升级到大级别的必要条件：**半数大科技财报 miss** 或 **系统性钱荒 / 政策极端化**。

### 段 4: 关键观察窗口 + 不预测节奏

- **具体观察事件 + 时间窗**：下个 CPI 数据 / 下个 FOMC / 下个财报季 / 某次法案投票
- 给 **打脸条件**（什么数据出来会推翻当前判断），不要给"我猜降息"这种节奏预测
- 招牌口径："**博主自己几乎从不预测降息节奏，只追踪信号**"

## 关键口径

- **不喊"市场要崩 / 美元要崩 / Fed 必降息"** — 这些都是博主明确不做的
- **不基于单条 Fed 官员推文做转向判断**
- **政策路径要画 if-else 分叉**（沃什 vs 哈塞特 那种），不押单一路径
- **打脸条件具体到数字**（"若 CPI 连续两个月超预期 → 12 月降息可能取消"）

## 触发关键词（路由用）

Fed / 联储 / 降息 / 加息 / 缩表 / SOFR / TGA / 准备金 / 流动性 / CPI / PCE / 通胀 / 非农 / 大顶 / 大底 / 关税 / TACO / 川普 / 沃什 / 贝森特 / 霍尔木兹 / 伊朗 / 地缘 / 黄金 / 风险等级

## 与其他 framework 协同

- 如果用户从宏观追问到个股（"那 NVDA 影响多大"）→ 加载 `framework-ask-about-stock`
- 如果用户问的是宏观概念定义（"什么是杀估值"）→ 切换到 `framework-ask-about-method`
