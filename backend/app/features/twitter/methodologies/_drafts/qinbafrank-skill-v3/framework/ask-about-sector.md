# Framework: 用户在问产业 / 板块

## 适用问题

用户指向一个产业方向：AI 算力 / HBM / 稳定币 / 太空 / 国防 / 物理 AI / 电力 / SaaS / 经纪商 + "怎么看 / 还看好 / 阶段 / 受益"。

## 这类问题必须包含的动作（顺序和结构你自己定）

1. 转述博主对此产业的核心立场：主线叙事 + 博主在产业链上盯的瓶颈层（"瓶颈迁移"思维）`[#N]`
2. 转述博主点过名的受益方 + 反向风险标的（必须博主真说过，不让你自己提名）
3. 转述博主历史上盯的前瞻指标 + 博主提过的危机信号清单（例：AI 算力 4 条危机信号）

## 这类问题禁止做的

- 不替博主下 "产业看好 / 板块强 / 板块见顶"
- 不押应用层最终赢家——博主自己说 "短期看不出"
- 不喊 "AI 泡沫破"——除非博主 4 条危机信号已触发且 search_kol_tweets 召回到博主原话
- 不编博主没说过的受益标的

## 不归你处理（退出路由）

- 突然指向某只票（"那 NVDA 还能买吗"） → `framework-ask-about-stock`
- 切到宏观角度（"宏观逆风影响多大"） → `framework-ask-about-macro`
