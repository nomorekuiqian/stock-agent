# Framework: 用户在问产业 / 板块

## 适用问题

用户的问题指向一个**产业方向**而非具体标的：

- "AI 算力还看好吗 / AI 基建什么阶段"
- "加密 / 稳定币这块怎么布局"
- "太空经济 / 国防 / 物理 AI 是下一波吗"
- "纯软件 SaaS 会被 AI 替代吗"
- "电力是不是下一个 AI 卡脖子"

## 答题骨架（**4 段，长度跟问题深度走**）

### 段 1: 主线叙事是否仍成立

- 这个产业在博主"产业派"框架里的核心叙事是什么（来自 sector skill 的「核心问题」段）
- 当下哪些信号在验证 / 哪些在动摇
- 这条主线是不是属于 qinbafrank 长期看好的几个万亿赛道之一（AI 算力 / 加密金融基建 / 太空经济 / 物理 AI / Z 世代经纪商）

### 段 2: 当前卡脖子环节 / 价值捕获点

这是 sector 问题最差异化的一段。沿用博主"瓶颈迁移"思维：

- 当前产业链上哪一层最紧（GPU → HBM → 光互连 → 电力 → CPU 这类传导）
- 谁是不可替代的卡位（垄断 / 双寡头 / 三家分润 / 长合约锁定）
- 哪些环节正在被错杀但本质是硬需求（典型例：AI 颠覆论下的安全 / 数据软件）

### 段 3: 受益方分布 + 反向风险

- **受益方分级**（不要只点一家）：
  - 头部龙头（高确定性）
  - 卡脖子环节（高确定性，越靠近物理瓶颈越确定）
  - 非英伟达受益者 / 周边链（弹性大）
- **反向风险**：
  - 资本结构脆弱的玩家
  - 押注应用层最终赢家（博主自己不下注的）
  - 情绪化定价的"AI 颠覆受害者"中真正没护城河的

### 段 4: 打脸条件 + 时间窗

- 整个产业看好叙事的**打脸条件**（典型例：4 条 AI 危机信号清单 / 卡脖子环节集体扩产 / 长合约期限缩短到 3.8 年以下）
- 关键观察窗口：**下个财报季 / 政策节点 / 数据发布时间**

## 关键口径

- **不押注应用层赢家** — 博主自己说"短期看不出最终赢家"
- **赢家通吃 + 输家丢掉一切** — 这是博主对 AI 时代格局的招牌判断，可以引用
- **不喊"AI 泡沫破" / "板块见顶"** — 用 4 条危机信号清单对照，没触发就不喊
- **打脸条件用具体指标**，不要写"产业逻辑动摇"这种废话

## 触发关键词（路由用）

产业关键词（AI 算力 / HBM / 稳定币 / 太空 / 国防 / 物理 AI / 物理机器人 / 电力 / 数据中心 / SaaS / 经纪商）+ 「板块 / 链 / 还看好 / 布局 / 怎么看 / 阶段 / 受益」

## 与其他 framework 协同

- 如果用户突然指向某只票（"那 NVDA 还能买吗"）→ 加载 `framework-ask-about-stock`
- 如果用户切到宏观角度（"宏观逆风影响多大"）→ 加载 `framework-ask-about-macro`
