# Skill: AI Infrastructure

## 适用问题

- AI 算力 / 半导体 / GPU / HBM / 光模块 / 数据中心 / 电力相关
- NVDA / AMD / TSM / ASML / 美光 / SK 海力士 等 AI 基建链公司
- token 经济 / Agentic AI / 物理 AI / AI 商业化 / AI 是不是泡沫
- Colossus / Stargate / Mag4 capex / RPO 等大型基础设施项目
- 任何"AI 算力够不够" / "下一个卡脖子环节是什么"

## 核心问题

qinbafrank 把 AI 算力当作未来 5-10 年最重要的产业主线。本 skill 要回答的判断问题：

1. 当前 AI 产业链的卡脖子环节在哪一层？瓶颈在迁移吗？
2. 商业兑现（capex → 收入）的节奏 vs 折旧节奏，谁更快？
3. 哪些环节的护城河可以穿越供给周期？哪些是周期股伪装？

## 他看什么信息

### 核心硬指标

- **Token 消耗量增速** — Y/Y 倍数（谷歌 9.7T → 1300T /月，134 倍；字节 1200B → 16.4T /天，137 倍；OpenAI 60B → 150B /分钟，2.5 倍）
- **GPU / Blackwell 出货量** vs 市场预期（NVDA 2000 万 vs 预期 1500 万 → +30% 上修）
- **HBM 三家产能分配**：SK 57% / 三星 22% / 美光 21%
- **算力价格指数**（Ornn）：Blackwell 时租从 2.75 → 4.08 美元，两个月 +48%
- **数据中心建设周期**：电力容量预订情况
- **RPO 同比 / 环比**：微软 4000 亿 RPO 增 50%+；**RPO 环比 < 8% 是经典证伪线**
- **Mag4 capex 占自由现金流比例**：26 年 6500 亿 ≈ 吃掉一年 FCF
- **营收/Capex 比值**：FY25 ≈ 4.0；< 3.5 时产能爬坡跑不赢折旧；>3.8 拐点至少推迟到 2028H1
- **加权平均合约剩余期限**：延长至 5.0 年以上 = 长合约时代；缩短至 3.8 年以下 = 短合约回流

### 产业链层次（L0 → L5）

```
L0 算力底座      NVDA  TSMC  ASML（产业链中间收租）
L1 关键组件      HBM (SK / 三星 / MU)、光模块、CPO、CPU (INTC / AMD / ARM)、NAND
L2 数据中心/云   Mag4 capex、CRWV、NBIS、ORCL
L3 电力/物理基建  变压器、冷却、核电、地热

```

## 他如何理解

### Step 1 定位产业链层次

不同层有不同的判断逻辑和估值锚。问的第一件事是"这只票挂在哪一层"。

### Step 2 量化 token 消耗作为基本面证据

> 用电力的视角去看算力，而不是电缆的视角去看算力。电力发明一百多年了、今年各国的电力消耗还在快速上升。

这是核心思维框架。token 消耗指数级增长是 AI 商业落地的硬证据。

### Step 3 评估卡脖子环节的迁移

```
2024  GPU 短缺
2025  HBM 卡脖子
2026 初  电力卡脖子（Blackwell 时租 2.75 → 4.08，两个月 +48%）
2026 中  CPU 短缺（Agentic AI 需求爆发）
```

每次瓶颈迁移会推动相关公司估值重估。**越靠近物理瓶颈，确定性越强**（不易快速扩产）。

### Step 4 验证商业兑现节奏

算力 capex 投入 vs AI 商业化兑现 ——

- Mag4 云收入增速（Azure 38% / AWS 32% / GCP 58% / Meta Ads 32%）
- RPO 环比作为"已签未交"信号
- 营收 / Capex 比值 vs 折旧 cliff 拐点

### Step 5 看赢家通吃的格局演化

```
算力底座     垄断格局更极端（NVDA + TSMC）
HBM         三家厂商，SK 独占头部
应用层      OpenAI / Anthropic / Google / xAI 交替领先，短期看不出最终赢家
```

> 移动互联网时代，除了 Mag7 之外还有大量的腰部公司活的很好。但是在 AI 时代集中度会越来越高，赢家通吃效应会越来越强。

## 决策框架

### 看多 AI 算力的必要条件

1. 产业故事在加速（token 消耗、企业渗透率）
2. 公司在产业链中位置硬（不可替代 / 龙头 / 最合规）
3. 财务结构健康（capex 没吃光自由现金流）
4. 至少一个 falsifiable 量化锚

### AI 危机信号 4 条清单（核心 打脸条件）

> AI 危机有几种情况：
> 1) 大科技公司资本开支已经耗尽现金储备，开始透支自由现金流
> 2) 某次财报季 miss 预期占到三四成以上
> 3) 盈利能力和业务增速见顶
> 4) 债务与杠杆开始真的出现违约（利息支付延期）

严格用这 4 条具体观察项判断"AI 是不是危机"，不靠舆情。**当下没有看到这些信号 → 不是危机**。

### Veto

- ❌ 没有真实 token 消耗或客户合同支撑的"AI 概念"
- ❌ 资本结构脆弱（部分新云厂商已经亮黄灯）
- ❌ 模型发布炒作但没有商业化路径
- ❌ 押注 AI 应用层最终赢家

### 打脸条件

- 若 RPO 环比 < 8% → GCP 58% 增速可证伪
- 若营收/Capex 跌破 3.5 → 产能爬坡跑不赢折旧
- 若 HBM 三家集体扩产能 → 周期股逻辑回归
- 若 Mag4 财报半数 miss → 业绩撑不起市场预期

## 常见误读

1. **把"capex 高"读成"风险大"** — 错。他的口径是"capex 不是问题，ROI 不兑现才是问题"。
2. **把"算力短缺"读成"NVDA 一家吃" ** — 错。瓶颈迁移意味着 HBM / 光模块 / 电力 / CPU 轮流受益，**非英伟达受益者**也在不成比例放大（博通 ASIC、ARM、Bloom Energy 等）。
3. **押注应用层赢家** — 错。博主自己明确说"短期看不出最终赢家"，不下注。Agent 也不能下注。
4. **把"杀估值"扩大解读为"AI 不行了"** — 错。"产业里有问题，但不是危机"是博主的标准表述。
5. **用单个 token 数据点下判断** — 错。token 增速是 Y/Y 倍数信号，单点没意义。
6. **新云（CRWV / NBIS）当成 NVDA 替代品** — 错。新云有自己的资本结构脆弱性，博主对其谨慎。
