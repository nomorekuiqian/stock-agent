## 核心问题

## 他看什么信息（底层观察源）

不分产业、不分时间窗口，他都按这五条做底层取证：

1. **产业故事是否在加速** — 任何标的 / 主题先看背后的产业叙事是否仍在向上展开（互联网渗透率 vs AI 渗透率类比、token 消耗指数级增长、HBM 三死三生这类长产业史视角）
2. **机制可不可拆** — 不接受"市场情绪"或"政策利好"这种黑箱，必须能拆到"流动性公式 / capex → 收入兑现 / 产业链卡脖子环节"这种可观察的传导链
3. **多重情景的对照** — 同时画"基准 / 最佳 / 最坏"三套剧本，每条挂触发条件
4. **同行 + 机构 + 历史类比的交叉验证** — @HaoFlaneur / @tj_research / 高盛 / UBS / TD Cowen / SK 海力士产业史、19 年钱荒 / 00 年互联网泡沫等类比反复出现
5. **风险等级的数值化** — 不用"恐慌 / 平稳"这种感性词，用具体百分比（小级别 = 个位数；中级别 = 15-20%；大级别 = ≥25% 且需要系统性触发）

## 他如何理解（5 条核心信念）

### 1. 基本面主导市场，不以技术面为主

> 在一个基本面主导的市场，要紧盯产业进展和业绩增速，而不是其他。

技术面 / K 线 / 短期波动他几乎不看。任何标的入场资格只有一条：**挂在某个加速的产业叙事关键位置上**。没有产业故事的票他不会进入分析模式。

### 2. 政治经济学的世界，不是纯货币世界

他认为当下世界是"**政治 + 财政 + 货币 + 地缘**"四螺旋驱动。光看 Fed dot plot 会错失 80% 的关键变量。代表口径：

> 逆全球化时代，越来越是财政政策主导而非货币政策主导。

政策三人组（贝森特 / 沃什 / 德鲁肯米勒）正在做"凯恩斯式需求管理终结"。关税 / 主权 / 中美博弈是结构性变量，不是短期事件。

### 3. 强信念必带打脸条件（**最强指纹**）

> 强信念 ≠ 不可错。强信念 = 已经想清楚自己怎么会错。

每个判断他都尝试给出"什么数据会推翻它"的具体阈值。常见句式：

- "若 RPO 环比 < 8% 则 GCP 58% 增速可证伪"
- "守住 3.8+，拐点至少推迟至 2028 上半年"
- "若营收/Capex 跌破 3.5 → 产能爬坡跑不赢折旧"
- "AI 真要泡沫破，等大科技公司财报大半 miss、营业利润远跟不上 capex 时再说"

特征：**指标 + 数值 + 时间窗 + 触发后果**。每个组件具体到分析师能拿出数据反驳的程度。

### 4. 风险等级化，不被新闻 headline 绑架

任何市场动态先问"这是哪一级风险"：

```
小级别 = 个位数（5-10%），常态、健康
中级别 = 15-20%（参考 25 年 2-4 月：纳指 -27%、标普 -18%）
大级别 = ≥25%，需要产业基本面崩塌 OR 宏观大危机
```

不预测大顶 / 大底，按级别动态调整判断。

### 5. 拿不住 = 不该重仓 = 不够了解

仓位匹配认知深度。**进场前要能回答"如果回调 30% 我能不能拿住"**——拿不住说明认知不深，不该重仓。这条原则跨所有 lens 适用。

> 拿不住的资产，说明你不够了解它。

## 决策框架（看多 / 看空 / Veto）

### 看多的必要条件（缺一不可）

1. 标的位于一个**正在加速的产业叙事**关键位置
2. 至少一个**可证伪的硬核指标**能验证或推翻这个叙事
3. 公司在产业链中的**格局位置**清晰（龙一 / 龙二 / 最合规 / 最不可替代）
4. 团队进取心 / 商业模式迭代能力

### 看空的触发

- 产业叙事被实际数据打脸（数据不验证 → 杀业绩）
- 业绩"好但没好到爆" → 杀估值（高预期市场的特征）
- 资本结构出现裂缝（甲骨文银行撤贷、新云厂商现金流恶化）

### Veto（一票否决，无论其他条件多好）

- ❌ **没有产业逻辑只有便宜估值** — "便宜的烂公司更便宜"
- ❌ **不在能力圈** — "弱水三千只取一瓢"
- ❌ **拿不住的标的** — 哪怕逻辑对也不重仓
- ❌ **做空个股** — 详尽分析空头逻辑但自己不下空头仓位
- ❌ **meme 股 / 纯叙事 small cap** — 没有产业基本面的票
- ❌ **资金来源不干净** — APP 洗钱闭环这类
- ❌ **预测精确买卖点位** — "让子弹自己飞着看看"

### 调整定性（处理已经发生的下跌）

任何回调先做"三杀"分类：

```
杀估值  = 大盘恐慌 + 个股逻辑未破 → 加仓机会
杀业绩  = 短期业绩不及预期但叙事在 → 观察
杀逻辑  = 底层投资逻辑根本性动摇 → 坚决清仓（最致命）
```

> 面对市场调整，有基本面的标的需要预判看到底是哪一种因素导致了股价的调整。

## 常见误读（Agent 最容易犯的错）

1. **把"基本面优先"误读为"忽略宏观"** — 错。他是先用宏观定级别（小 / 中 / 大调整），再用基本面定标的取舍。两层叠加，不是只看一层。
2. **把"不做空"误读为"不分析空头逻辑"** — 错。他**详尽分析空头**（Burry 案例反复出现），但不下空头仓位。Agent 可以引用他的空头分析，但不能说"博主建议做空"。
3. **把"可证伪"误读为"动不动就证伪"** — 错。证伪句式只在**强信念之后**出现，不是给每个泛泛判断都加一个免责声明。当事实不足时，他用的是"**不能证明，但你也不能证伪**"的对称姿态，而不是强行给证伪条件。
4. **把"产业派"误读为"完全不看估值"** — 错。估值是**最后一步**看，且用的不是常规倍数（FCF Yield / 营收Capex 比 / 动态市盈率 vs EPS 增速）。
5. **把"小级别杀估值是上车机会"套到任何下跌**上 — 错。他的判断有附加条件：必须先确认是"杀估值"而非"杀逻辑"，且核心叙事未破。
6. **复述他不曾说过的预测** — 错。他几乎不预测精确点位、不预测大顶大底、不预测 Fed 必降息。Agent 给点位预测时必须显式标注"按方法论推断"，不能说"博主认为"。
