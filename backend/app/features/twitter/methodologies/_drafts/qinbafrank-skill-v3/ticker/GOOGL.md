## 他如何理解

### 1. 营收/Capex 比值是折旧拐点的核心指标

> 营收/Capex 比值"衡量折旧拐点的核心指标，FY25 约 4.0；< 3.5 时产能爬坡跑不赢折旧；>3.8 拐点至少推迟至 2028H1。

谷歌守得住 4.0 → AI 算力变现速度跑赢折旧。

### 2. GCP Backlog 长合约时代确认

> 谷歌 Backlog 环比最炸（确认长合约拐点），微软/亚马逊 RPO 稳健扩张 + 消耗加速

加权平均剩余期限 > 5.0 年 = 长合约时代确认。

### 3. Capex 1800 亿吃掉一年 FCF + 1200 亿现金

> 谷歌 1800 亿 capex / 谷歌 700 亿 FCF + 1200 亿现金 ≈ 全吃完

商业模式重塑：高速增长 + 轻资产 → 高速增长 + 重资产。

### 4. Search vs AI 搜索

AI Overview 的双刃剑 — 提升搜索价值 vs 蚕食广告点击。**目前还未确认是哪一边**。

## 决策框架

### 升级条件

- GCP 增速维持 50%+ 且 RPO 环比 > 15%
- TPU 出货量 / 客户绑定加速
- Search 广告增速回到 +10%+
- AI Overview 不显著拉低 click-through

### 观察条件

- GCP 增速温和（30-50%）但 RPO 环比 8-15%
- 营收/Capex 比 守住 4.0+

### 不追高 / 减风险条件

- GCP 财报 RPO 环比 < 8% → 增速可持续性证伪
- 营收/Capex 跌破 3.5
- AI Overview 显著拉低 Search 营收

### Veto

- ❌ 押注短期 Gemini vs Claude 模型胜负
- ❌ 把 Search 收入当成永远的"现金奶牛"

### 打脸条件

- 若 GCP 财报"递延收入 + RPO 季度环比增速"低于 8% → GCP 58% 增速可持续性证伪
- 若营收/Capex 跌破 3.5 → 产能爬坡跑不赢折旧
