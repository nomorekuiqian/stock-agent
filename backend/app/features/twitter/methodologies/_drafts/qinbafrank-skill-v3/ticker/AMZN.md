## 核心问题

AMZN 在博主框架里是"**AWS 算力变现快 + 财务压力略大的 Mag4**"。本 playbook 要回答：

1. AWS 32% 增速能否持续？RPO 消耗加速？
2. 2000 亿 Capex 吃光 FCF + 现金的可持续性
3. EPS 39% 增速 vs 33x PE 的成长股架势

## 博主如何定位

> 看亚马逊每股收益 EPS 同比增长 39%，但是滚动市盈率才只有 33 倍，PEG 远小于 1，还是妥妥成长股的架势。

PEG < 1 是看多核心。AWS + 零售双重敞口。

## 他看什么具体信息

- **AWS 增速** — Q1 32%（瑞银口径）
- **EPS 增速** — 同比 +39%
- **滚动 PE** — 33x（PEG < 1）
- **资本开支** — 2000 亿（vs Mag4 6500 亿合计）
- **FCF + 现金能否吃下 Capex** — 2000 亿 / 300 亿 FCF + 1200 亿现金 ≈ 不够
- **RPO 消耗加速** — AWS Backlog 兑现节奏
- **零售业务利润率** — 二季度提升

## 他如何理解

### 1. PEG < 1 + EPS 39% = 成长股

不是简单看 PE，看动态成长性。

### 2. AWS 算力变现快 + RPO 消耗加速

> 谷歌和 AWS 转化最快（营收加速覆盖）

AWS 算力变现节奏与谷歌齐平。

### 3. 财务压力 = Capex 吃光 FCF + 现金

> 亚马逊 2000 亿 capex / 亚马逊 300 亿 FCF + 1200 亿现金 ≈ 不够

商业模式重塑：高速增长 + 重资产，估值中枢下移。

### 4. 零售业务作为压舱石

零售利润率提升是基本面 backup。

## 决策框架

### 升级条件

- AWS 增速 ≥ 32% 且加速
- RPO 消耗加速 + 长合约
- 零售利润率持续提升
- EPS 增速维持 35%+

### 不追高 / 减风险条件

- AWS 增速跌破 25%
- 营收/Capex 跌破 3.5
- 零售业务遭遇逆风

### Veto

- ❌ 把 Capex 大当成 veto（要看 ROI）
- ❌ 押注短期 Trainium / Inferentia vs NVDA 替代节奏

### 打脸条件

- 若 AWS 增速跌破 25% → 增速可持续性证伪
- 若营收/Capex 跌破 3.5 → 折旧拖累
- 若 EPS 增速跌破 25% → PEG 重估

## 已持有 / 未持有

- 已持有：双重敞口 + PEG < 1 长持
- 未持有：等小级别杀估值入场

## 常见误读

1. **把"Capex 大"等同于"风险大"** — 错。看 ROI 兑现节奏。
2. **把"零售竞争"翻译成"亚马逊压力大"** — 错。零售是压舱石，AWS 才是增长核心。
3. **押注 Trainium vs NVDA 替代节奏** — 错。混合算力是趋势。
