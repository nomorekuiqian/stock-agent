# Ticker: ARM — ARM Holdings

## 覆盖状态
`coverage: medium` — 18 次直接提及

## 适用问题
- ARM 架构 / 服务器 CPU 渗透
- AI 算力链上的 ASIC / Custom Silicon
- "ARM 还能不能买"

## 所属上级
- `sector/ai-infrastructure.md` — L1 关键组件（CPU 架构）

## 核心问题
ARM 在博主框架里是"**非英伟达 AI 基建受益者**"代表，资本开支战争背景下不成比例放大。

## 博主如何定位
> 关键看产业链上的"非英伟达受益者" — 博通 ASIC、HBM、ARM、Bloom Energy 等正不成比例放大

## 他看什么具体信息
- **ARM 架构在服务器 CPU 的渗透率**
- **大客户 license 收入**（NVDA / Apple / 高通等）
- **AI 加速器 ARM 化趋势**
- **CPU 紧缺背景下 ARM 节能优势**

## 他如何理解

### 1. AI 基建二线受益者
不是 NVDA 那种龙头，但产业链上的关键非英伟达角色。

### 2. 数据中心 CPU 节能 → ARM 优势
AI 数据中心电力卡脖子 → ARM 节能架构溢价。

### 3. License 模式 = 抗周期
不是直接卖芯片，而是收 license 费 → 抗周期。

## 决策框架

### 升级条件
- ARM 服务器 CPU 渗透率上升
- 大客户 license 续签 + 价格提升
- AI 数据中心 ARM 化加速

### 不追高 / 减风险条件
- 服务器 CPU 渗透停滞
- 大客户转向自研

### Veto
- ❌ 押注 ARM 超越 x86 短期份额
- ❌ 把"ARM 万能"作为下注理由

### 打脸条件
- 若服务器 CPU ARM 渗透停滞 → AI 受益叙事证伪
- 若大客户自研 license 减少 → 收入结构恶化

## 已持有 / 未持有
- 已持有：长持 + 等渗透率拐点
- 未持有：等估值小级别杀入场

## 常见误读
1. **把 ARM 当成"下一个 NVDA"** — 错。是非英伟达受益者，不是龙头。
2. **押注 ARM vs x86 短期份额** — 错。是渐进过程。
