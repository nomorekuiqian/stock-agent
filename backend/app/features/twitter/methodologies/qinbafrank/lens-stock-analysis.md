# qinbafrank 看个股的镜头

## 1. 关注圈 & 风格画像

qinbafrank 是**产业派**，不是估值派、不是技术派、更不是题材派。
他看股票的入场资格只有一条：**这家公司必须挂在某个产业叙事的关键
位置上**。没有产业故事的票他几乎不开口。

**覆盖的标的轮廓**：

- **核心覆盖**（出现频次最高 + 反复深度分析）：META、NVDA、MSFT、
  GOOGL、AMZN、AMD、INTC、ARM、ORCL、CRWV、NBIS、AVGO，以及
  Mag7 旁边的"AI基建第二圈"。
- **强信念长持**：MSTR（加密资产财库）、Circle/USDC（合规龙二）、
  RKLB（太空火箭）、PLTR（国防 AI）。
- **跨界关注**：BMNR、SOL、HOOD、COIN（加密 / 链上美股）、
  Anthropic / OpenAI / xAI（虽未上市但作为产业格局变量）。
- **国别覆盖**：以美股为主，A 股（海光信息 688041、龙芯 688047、
  澜起科技 688008）、港股（中芯 0981、联想 0992）作为产业链补充
  视角，不是单独投资标的。

**时间维度**：

- 主体是 **1-3 季度兑现** —— 关注下个财报、下个产品周期、
  下个监管节点
- 但他**爱写长线产业史**（SK海力士三死三生、李嘉诚四十年石油
  布局、互联网/移动互联网 vs AI 渗透率对比）—— 长线视角是给中
  线持仓提供锚点

**他**不**做的事**：
- 不日内交易、不看 K 线形态
- 不基于政治倾向选股（即使 Trump 概念股也只看产业）
- 不抄"便宜的烂公司"
- 不参与 meme 股、纯叙事 small cap
- 不做空（多次分析空头逻辑但**自己不参与**）

## 2. 分析路径（按这个顺序想）

拿到一个标的，他几乎一定按这个顺序展开：

**Step 1 — 产业故事在哪一层？**
他先把这只票挂到一个产业叙事上。AI 算力 / 半导体周期 / 稳定币
合规 / 太空商用 / 加密 ETF / 国防 AI ……没有故事的票他不会进入
分析模式。

**Step 2 — 哪个指标能验证或证伪这个故事？**
他**会主动挑出"这个故事最关键的那个变量"**，而且经常是不太被
散户关注的硬核指标。例：
- 看 NVDA：RPO 同比 + Blackwell 出货量 + token 消耗增速
- 看美光：HBM 在三家厂商里的产能分配 + 是否扩产能（克制 vs 暴增）
- 看 Circle：USDC 流通量增速 + 利率敏感性测算
- 看 Mag7 整体：营收/Capex 比值 + 加权平均合约剩余期限

**Step 3 — 能见度和拐点在什么时候？**
他特别在意"什么时候会被验证"。所以他经常在推文里写**未来 1-2 个
财报季的关键看点**，并在事件前后回过头来比对。

**Step 4 — 估值合理吗？**
**估值是最后才看**的，且他用的不是常规倍数：
- AI 时代他认为 PE 没那么靠谱（"18 年谷歌 PE 四五十倍"）
- 他更看 FCF Yield、营收/Capex 比值、动态市盈率 vs 业绩增速
- 他承认**估值中枢可能下移**（重资产高 capex 商业模式）

**Step 5 — 反面是什么？**
他几乎不会写一篇"全看多无短板"的分析。他的推文里**总有"质疑合理的
地方 + 质疑不合理的地方"** 这样的双面结构（见 Burry 做空英伟达
那条 thread 的经典对比）。

## 3. 信号偏好

### 他**信**的硬核指标

- **Token 消耗量** — 他多次用具体数字（谷歌从 9.7 万亿/月 → 1300
  万亿/月，字节 1200 亿 → 16.4 万亿）。他视 token 消耗为"算力的
  电力消费量"，是 AI 应用真实落地的硬指标。
- **RPO（剩余履约义务）** — 微软 4000 亿 RPO 增 50% 是他眼里"算力
  订单兑现"的核心信号。**RPO 环比增速跌破 8%** 是他的经典证伪线。
- **资本开支 / 现金流的对应关系** — 他详细算过谷歌 1800 亿 capex
  能吃掉一年自由现金流；亚马逊 2000 亿 capex 把 25 年自由现金流
  和现金全吃完都不够。**这个对应关系的恶化是他眼中的"商业模式
  重塑信号"**。
- **营收 / Capex 比值** — FY25 ≈ 4.0；他援引 UBS 判断**< 3.5 时
  产能爬坡跑不赢折旧**，**>3.8 拐点至少推迟到 2028H1**。
- **HBM 三家产能分配** — SK 57% / 三星 22% / 美光 21%。他用这个
  来判断存储链的格局。
- **加权平均合约剩余期限** — Backlog 不只是看数字，要看**期限**
  延长（>5.0 年 = 长合约时代）or 缩短（<3.8 年 = 短合约回流）。

### 他引用的源

- **同行分析师**：@HaoFlaneur（美光 thesis）、@tj_research、
  @nft_hu（右侧操作教科书）、@wufantouzi、@BTCdayu
- **机构研报**：高盛、UBS、Citi、Morgan Stanley、TD Cowen、
  FactSet、Counterpoint、Bloomberg、CB Insights
- **第三方数据**：Ornn（算力价格指数 — Blackwell 时租从 2.75 →
  4.08 美元，两月 +48%）
- **CEO 公开发言/访谈**：Sam Altman 达沃斯、Dario Amodei、黄仁勋
  GTC、皮查 UCP

### 他**不**信的

- 日内 K 线 / 短期价格波动
- 单一估值倍数（PE 在 AI 时代已经不可靠）
- "便宜"本身（"便宜的烂公司更便宜"）
- "崩盘论" / 大跌预警（"动不动喊泡沫崩盘，其实略过度了"）

## 4. 判断闸 & 可证伪锚

这是他最强的部分 —— **强信念之前必带"如何被证伪"的句式**。
这是他的**特征性表达**：

> "若 RPO 环比 < 8% 则 GCP 58% 增速可证伪"
> "若营收/Capex 跌破 3.5，市场定价产能爬坡跑不赢折旧"
> "守住 3.8+，拐点至少推迟至 2028H1"
> "AI 真要泡沫破，等大科技公司财报大半 miss、营业利润远跟不上
>  capex 时再说"

### 看多的必要条件（缺一不可）

1. 标的位于一个**正在加速的产业叙事**关键位置
2. 至少一个**可证伪的硬核指标**能验证或推翻这个叙事
3. 公司在产业链中的**格局位置**清晰（龙一 / 龙二 / 最合规 / 最不可
   替代）
4. 团队进取心 / 商业模式迭代能力（Circle 的 CPN 升级是经典）

### 看空的触发

- 产业叙事被实际数据打脸（数据不验证 → 杀业绩）
- 业绩"好但没好到爆" → 杀估值（高预期市场的特征）
- 资本结构出现裂缝（甲骨文银行撤贷、新云厂商现金流恶化）

### Veto（一票否决，即使其他都好也不进）

- 没有产业逻辑只有便宜估值
- 资金来源不干净（如 APP 做空案例：洗钱闭环 → 不碰）
- 不在自己能力圈 → "弱水三千只取一瓢"
- 拿不住的标的 → 哪怕逻辑对也别重仓（这条来自他的元方法论，
  与个股判断耦合）

## 5. 风控纪律

- **逢跌买不追高**：他多次写"调整下更好。估值杀到位，不那么贵了，
  又是上车良机"。**反对在情绪高点重仓**。
- **不预测精确点位**：经典句"$1330 反倒没那么重要，让子弹自己飞着
  看看"。他认为自己擅长方向不擅长点位。
- **公开复盘观点演化**：他写过"近期判断的动态修正逻辑"长文，承认
  自己一些判断回头看"还是太保守了"。**不护短**。
- **不预测大崩盘**：判断市场调整时分级（小级别 / 中级别 / 大级别），
  90% 时间认为是"正常调整 / 蓄力"。**只有极端情况才会用"危机"
  这个词**，且会区分"债务问题" vs "债务暴雷"。
- **不做空**：他多次详尽分析空头逻辑（Burry 案例反复出现），但
  **自己不下空头仓位**。他认为做空是"宏观大风险才能赢"，散户级别
  做空个股"忽略了基本面"。

## Agent 应用这个 lens 时的指南

**当用户问"我应该买 [TICKER] 吗？"**：

不要说"qinbafrank 推荐 X"。要按 Step 1-5 走一遍：
1. 这只票的产业故事是什么？（如果你不知道，先承认不知道）
2. 故事的关键证伪指标是什么？
3. 下一个财报/事件什么时候验证？
4. 估值放在最后讨论
5. 反面观点是什么？

**当用户问"博主历史上怎么看 [TICKER]"**：

去 RAG 召回 stock_analysis 类该 ticker 的历史推文。**逐字引用，
不要改写**。如果博主没明确表态过，**诚实说"博主未就此发言"**，然后
用本 lens 推断"按他的方法论应该会怎么看"，并明确标注"推断"二字。

**禁忌**：

- 不能说"all in" / "梭哈" / "必涨" —— 不是博主用语
- 不能给精确买卖点位 —— 博主自己很少给
- 不能虚构 RPO / 营收 / capex 具体数字 —— 必须有 RAG 命中或实时
  数据 tool 返回
- 遇到博主没覆盖的小盘股 / meme 股 → 用 lens 的 Veto 项婉拒：
  "按 qinbafrank 的能力圈和风格，他通常不参与 [类型]，建议另请
  专长这块的视角"
