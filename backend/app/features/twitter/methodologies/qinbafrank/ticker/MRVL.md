## 核心问题

MRVL 在 Frank 框架里不是先看 PE，而是先看它是否处在 AI 基建加速链条中更硬的环节：

1. 数据中心收入和指引是否继续加速。
2. AI interconnect / optical / custom silicon 是否从叙事变成收入。
3. 铜互联到光互联的切换节奏是否继续推进。
4. 它相对 AVGO / NVDA / LITE / NOK 处在什么链路位置，是核心平台、供应链受益者，还是只吃估值扩张。
5. 股价是否已把黄仁勋点名后的乐观预期一次性透支。

## 他看什么信息

- 数据中心业务收入占比、同比 / 环比增速、下一财年指引。
- Interconnect、custom silicon、光学互联、DCI、相干光等业务的增长路径。
- 大客户 AI capex 是否继续外溢到非 GPU 基础设施。
- 铜互联到光互联的切换节奏，以及它对数据中心 scale-up / scale-out 架构的影响。
- 和 AVGO 的差异：两者都在 custom silicon / 网络 / 数据中心链条里，但 MRVL 更需要证明自己的收入兑现强度和客户绑定。

## 他如何理解

### 1. 从 AI 基建链路看，不从普通半导体周期看

MRVL 的价值点在于 AI 数据中心架构变化：GPU 之外，数据移动、互联、光学、定制芯片会变成更大的瓶颈。Frank 对这类标的的判断顺序通常是"产业叙事是否加速 -> 业务数据是否验证 -> 格局位置是否清楚"。

## 决策框架

### 看多 / 支持条件

- MRVL 数据中心收入继续超预期，且不是一次性订单。
- Interconnect / custom silicon / optical 业务指引持续上修。
- AI capex 从 GPU 扩到数据中心互联、网络和光学基础设施，且 MRVL 有明确收入份额。
- 管理层能给出更长周期的订单、客户导入和产能兑现路径。
- 光互联从 CPO 远期故事过渡到 1.6T / LPO / NPO / 光源 / 测试等更近的收入兑现环节。

### 看空 / 减风险条件

- 数据中心收入增速放缓，或上调指引无法兑现。
- Custom silicon / interconnect 只是叙事，不能转成可验证收入。
- 大客户自研、供应链替代或 AVGO / NVDA 平台化压缩 MRVL 议价能力。
- 光互联推进慢于预期，铜互联继续延长生命周期，MRVL 的光学叙事被推迟。
- 黄仁勋点名后的交易过热退潮，股价先杀估值，即使产业趋势未坏。

### 可证伪

如果未来 MRVL 的数据中心收入、interconnect / custom silicon 指引或客户需求连续低于管理层上修后的预期，这条 AI 基建受益逻辑就要下修；如果光互联切换被显著推迟，也会削弱 MRVL 在数据中心架构变化中的弹性。
