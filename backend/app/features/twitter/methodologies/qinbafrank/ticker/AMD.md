# Ticker: AMD — Advanced Micro Devices

## 适用问题

- AMD / 超微 / MI300 / MI355 / Instinct AI 加速器。
- AMD vs NVDA，或者服务器 CPU 在 Agentic AI 时代是否成为新瓶颈。
- AMD 数据中心业务、AI 加速器份额、CPU 紧缺。

## 一句话定位

在 Frank 框架里，AMD 不是“取代 NVDA”的故事，而是“服务器 CPU 紧缺 + AI 加速器二把手”的故事。它的确定性来自瓶颈迁移，弹性来自 NVDA 之外的替代需求。

## Frank 会先看什么

- 服务器 CPU 交期：交期拉长说明 CPU 变成新的卡脖子。
- 服务器 CPU 价格：涨价说明供需偏紧，不只是新闻热度。
- 数据中心业务增速：CPU 和 AI 加速器需求最终要进财报。
- Instinct 加速器收入：AMD 在 AI 加速器里有没有拿到真实份额。
- AMD vs NVDA 份额：AMD 是二把手，不是短期王座挑战者。

## 这些变量怎么连接

Frank 对 AMD 的链条是：

```text
Agentic AI 让推理和调度需求变大 -> 服务器 CPU 也开始紧缺 -> AMD/Intel 双寡头受益 -> AMD 同时拿到 AI 加速器二把手弹性
```

所以 AMD 的核心不是“能不能干翻 NVDA”，而是 CPU 和加速器两个方向有没有同时兑现。CPU 紧缺是确定性，AI 加速器份额是弹性。

## 支持信号

- 服务器 CPU 交期继续拉长或价格继续上涨。
- 数据中心收入加速。
- Instinct 收入和客户采用继续提升。
- 市场开始把 CPU 瓶颈纳入 AI 基建叙事。

## 削弱信号

- CPU 交期回到正常区间，紧缺叙事缓和。
- Instinct 收入或份额停滞。
- 数据中心业务增速跟不上估值预期。
- 市场把 AMD 错定价成“短期取代 NVDA”，导致预期过高。

## 打脸条件

- CPU 交期明显回落，说明 Agentic AI 带来的 CPU 卡脖子不够强。
- AI 加速器份额无法继续上升，二把手弹性要下修。
- 数据中心收入不能验证 CPU + AI 加速器双轮驱动。

## 不同持仓状态下该观察什么

- 已持有：看 CPU 紧缺是否持续、Instinct 是否兑现，不要只盯 NVDA 股价联动。
- 未持有：先判断估值是否已经透支“二把手弹性”，再看 CPU 瓶颈有没有新证据。

## 常见误读

1. 押注 AMD 短期取代 NVDA。Frank 框架里 AMD 是二把手和瓶颈迁移，不是龙头替代。
2. 把 CPU 紧缺直接翻译成 AMD 必涨。还要看数据中心收入和估值预期。
3. 忽略 Intel。服务器 CPU 是双寡头格局，AMD 不是唯一受益方。

## 用户可见术语翻译

- 服务器 CPU 交期：客户下单后要等多久才能拿到服务器处理器。
- Instinct：AMD 的 AI 加速器产品线。
- 二把手弹性：不是最确定的龙头，但如果拿到份额，股价弹性可能更大。
- 瓶颈迁移：AI 链里最缺的东西从 GPU 转到 CPU、HBM、电力等环节。
