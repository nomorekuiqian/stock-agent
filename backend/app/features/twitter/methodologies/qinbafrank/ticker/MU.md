## 核心问题

MU 在博主框架里是"**HBM 紧平衡 + 估值还便宜的成长股**"。本 playbook 要回答：

1. HBM 三家产能分配是否稳定？美光 21% 是否能扩
2. 动态 PE vs 业绩增速 — PEG < 1 的成长股性
3. NAND / DRAM 价格周期阶段

## 博主如何定位

> 当下市场给美光 37 倍的滚动市盈率，10 倍的动态市盈率，从现在的增速来看 PE 还是低于业绩增速的。

**PEG < 1 = 妥妥的成长股架势**。学精了的供给纪律 = 结构性紧平衡。

## 他看什么具体信息

- **HBM 三家份额** — SK 57% / 三星 22% / **美光 21%**
- **HBM 价格涨幅** — 单季 30-40%
- **NAND / DRAM ASP** — 平均售价
- **滚动 PE vs 动态 PE vs PEG** — PEG < 1 看多标记
- **资本开支与扩产纪律** — 不抢产能
- **客户合同期限** — 长合约时代信号

## 他如何理解

### 1. 学精了的供给纪律 = 结构性紧平衡

> 存储厂商相比以前的周期学精了，不断提价而不是像之前周期那样先扩产能。

这是 MU 看多的根本逻辑。

### 2. PEG < 1 的成长股架势

动态 PE 10x vs 业绩增速（炸裂）→ PEG < 1。

### 3. HBM 三家格局稳定 = MU 受益

NVDA 等下游买家议价能力被分散在三家。MU 21% 份额相对稳定。

## 决策框架

### 升级条件

- HBM 价格继续上涨（季度 30-40%）
- 三家不扩产能（供给纪律维持）
- 动态 PE 维持低位 + 业绩增速 维持

### 不追高 / 减风险条件

- 三家集体扩产能信号 → 周期股逻辑回归
- ASP 连续两季度环比下跌

### Veto

- ❌ 把美光当成传统周期股（这次不一样）
- ❌ 押注美光超过 SK 海力士的份额

### 打脸条件

- 若 HBM 三家集体扩产能 → 周期股逻辑回归
- 若 NAND ASP 连续两季度环比下跌 → 量价齐升叙事证伪
- 若加权平均合约期限缩短至 3.8 年以下 → 长合约证伪

## 已持有 / 未持有

- 已持有：长合约确认 + 三家格局稳定时回补
- 未持有：等估值小级别杀（动态 PE 已 10x 不算贵）

## 常见误读

1. **把"PE 37x"等同于"贵"** — 错。看动态 PE 10x + PEG < 1。
2. **把美光当周期股** — 错。这次有 HBM + 长合约 + 供给纪律三重不同。
3. **押注份额超越 SK 海力士** — 错。SK 13 年孤独押注的龙一地位不易动摇。
4. **看到 NAND 价格波动就出货** — 错。要看长期 ASP 趋势。
