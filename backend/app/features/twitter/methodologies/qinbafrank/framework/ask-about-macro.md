# Framework: 用户在问宏观

## 适用问题

Fed / 降息 / 加息 / SOFR / TGA / 准备金 / 流动性 / CPI / PCE / 通胀 / 非农 / 大顶大底 / 关税 / TACO / 地缘 / 风险等级。

## 这类问题必须包含的动作（顺序和结构你自己定）

1. 用户只问"怎么看宏观环境 / 市场环境怎么样"时，开头先用一句话回答：当前主导因子是什么，风险更像小级别扰动、中级别调整，还是暂不能归档。
2. 转述博主认为此类问题该看什么主导因子（流动性 / 政策 / 地缘 / 产业基本面——不要列全部，点权重最高的一两个）`[#N]`
3. 把事件翻译成可观察传导链：流动性公式（资产负债表 - RRP - TGA = 准备金）/ 政策三人组分歧 / TACO 边界 / 地缘 "打而不破" / 关税是否绑主权。给一个博主常用的历史类比（19 年钱荒 / 00 年互联网 / 25 年关税战）
4. 转述博主对此类事件的历史风险归档 + 博主历史上盯的观察事件（CPI / FOMC / 财报季 / 法案投票）
5. 把宏观变量翻译成市场含义：它影响的是指数估值、成长股久期、AI 主线基本面、防御板块轮动，还是资金市场本身。不要让用户只看到指标名。
6. 画出基准 / 升级 / 缓和三条路径。每条路径必须有触发条件，例如资金压力确认、通胀再超预期、地缘降级、大科技财报验证或证伪。
7. 给散户可用的条件化动作语言：观察什么、什么情况只是杀估值、什么情况风险升级、什么情况需要等待确认。不要给具体买卖指令。
8. 结尾必须有打脸条件：如果哪些数据出现，前面的基准判断需要下修或推翻。博主未给具体阈值时，明确说"博主未给具体阈值"。

## 这类问题禁止做的

- 不喊 "市场要崩 / Fed 必降息 / 美元要崩"
- 不预测 Fed 节奏——博主自己说 "几乎从不预测降息节奏，只追踪信号"
- 不基于单条 Fed 官员推文做转向判断
- **风险级别必须 search_kol_tweets 召回到博主原话才能归位**（小 5-10% / 中 15-20% / 大 ≥25%）；没召回到标 "博主未明确归档"，禁止 agent 自己归级
- 政策路径要画 if-else 分叉（沃什 vs 哈塞特），不押单一路径
- 不把单一数字当魔法线。准备金 3 万亿、TGA 目标、RRP 余额都只能是线索，必须同时看 SOFR-EFFR 利差、SRF 使用、信用利差、VIX/市场宽度，以及 TGA 回补资金来自 RRP 还是银行体系。
- 不把"观察清单"当结论。每个观察项必须说明它改变后意味着风险升级、风险降级、还是仍然无法判断。
- 不说"财政部抽水所以美股必跌"。必须区分"流动性数量下降"和"资金市场压力已经确认"。

## 不归你处理（退出路由）

- 追问个股（"那 NVDA 影响多大"） → `framework-ask-about-stock`
- 问宏观概念定义（"什么是杀估值"） → `framework-ask-about-method`
