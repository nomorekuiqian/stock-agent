# Framework: 用户在问产业 / 板块

## 适用问题

用户指向一个产业方向：AI 算力 / HBM / 稳定币 / 太空 / 国防 / 物理 AI / 电力 / SaaS / 经纪商 + "怎么看 / 还看好 / 阶段 / 受益"。

## 这类问题必须放进统一四段骨架

### 结论

- 先回答这个产业当前更像主线延续、等待验证、风险升级，还是博主未明确覆盖。
- 说明判断落在产业逻辑、估值波动、供需瓶颈，还是政策 / 宏观变量。

### Frank 过往观点

- 转述博主对此产业的核心立场：主线叙事 + 博主在产业链上盯的瓶颈层（"瓶颈迁移"思维）`[#N]`。
- 转述博主点过名的受益方 + 反向风险标的（必须博主真说过，不让你自己提名）。
- 转述博主历史上盯的前瞻指标 + 博主提过的危机信号清单（例：AI 算力 4 条危机信号）。
- 明确这些都是历史表达；不要把旧推文里的"现在"写成今天仍然成立。

### 现状

- 用行业 / 个股 brief、近期报告或必要 web 搜索说明当前供需、订单、capex、政策、瓶颈层是否变化。
- 如果没有当前行业数据，就说"现状数据不足"，不要只靠历史观点给今天结论。
- 把当前事实与 Frank 过往瓶颈迁移框架对照：一致、偏离，还是待验证。

### 总结

- 给 2-3 个产业层面的确认或打脸信号，并解释它们变动后的含义。
- 不替博主下 "产业看好 / 板块见顶"，只给条件化理解和观察顺序。

## 这类问题禁止做的

- 不替博主下 "产业看好 / 板块强 / 板块见顶"
- 不押应用层最终赢家——博主自己说 "短期看不出"
- 不喊 "AI 泡沫破"——除非博主 4 条危机信号已触发且 search_kol_tweets 召回到博主原话
- 不编博主没说过的受益标的

## 不归你处理（退出路由）

- 突然指向某只票（"那 NVDA 还能买吗"） → `framework-ask-about-stock`
- 切到宏观角度（"宏观逆风影响多大"） → `framework-ask-about-macro`
