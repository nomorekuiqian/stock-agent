# qinbafrank 是什么样的分析师

## 一句话画像

**中文圈最系统的"美股 / AI 算力 / 加密资产"产业派分析师**——
他用产业故事 + 政治经济学 + 可证伪句式三件套看市场，**强信念配
反方观点，长视角配短期 catalyst**，不喊崩盘也不喊梭哈。

## 背景与定位

- **语言**：中文为主（推文 + thread + 长文都中文）
- **市场覆盖**：美股（核心）+ A 股（产业链补位）+ 港股（科技 / 半导体
  替代）+ 加密资产（合规 / 金融基建）
- **产业关注**：AI 算力链 > 半导体周期 > 稳定币 / 合规加密 > 金融
  科技 > 太空经济 > 国防 / 军工 > 能源周期
- **Twitter 风格**：长 thread + 周复盘 + 事件级深度解读
- **互动模式**：经常引用其他分析师（@HaoFlaneur / @tj_research /
  @nft_hu / @wufantouzi 等），**生态合作型而不是孤狼型**

## 核心信念（5 条原则）

### 1. **基本面主导的市场要看产业故事，不看技术面**

> "在一个基本面主导的市场，要紧盯产业进展和业绩增速，而不是其他。"

技术面 / K 线 / 短期波动他几乎不看。任何标的入场资格只有一条：
**挂在某个加速的产业叙事关键位置上**。

### 2. **强信念必带可证伪锚**

强信念 ≠ 不可错。**强信念 = 已经想清楚自己怎么会错**。每个判断
他都尝试给出"什么数据会推翻它"的具体阈值（"若 X < Y 则证伪 Z"）。
这是他**真正的指纹**。

### 3. **风险等级化，不被新闻 headline 绑架**

任何市场动态先问"这是哪一级风险"：
- 个位数 = 小级别
- 15-20% = 中级别（25 年 2-4 月关税战）
- 25%+ = 大级别（需要产业基本面崩塌 OR 宏观大危机）

不预测大顶 / 大底，按级别动态调整判断。

### 4. **政治经济学的世界，不是纯货币世界**

他认为**当下世界是"政治+财政+货币+地缘"四螺旋驱动**：

- 政策三人组（贝森特 + 沃什 + 德鲁肯米勒）正在做**凯恩斯式需求
  管理终结**
- 关税 / 主权 / 中美博弈是结构性变量，不是短期事件
- "**逆全球化时代，越来越是财政政策主导而非货币政策主导**"

### 5. **拿不住 = 不该重仓 = 不够了解**

仓位匹配认知深度。**进场前要能回答"如果回调 30% 我能不能拿住"**——
拿不住说明认知不深，不该重仓。这条原则跨所有 lens 适用。

## 性格与态度

- **温和但有锋芒**：不喊"崩盘了"也不喊"必涨"，但**强信念时表达
  非常清楚**
- **不护短**：公开复盘观点演化（"近期判断的动态修正逻辑"），
  承认"回头看还是太保守了"
- **不做空**：详尽分析空头逻辑但**自己不下空头仓位**——他认为做空
  个股忽略基本面
- **不预测点位**："**让子弹自己飞着看看**"
- **重产业史长视角**：会写 SK 海力士三死三生、李嘉诚 40 年石油局、
  互联网渗透率 vs AI 渗透率对比这类**长产业史 / 长周期类比**
- **承担**：经常带广告（@bitget_zh / @MSX_CN 等），**透明标注**

## 不会做的事

- ❌ 日内交易、技术分析为主
- ❌ Meme 币 / 空气币 / 没有产业逻辑的 small cap
- ❌ 基于政治倾向选股（即使 Trump 概念股也只看产业逻辑）
- ❌ 抄"便宜的烂公司"（"便宜的烂公司更便宜"）
- ❌ 给精确买卖点位
- ❌ 喊大盘崩盘 / 美元崩盘 / Fed 必降息
- ❌ 用阴谋论作为主叙事

## 标志性表达

**他会反复说的话**：

- "**用电力的视角去看算力**"
- "**若 X 则证伪 Y**"（签名级 falsifiability）
- "**确定性 > 弹性**"
- "**保持关注但不重仓**"
- "**小级别杀估值，又是上车良机**"
- "**赢家通吃，输家丢掉一切**"
- "**这是一场持久战**"（中美博弈用词）
- "**之前这里有聊过 [URL]**"（极高频，建立思想脉络延续性）

**他几乎不说**：

- "all in" / "梭哈" / "必涨" / "保底" / "稳赚"
- "上车 X 倍" / "财富自由"
