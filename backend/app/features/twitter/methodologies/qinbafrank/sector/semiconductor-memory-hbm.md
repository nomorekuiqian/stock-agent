# Skill: Semiconductor / Memory / HBM

## 适用问题

- 半导体周期 / 存储 / HBM / DRAM / NAND / NOR
- 美光 / SK 海力士 / 三星 / SanDisk / 希捷 / Seagate
- "存储周期是不是已经在涨" / "HBM 还能不能买"
- 闪存 / QLC / 近线 / SSD
- 半导体设备链（ASML / 应材 / KLA）

## 核心问题

存储 / HBM 是 AI 算力链 L1 层最关键的"卡脖子环节"。本 skill 要回答：

1. **HBM 三家产能分配** + 是否扩产 → 周期 vs 长合约定性
2. **NAND / DRAM 价格周期** + 客户订单兑现节奏
3. 半导体设备链（ASML / TSM）的产业卡位

## 他看什么信息

### HBM 硬指标

- **三家产能分配** — SK 57% / 三星 22% / 美光 21%
- **是否克制扩产能** — "存储厂商学精了，不断提价而不是像之前周期那样先扩产能"
- **HBM 价格涨幅** — 单季 30-40%

### NAND / DRAM 硬指标

- **量价齐升信号** — 产能售罄 + 提价
- **平均售价** — 美光 / 闪迪 / SanDisk 的 ASP
- **NAND 周期阶段** — 学精后的供给纪律

### 近线 / HDD 硬指标

- **希捷 build-to-order 长合约** — 锁定主要云客户
- **毛利率创纪录**（47% non-GAAP）
- **长期增长目标上调**（≥20% 年化）

### 估值锚

- **滚动 PE vs 动态 PE vs PEG**
  - 美光 ~10x dynamic PE / 37x trailing → PE < 业绩增速
  - PEG < 1 = 成长股标记

## 他如何理解

### Step 1 这是 AI 卡脖子还是周期股反弹？

> 学精了的存储厂商 + AI 算力需求 = **结构性紧平衡，不是过往周期反复**

### Step 2 SK 海力士三死三生作为产业史

博主写过 SK 海力士 13 年的孤独押注作为 HBM 龙一的合法性来源。**产业史视角给中线持仓提供锚点**。

### Step 3 卡脖子是不是已经迁移走

```
2024  GPU 短缺
2025  HBM 卡脖子 ← 当下还在中段
2026 初 电力卡脖子 ← 同时叠加
2026 中 CPU 卡脖子
```

HBM 紧平衡持续到至少 2027 年（库存周期 + 产能扩张周期）。

### Step 4 NAND vs DRAM vs HDD 各看什么

- **DRAM** — HBM 拉动主旋律
- **NAND** — QLC 大容量 + AI 训练数据存储拉动
- **HDD** — 近线存储 build-to-order 长合约（希捷为代表）

## 决策框架

### 看多必要条件

1. **学精了的供给纪律**（不抢产能）
2. **量价齐升 / 长合约锁定**
3. **动态 PE < 业绩增速**（PEG < 1）
4. **HBM 三家格局没大变化**

### 看空触发

- HBM 三家集体扩产能 → 周期股逻辑回归
- AI 训练需求降速 → 拉动效应弱化
- 替代材料 / 工艺出现（远期）

### Veto

- ❌ 没有 HBM 敞口的传统存储公司
- ❌ 资本结构脆弱的二线厂商
- ❌ 押注 SK 海力士 / 三星短期份额变化（格局稳定）

### 打脸条件

- 若 HBM 三家集体扩产能 → 周期股逻辑回归（短合约时代回来）
- 若加权平均合约剩余期限缩短至 3.8 年以下 → 长合约时代证伪
- 若 NAND ASP 连续两季度环比下跌 → 量价齐升叙事被证伪

## 常见误读

1. **把"美光 PE 37x"读成"贵"** — 错。要看动态 PE（10x）vs 业绩增速（炸裂），PEG < 1 才是博主的看多标准。
2. **把存储当成纯周期股** — 错。"学精了"的供给纪律 + AI 算力拉动 = **结构性紧平衡**，不是过往周期。
3. **押注三星 / 海力士份额超车** — 错。SK 海力士 13 年孤独押注的龙一地位不易动摇。
4. **把"HBM 涨价"读成"美光必涨"** — 错。要叠加美光本身的财务指引 + 客户合同结构。
5. **把希捷 HDD 当成"传统过气"** — 错。AI 训练数据近线存储拉动 + build-to-order 长合约 = 结构性紧平衡。
