# Skill: Crypto / Stablecoin / RWA

## 适用问题

- 加密资产 / 稳定币 / USDC / USDT / Circle / Tether
- 清晰法案 / GENIUS / SEC Project Crypto / RWA / 代币化
- 链上美股 / 链上 DeFi / AI × Crypto / Agentic Wallets / x402
- Coinbase / Robinhood / MSTR / BMNR / BNB / SOL
- 中国对加密的监管 / 海外发行 ABS 代币
- "BTC / ETH 怎么看" / "现在能不能进场"

## 核心问题

qinbafrank 看 crypto 的角度跟币圈完全不同——他不信"crypto native 革命"，他信 **crypto 是 AI 时代金融基建**。本 skill 要回答：

1. 当前讨论的资产是金融基建（稳定币 / 合规交易所）还是投机标的（meme / 空气币）？
2. 监管节奏在哪一步？是顺风还是逆风？
3. 真实业务数据（USDC 发行量、Coinbase 市占率）vs 叙事，谁更硬？

## 他看什么信息

### 核心硬指标

- **稳定币发行量增速**（USDC 同比 80%、USDT 增减、Tether 利润）
- **现货 ETF 净流入 / 流出**（BTC ETF 是大换手周期最大买方）
- **链上活跃地址 / 交易量**
- **合规交易所市占率**（Coinbase 在美国市场）
- **稳定币市占率**（USDT vs USDC vs 新进入者）
- **机构托管规模**（贝莱德 / 富达）

### 监管节奏（catalyst 级）

- **白宫 / SEC / CFTC 会谈频次**
- **法案进度**（草案 → 委员会 → 投票 → 总统签署）
- **罚款条款**（清晰法案 50 万/天）
- **对华监管动作**（八部委 / 证监会节奏）

### AI × Crypto 信号

- **x402 协议处理交易量**（Coinbase 已 5000 万笔）
- **Base 链 Agentic Wallets 创建数**
- **Stripe / Coinbase / Cloudflare 支付协议演进**

## 他如何理解

### Step 1 这是哪一层？

- 法币锚（稳定币）？
- 资产层（BTC / ETH / SOL）？
- 应用层（DeFi / NFT / GameFi）？
- 监管层（立法 / 行政命令）？
- 基建层（CDN + 支付协议如 x402）？

**不同层关键变量完全不同**。

### Step 2 流动性源头：美元 vs 币本位

美元流动性公式（同 macro skill）。币市自身流动性还看：

- USDC / USDT 发行量增减（年初 2 月跳水 100 亿 = 大饼跌到 6 万的直接原因之一）
- BTC 现货 ETF 净流入流出
- 各国央行金 / 比特币储备
- Jane Street 等大做市商动作

### Step 3 监管节点是关键 catalyst

不预测立法结果，但追踪每次会谈的妥协路径：

- GENIUS 法案（已通过，禁生息稳定币）
- 清晰法案（CLARITY，正在博弈）
- SEC Project Crypto（资产代币化）
- 中国八部委（境内严管）
- 证监会境外 ABS 代币口子（"严管 + 留口子"）

### Step 4 项目方动态 + 团队进取心

对有商业模式的 crypto 项目，用类似看股票的方法：

- 业务数据（USDC 发行量增速 80% Y/Y）
- 团队进取心（Circle 不断拓展 → 深度合作 Coinbase / 贝莱德 / 支付场景）
- 行业地位（龙二、最合规）
- 网络效应（稳定币天然有）

### Step 5 反方观点

跟个股一样，几乎从不一面倒：

> 未来合规稳定币不只是 USDC 一家，很多大型银行商业机构都会推自己的稳定币。

然后再分析为什么大部分中小型银行会选择跟现有稳定币合作。

## 决策框架

### 看多必要条件（针对合规标的如 Circle / Coinbase）

1. 市场规模 + 增长空间（未来三五年稳定币 3 万亿市场）
2. 行业地位（龙一 / 龙二 / 最合规）
3. 团队进取心（节奏 + 业务拓展数）
4. 网络效应（稳定币天然有）
5. 监管路径明朗度（清晰法案进度）

### 看空触发

- 立法严重不利（完全禁止生息稳定币 + 利息分成）
- 美元流动性持续紧缩
- 真实违约 / 暴雷（22 年 LUNA / FTX 级别）
- 主流交易所 / 头部项目方违规曝光

### Veto

- ❌ 完全没有合规路径 / 完全监管套利的项目
- ❌ 团队节奏混乱 / 抛压计划不透明
- ❌ 没有真实业务支撑的纯叙事代币
- ❌ meme 币 / 空气币
- ❌ 短期 BTC / ETH 价格预测

### 打脸条件

- 若 USDC 发行量同比增速 < 50% → 网络效应叙事被证伪
- 若清晰法案最终条款完全不利创新 → 美国加密创新转移海外
- 若 BTC ETF 转为持续净流出 6 个月 → 大换手周期不成立

## 常见误读

1. **把 crypto 当 native 革命** — 错。他的口径是"加密资产未来最大的应用场景**并不是 crypto 原生的创新应用**"，而是 web2 上链 + AI agent 支付。
2. **把"看好 Circle"等同于"看涨 USDC 价格"** — 错。稳定币锚定法币，没有"价格"概念。他看好的是 Circle 公司（CRCL 股票）的业务增长。
3. **把"中国监管严"读成"中国会放开加密"** — 错。他多次否定"在资本管制的地区，放开加密 = 给资本外流打开口子"。
4. **把 MSTR / BMNR 当成长期持有稳态** — 错。他在 legacy stock_analysis.yaml 里明确警告"借微策略之名实则大股东抛售运作"的 DAT 类标的，"模式没风险不代表股价没风险"。
5. **把 ETF 流入流出当唯一信号** — 错。需要叠加美元流动性 + 监管节点 + 做市商动作。
6. **把"AI × Crypto"误读为"crypto 拯救者"** — 错。他的视角是 crypto 因为 AI agent 支付需求而变成"基建"，不是反过来。
