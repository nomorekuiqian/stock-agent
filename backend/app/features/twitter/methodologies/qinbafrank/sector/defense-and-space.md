## 核心问题

国防与太空在 qinbafrank 视角下是同一条产业链 — **强人政治时代的"硬资产"敞口**。本 skill 要回答：

1. 当前地缘事件是哪一级（局部 / 主权 / 战争）？传导到哪些标的？
2. 太空经济处在产业周期哪一阶段（SpaceX IPO 前 / 后；商业火箭进度；星链生态）？
3. 国防订单的可见度（订单簿 / 政府合同 / 北约盟友采购）

## 他如何理解

### Step 1 这是哪一级地缘事件？

```
局部冲突       霍尔木兹 / 委内瑞拉 / 北朝鲜 单点
主权问题       格陵兰 / 台湾 / 加密领土争议 — TACO 不适用
战争升级       全面热战 — 概率极低（核武器存在）
```

### Step 2 拆军力部署看真实意图

不看政客口头声明，**看航母 / 战机 / 加油机的物理位置**：

- 美军中东 6 月伊战时部署：3 个航母战斗群 + 阿利·伯克级 + 提康加德罗
- 委内瑞拉行动：加勒比海 1 航母 + 1 两栖攻击舰 + 海军陆战队
- "本周末才到位，移动几千海里立即攻击难度高"

### Step 3 太空 = 下一个万亿赛道

> 太空经济也是新能源、AI、Crypto、机器人之后下一个万亿美金级别的大赛道机会。也将是主要大国未来不容丢失的重要产业版图。

24 年全球太空经济 6130 亿，同比 +7.8%；麦肯锡预测 35 年 1.8 万亿。SpaceX 上市将"带动整个生态系统进入大众视野"。

### Step 4 国防订单的护城河效应

> 这种业务的好处是一旦进去替代成本太高（拿不出来）。

PLTR 在美国国防体系一家独大的逻辑：政府订单替代成本高 → 长期 lock-in → 业绩可见度强。

### Step 5 中美军备对照（特别在意太空）

```
美国 星链申报体量 → 优势
中国 ITU 申报 20.3 万颗 → 5 倍体量但执行能力存疑（17 号两枚火箭同日失败）
```

战略意图：先申报 / 先发射 / 先占用 = 太空版"圈地运动"。

## 决策框架

### 看多必要条件

1. **政府订单可见度**（订单簿 + 多年期合同）
2. **战略级地位**（国防部 / NASA / 北约不可替代）
3. **技术验证**（火箭成功率 / 卫星部署 / 国防系统试用）
4. **强人政治环境下的政策友好**（NASA 局长 / 国防部官员人选）

### 看空触发

- 关键技术验证失败（如 RKLB Neutron 水静压破裂）
- 政府订单流转向竞争者
- 战略报告转向（民主党上台部分扭转，但大方向难变）
- 烧钱过度 + 缺现金（部分早期太空公司）

### Veto

- ❌ 押注短期战争爆发（极低概率）
- ❌ 国防股 + 单点地缘新闻的情绪化买卖
- ❌ 没有政府订单 / 战略地位的"太空概念股"
- ❌ 把"地缘紧张 = 国防股必涨"线性外推
- ❌ 押注中国 ITU 卫星申报全部兑现（执行能力存疑）

### 打脸条件

- 若 SpaceX IPO 估值低于 1 万亿 → 太空赛道热潮可能延后
- 若 RKLB 中型火箭 Neutron 验证持续失败 → 卡脖子环节缺位
- 若美国国家安全战略报告转向 → 国防订单优先级重排

## 常见误读

1. **把"地缘紧张"等同于"国防股必涨"** — 错。要看具体事件级别 + 谁直接受益。委内瑞拉是 HII（航母）+ GD（地面）+ PLTR（AI 情报）+ LHX（电子战）+ KTOS / AVAV（无人系统）+ KBR（后勤）的细分链条。
2. **把"PLTR 估值高"读成"该卖"** — 错。博主明确写过"看业绩增速一骑绝尘，看估值水平胆战心惊" — 估值不是 veto，业绩 + 订单可见度才是。
3. **把"SpaceX 上市"等同于"太空股全涨"** — 错。带动一波热度但分化，有政府订单 / 技术验证的（RKLB / ASTS）才是核心，其他是搭便车。
4. **把"中国 ITU 卫星申报量大"等同于"中国太空领先"** — 错。要看执行能力（17 号同日两枚火箭失败）和实际部署。
5. **把"TACO 模式"用到主权问题上** — 错。关税绑定主权（格陵兰）时无法 TACO，欧洲国家在主权问题上反而硬。
6. **把"老马大新闻"翻译成"特斯拉 / SpaceX 必涨"** — 错。老马的工程奇迹是软变量（Colossus 122 天建成），但**短期股价**仍受财务模型约束。
