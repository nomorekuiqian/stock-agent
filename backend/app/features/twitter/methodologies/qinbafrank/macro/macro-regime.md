# Skill: Macro Regime — qinbafrank 怎么读市场环境

## 适用问题

- Fed / 联储 / 降息 / 加息 / 缩表 / 流动性
- CPI / PCE / 通胀 / 非农 / 就业 / GDP
- TGA / 准备金 / SOFR / SRF / ON RRP（流动性体制层面）
- 川普 / 关税 / TACO / 贝森特 / 沃什 / 政策三人组
- 地缘：霍尔木兹 / 伊朗 / 委内瑞拉 / 中美博弈 / 中东
- "美股要不要大顶 / 大底 / 现在是哪一级调整"
- 黄金 / 央行购金 / 资产 MEME 化 / 周期压缩

## 核心问题

**当前市场主导因子是什么？它会造成什么级别的风险？**

不预测精确点位、不预测降息节奏、不喊崩盘。只回答两个东西：

1. 当下"阵眼"是流动性 / 政策 / 地缘 / 产业基本面 中哪一个？
2. 当前调整 / 反弹处在小 / 中 / 大 哪一级？需要什么触发条件才升级？

## 他看什么信息

### 流动性体制（他写得最深的部分）

- **银行准备金规模** — 3.0 万亿是充裕到紧张的临界，跌破开始警觉；回升到 3.2 万亿以上才是真正的充裕过剩区间
- **TGA 账户** — 政府停摆下持续走高 = 抽水机，影响银行准备金
- **ON RRP** — 从 2 万亿用到接近 0 = 流动性缓冲垫见底
- **SOFR - EFFR 利差** — 放大 = 流动性紧张早期信号；SOFR 突破利率走廊上限 = 钱荒级警报
- **SRF 使用量** — 创新高 → 钱荒前奏（10/31 创 503.5 亿历史纪录）
- **美元流动性公式**：`美联储资产负债表 - ON RRP - TGA = 银行准备金 + 流通现金`
- **联储资产负债表** — 缩表节奏 + 停止时间 + 是否重启扩表
- **H.4.1 周报 + 财政部 Daily Treasury Statement** — 高频追踪入口

### 政策经济学（"四螺旋"驱动）

- **政策三人组** — 贝森特（财政）+ 沃什（联储）+ 德鲁肯米勒（市场顾问），凯恩斯式需求管理终结
- **关税战节奏** — TACO 模式（True Always Caves Out）：川普先加狠 → 谈 → 让步，但**关税绑定主权问题（如格陵兰）则破坏 TACO**
- **国家安全战略报告级文件** — 比单条新闻信号强
- **中期选举前的"可负担性"主题** — 通胀控制 + 油价压制 → 反向压力链

### 通胀和就业数据

- **核心 CPI / PCE 同比** — 不被 headline 误导
- **非农 + 行业拆分** — 25 年 71 万医疗 vs 其他行业 -12 万的真实疲软
- **GDP** + 软着陆叙事
- **CPI 连续两个月数据** — 决定 12 月降息能否持续

### 地缘咽喉

- **霍尔木兹海峡** — 实际通行量（不只是 AIS 数据）+ IRGC 动态
- **委内瑞拉** — 石油储量 + 中美博弈链
- **OPEC+ 凝聚力** — 阿联酋退出 → 多米诺
- **CFTC 持仓 / COT 报告** — 日元净空头 vs 净多头转换看套息撤退

### 市场结构

- **VIX** — < 14 = 无对冲状态、均值回归风险高
- **大科技财报** — 用基本面"反驳"宏观焦虑
- **资产 MEME 化** — 信息半衰期 + 衍生品闭环 + 周期压缩

## 他如何理解（分析路径 5 步）

### Step 1 — 当下处在哪个阶段？历史上有没有类似的？

他**极爱用历史类比**给当下定位：

- 现在的流动性紧张 → 19 年 9 月钱荒
- AI 现在的状态 → 不是 00 年互联网泡沫，是 08 年互联网渗透率拐点
- 当前美股调整 → 25 年 2-4 月关税战的延续 vs 不同
- 智能手机渗透率（90s 互联网）vs AI 渗透率

### Step 2 — 拆解机制：钱从哪里来？流到哪里去？

不接受"市场情绪"或"利好"这种黑箱，必须能拆到具体公式：

- 美元流动性公式（见上）
- 关税链：川普加 → 企业利润压缩 → 转嫁消费者 → 通胀压力 → 联储反应
- 央行购金 → 主权储备多元化 → 黄金长期 floor

### Step 3 — 风险等级评级

```
小级别  个位数（5-10%）        常态、健康
中级别  15-20%                  参考 25 年 2-4 月（纳指 -27%、标普 -18%）
大级别  ≥25%                    需要"产业基本面崩塌"或"宏观大危机"
```

### Step 4 — 时间窗口

他几乎一定写"什么时候会被验证"：

- "12 月初联储正式停止缩表"
- "1 月中宏观大事件多起来"
- "本周 CPI / FOMC / 财报 的看点"
- "中期选举前川普的政治优先级"

### Step 5 — 反向情景与极端剧本

经常写"最佳剧本" vs "最坏剧本"，强调**两边都画出来**：

- **最佳**：利率缓慢下降 + SLR 解绑 + 银行回归主业 + 实体经济信贷复苏
- **最坏**：通胀失控 + 联储被迫加息 + 风险资产大跌

## 宏观 x AI 基本面的组合判断

宏观不能孤立回答，尤其是用户问美股 / 纳指 / AI 主线时。要把流动性环境和产业基本面交叉判断：

| 组合 | 博主框架下的含义 | 散户怎么理解 |
|---|---|---|
| 流动性紧 + AI 基本面强 | 更像杀估值，不是杀逻辑 | 回调先看资金压力是否缓和，不急着把主线判死 |
| 流动性紧 + AI 基本面弱 | 风险升级，可能从杀估值转向杀业绩 / 杀逻辑 | 不能用"调整下更好"自动解释下跌 |
| 流动性松 + AI 基本面强 | 趋势延续概率更高 | 重点看赢家是否继续扩大营收和 RPO 差距 |
| 流动性松 + AI 基本面弱 | 指数可能被宽松托住，但 AI 内部会分化 | 防止把宏观顺风误读成产业逻辑仍强 |

这张矩阵的用途是防止两个常见错误：

1. 只看宏观流动性，把所有下跌都解释成"抽水"。
2. 只看 AI 长期叙事，忽略资金市场压力对高估值资产的折现影响。

## 流动性单指标使用纪律

- **3 万亿准备金不是魔法线**。它是警戒线，不是交易信号。必须同时看 SOFR-EFFR 利差、SRF 使用、NFCI / 信用利差、VIX / 市场宽度。
- **TGA 上升先问资金来源**：如果主要消耗 ON RRP，冲击较小；如果开始压银行准备金，才更接近资金市场压力。
- **准备金下降不等于美股必跌**。真正的传导链是：准备金下降 -> 短端资金压力上升 -> 风险资产折现率/流动性溢价变化 -> 高估值成长股先承压。
- **AI 财报能改变宏观冲击的市场含义**。如果大科技营收、利润、RPO 仍能证明 capex 正在变现，宏观逆风更可能是杀估值；如果财报同时证伪 ROI，才升级为杀逻辑。

## 决策框架

### 看跌（中级别以上调整）触发条件

**必须至少满足一项**：

1. **产业基本面崩塌信号**：半数以上大科技公司财报 miss + 营业利润远跟不上 capex
2. **宏观大冲击**：通胀失控 / 强人政策极端化 / 系统性流动性危机（钱荒级）

### 看跌（小级别调整）触发条件

- 流动性紧张但有救市预期
- 高预期市场遇上"不够炸裂"的财报（杀估值）
- 单点地缘冲突未升级

### 反向看多（Buy the Dip）触发条件

- 流动性紧张已经出现救市动作
- 估值杀到位（"调整下更好"）
- 产业基本面坚实但市场过度恐慌

### 经典打脸条件

- "若 CPI 连续两个月超预期 → 12 月降息可能取消"
- "若半数大科技财报 miss → 业绩撑不起市场预期"
- "若霍尔木兹封锁超过一周 → 油价定价权变迁"
- "若准备金不能回到 3.2 万亿且 SOFR 持续破上限 → 必须依赖联储购债扩表"

### Veto

- ❌ 不基于阴谋论下注（即使分析里写了）
- ❌ 不基于地缘单点事件做空（除非升级到主权 / 战争级）
- ❌ 不在没有救市动作的流动性危机中买入
- ❌ 不预测降息节奏 / 不喊 Fed 必降息 / 不预测大顶大底
- ❌ 不基于单条 Fed 官员推文做转向判断

## 常见误读

1. **把"宏观利空"翻译成"减仓"** — 错。他的口径是"宏观逆风多数时候是杀估值，不是杀逻辑"。基本面强的标的反而是上车机会。
2. **把"政策三人组"当成确定性叙事** — 错。他写过沃什 vs 哈塞特两条路径，不押注单一结果。
3. **把"19 年钱荒类比"套到任何流动性紧张事件** — 错。19 年钱荒有 SOFR 18bp 单日跳升的明确触发点；类比时必须有同等量级的信号。
4. **把"TACO 模式"当成万能模板** — 错。"关税绑定主权问题（如格陵兰）则破坏 TACO"是显式例外。
5. **把"地缘升级"等同于"市场必跌"** — 错。市场更在意"何时谈"而非"何时打"，"打而不破"是基线。
6. **把博主的"个人角度"误读为强信念** — 错。"个人角度 / 个人以为"是他的对冲式开场，强信念会用"势在必行 / 大概率 / 核心逻辑是"。
7. **把"调整下更好"套到杀逻辑场景** — 错。前置条件是"基本面未破"。如果是杀逻辑（叙事崩塌），跌得更多也不该买。
