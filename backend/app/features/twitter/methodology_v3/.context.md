# Twitter Methodology V3 - Persona 方法论蒸馏工具

## 功能概述

`features/twitter/methodology_v3/` 是 KOL persona 方法论蒸馏的离线脚本包。它从 Insforge 中导出 persona tweets，按 ticker/sector/core/macro 分桶，生成 evidence slices 和 compact views，并审计最终 skill markdown 中引用的 tweet ids。

正式运行材料存放在 `features/twitter/methodologies/`；中间产物写入 gitignored 的 `_distillation_artifacts/` 目录。

## 文件结构

| 文件 | 职责 |
|------|------|
| `personas.py` | persona 配置、ticker aliases、sector keywords、目录解析 |
| `export_corpus.py` | 从 `kol-tweets` edge function 导出全量 filtered corpus |
| `bucketize.py` | 规则分桶，生成 ticker/sector/core/macro indices |
| `slice_corpus.py` | 按 bucket 切出 per-skill JSONL evidence slices |
| `compact_slices.py` | 生成便于人工阅读的一行一 tweet compact text |
| `evidence_audit.py` | 校验 skill markdown 中 tweet_id 是否存在于 corpus |
| `cleanup_skills.py` | 一次性清理/术语替换脚本 |

## 常用命令

```bash
cd backend
source venv/bin/activate
python -m app.features.twitter.methodology_v3.export_corpus --persona-key qinbafrank-skill-v3
python -m app.features.twitter.methodology_v3.bucketize --persona-key qinbafrank-skill-v3
python -m app.features.twitter.methodology_v3.slice_corpus --persona-key qinbafrank-skill-v3
python -m app.features.twitter.methodology_v3.compact_slices --persona-key qinbafrank-skill-v3
python -m app.features.twitter.methodology_v3.evidence_audit --persona-key qinbafrank-skill-v3
```

## 依赖

- `app.core.database.get_insforge_service`
- `app.core.config.EDGE_FUNCTION_SECRET`
- `app.core.logging.get_logger`
- `features/twitter/methodologies/` runtime material directories

## 注意事项

- 这些脚本是离线蒸馏工具，不应被 API request path import。
- 生成的 corpus/slices/audit 输出不要提交，除非明确是 promoted runtime material。
- `bucketize.py` 是规则分桶，不调用 LLM；保持可重复、可审计。
