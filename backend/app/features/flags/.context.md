# Feature Flags Module

Per-user feature flags for gradual rollout / canary testing.

## Architecture

`feature_flags` table (Insforge) → `feature-flags.js` Edge Function → `db.py` → `router.py` → `GET /api/flags`

## Key Constraints

- Flags are **read-only** from the API. Writes happen via manual SQL in Insforge Dashboard.
- Edge Function has no auth — security is enforced at the FastAPI layer via `verify_user_token`.
- On any failure, the system returns an empty flag set (safe fallback to V1 / default behavior).
- No RLS on the table (consistent with other EF-accessed tables).
