# Public SEO projections — 2026-10-18 implementation plan

`GET /api/seo/stock/{symbol}`, `/kol/{username}`, `/ticker-discussion/{symbol}`, `/sentiment`, `/report-timeline` expose bounded public projections. Missing stocks return 404, upstream failures 503. No public request invokes an LLM. Full stock/morning analysis remains protected by its original backend entitlements.

Stock responses allow investment summary and earnings opening paragraph up to 250 characters; guidance/full analysis is omitted. `digest_projection.py` uses stored digest argument summaries (not raw tweets), caps each at 60 characters, filters prohibited licenses/crypto topics, and hides ticker discussions with fewer than two authors. Counts describe distinct stored evidence URLs; they are not a census of all author posts. KOL public roots support qinbafrank/aleabitoreddit only. The plan separately enables authenticated Max cockpit GETs for these authors; all other paused products, MCP routes and dedicated schedules remain paused.

`company_content.sqlite` ships 70 sourced descriptions and fallback profiles. `company_names.py` is the maintained 70-name data-layer fallback; `company_facts.json` stores source-backed FAQ facts. Six priority descriptions and additional samples/revisions have agent source review (see docs/seo/2026-10-18/plan-company-review.json); required human sign-off remains separate. Offline import `scripts/seo/prepare_company_content.py --input FILE` uses the shared publication guard, makes no network/model calls, and preserves old content on rejection.

For production, mount persistent writable storage and set `SEO_CONTENT_DB`. Lifespan initializes a missing database from the shipped seed before startup, verifies its integrity, and never replaces an existing database. Production refuses to start without an explicit storage path. Preserve it across releases and back it up. Do not point to an empty file: it also stores generated content, provenance, job leases, review candidates, licenses and title direction cooldowns. Multiple workers on one SQLite file use transactional leases; separate machines need the same authoritative storage before enabling workers. `get_logger` records failures without source payloads.

Successful daily/morning/digest saves enqueue revision-deduplicated jobs. Earnings actuals discovered in the existing stock earnings data flow enqueue a public paragraph. The production lifespan worker polls every minute, leases four jobs, caps each model call at 120 seconds, and retries at most three times. Weekly author summaries enqueue once per ET day after 07:00 using stored recent digests. No paused ingestion schedule is enabled. Old sources can be imported with the explicit local backfill command; page GETs never generate copy.

`policy.py` requires traceable source IDs, supplied numeric placeholders, finite values, content bounds and non-promotional language. Publication checks the source revision under a transaction; rejected candidates retain the previous published version and enter review. Publication clears the backend public cache; frontend revalidation is at most one hour. Generated fields persist model, prompt version, generated_at and source_ids. Numeric provenance checks do not replace human factual review.

`service.py` caches for one hour, coalesces reads, derives daily/20-trading-day returns from historical closes, and changes directional titles at most once per seven days. Source modification dates exclude quote retrieval timestamps. Calendar conflicts are logged; unverified dates stay estimated. Dividend yield input is already percentage points; values above 25 are logged and omitted.

IndexNow remains production-only and best effort. Notifications are not indexing evidence. The existing save hooks notify changed public URLs; `/api/seo/refresh` requires `verify_cron_secret`. No third-party configuration is changed.

Frontend metadata, visible text and sitemap share `stockContent`. The numerator counts deduplicated source prose and specific FAQs, excluding recurring editorial guidance; denominator projects visible article text, excluding navigation/footer/disclaimers. Samples and existing directory controls require 40% and a 150-character description. Five specified W1 exceptions expire on 2026-11-02 ET. Other symbols remain noindex. Legacy earnings children redirect to the canonical #earnings module.
