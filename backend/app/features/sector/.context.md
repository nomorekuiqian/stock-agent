# Sector - 板块分析

## 功能概述

为 12 个预定义板块（Mag7、半导体、中概股等）生成每日 AI 分析日报。使用 Gemini Flash 分析板块内个股表现、相关新闻和宏观背景。支持用户订阅板块邮件推送。可通过 cron 批量生成全部板块日报。

## API 端点

| 端点 | 方法 | 描述 | 认证 |
|------|------|------|------|
| `/api/sectors/` | GET | 列出全部板块配置 | 无 |
| `/api/sectors/{sector_id}/digest` | POST | 生成指定板块日报 | 无 |
| `/api/sectors/{sector_id}/digest/latest` | GET | 获取最新板块日报 | 无 |
| `/api/sectors/{sector_id}/digest/history?days=30` | GET | 历史日报列表 | 无 |
| `/api/sectors/subscribe` | POST | 订阅板块邮件 | Bearer Token (`verify_user_token`) |
| `/api/sectors/subscriptions` | GET | 查询用户订阅 | Bearer Token (`verify_user_token`) |
| `/api/sectors/{sector_id}/unsubscribe` | DELETE | 取消订阅 | Bearer Token (`verify_user_token`) |
| `/api/sectors/generate-all` | POST | 批量生成全部板块日报 | X-Cron-Secret |

## 数据流

```
POST /api/sectors/{sector_id}/digest
  |
  +-- 校验 sector_id (是否存在且 enabled)
  |
  +-- SectorDigest.generate(sector_id)
  |   +-- 获取板块配置 (symbols 列表)
  |   +-- 并行获取:
  |   |   +-- get_stock_quotes(symbols) — 个股报价
  |   |   +-- get_combined_market_news(symbols + SPY/QQQ) — 相关新闻
  |   |   +-- get_economic_calendar(7天) — 经济事件
  |   |   +-- get_earnings_calendar(7天) — 财报日历(过滤板块相关)
  |   |   +-- get_all_market_data() — 宏观背景(SPY/QQQ/VIX/10Y/USD)
  |   |
  |   +-- 数据清洗 (新闻截断500字, 财报过滤, 最多30条新闻)
  |   +-- Gemini Flash Agent 生成结构化日报
  |
  +-- 保存到 DB (sector_digests 表)
  +-- 返回日报
```

| 文件 | 职责 |

### Agent 输出结构
- `greeting` — 日期 + 板块名 + 钩子标题
- `intro` — 2-3 句板块表现概述
- `stocks` — 5-8 只关键个股 {symbol, name, change_percent, analysis}
- `news` — 5-8 条相关新闻 {title, summary, url}
- `events` — 3-6 个即将到来的事件
- `summary` — 4 段 Markdown 深度分析（今日回顾 + 行业逻辑 + 风险机会 + 展望）

### 批量生成 (/generate-all)
- 按顺序遍历全部 12 个 enabled 板块
- 每个板块独立生成，单个失败不影响其他
- 返回成功计数（如 "Generated 10/12 sector digests"）

### 新闻智能过滤
- 新闻查询时除板块个股外，额外加入 SPY/QQQ/VIX 获取宏观新闻
- 财报日历过滤: 只保留板块个股 + 科技巨头的财报
- 新闻正文截断到 500 字以节省 token

## 注意事项

- SectorDigest 使用单例模式，避免重复创建 InMemoryRunner
- 板块配置硬编码在 models.py 的 SECTORS 列表中，添加新板块需修改此处
- 使用 Flash 模型（非 Pro），成本更低、速度更快
- cron 端点需要 X-Cron-Secret 认证
- 订阅功能通过独立的 Edge Function (sector-subscriptions) 管理
- P0 后订阅接口统一以后端 token user_id 为准，不再信任前端 query/body 中的 `user_id`

## 产品愿景

> 对应产品模块：板块分析 /sectors（详见 Obsidian 产品策略.md）

**当前阶段**：12 个板块每日自动生成 AI 分析，含成分股表现、新闻、事件，付费功能。

**下一步**：
- **持仓关联**：用户持有的股票属于哪些板块？板块异动对持仓的影响
- **板块轮动信号**：从每日总结升级为板块动量变化检测
- **机会发现信号源**：板块异动 → 触发机会发现模块推送

**长期定位**：持仓体检（板块分布 + 集中度分析）和机会发现（板块异动信号）的数据来源。
