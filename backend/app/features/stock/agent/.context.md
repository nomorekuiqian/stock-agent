# Stock Agent - 个股 AI 分析子模块

## 功能概述

`features/stock/agent/` 拆分个股 AI 分析能力。`stock/router.py` 和 `stock/service.py` 调用这些 agent 生成结构化中文投研内容，并由 `stock/db.py` 缓存结果。

## 文件结构

| 文件 | 职责 |
|------|------|
| `_base.py` | ADK session 运行、结构化输出解析、通用错误处理 |
| `fundamental.py` | 基本面/估值/财务健康分析 |
| `technical.py` | 技术面指标、图表情景和交易信号分析 |
| `news.py` | 新闻、分析师活动和催化事件分析 |
| `macro.py` | 宏观环境与板块定位分析 |
| `earnings.py` | 财报结果、指引、业务驱动和 transcript/data-only 双模式分析 |
| `market_overview.py` | Market Tab 综合市场面解读 |
| `__init__.py` | 兼容导出所有 public agent/getter/output symbol |

## 运行模式

```text
router/service 准备精简输入
  -> get_*_agent() 获取单例
  -> agent.analyze(...)
  -> _base.run_agent_session()
  -> ADK InMemoryRunner
  -> Pydantic output schema
  -> router 保存 stock_analyses cache
```

## 依赖

- `google.adk.agents.LlmAgent`
- `google.adk.runners.InMemoryRunner`
- `app.shared.llm_metering.meter`
- `app.utils.timezone.now_iso`
- `app.core.logging.get_logger`

## 注意事项

- 新增 LLM agent 必须挂 `meter(feature, model=...)`，避免生产成本不可观测。
- 所有输出都应保持结构化 schema，不要让 router 解析自由文本。
- `__init__.py` 保持向后兼容；迁移 import 时优先从具体文件导入，但不要破坏现有 `app.features.stock.agent` 导入。
- 失败时返回空结构或抛明确异常，不能把错误消息伪装成分析正文。
