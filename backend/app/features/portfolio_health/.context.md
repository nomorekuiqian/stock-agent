# portfolio_health module

Portfolio Health Check -- 4-dimensional scoring + AI diagnosis for user portfolios.

## Overview

Users can generate a "portfolio health check" that scores their holdings across
4 dimensions (0-25 each, total 0-100), plus an AI-generated diagnosis paragraph.
Results are cached daily. Both POST generation and latest-read endpoints require
Bearer auth plus `portfolio_management` entitlement. A lightweight
`portfolio_insights` table stores the
latest result for each user, which the brew digest agent can read to inject
"background knowledge" into daily reports.

## Files

| File | Role |
|------|------|
| `models.py` | Pydantic models: HealthScore, DiagnosisOutput, HealthReport, API responses |
| `scoring.py` | Pure functions for 4-dimension scoring (no I/O, fully testable) |
| `agent.py` | Google ADK LLM agent for diagnosis generation |
| `service.py` | Orchestrator: scoring + diagnosis + caching |
| `db.py` | Insforge Edge Function access (portfolio-health EF) |
| `router.py` | FastAPI endpoints: POST /health, GET /health/latest |

## Scoring dimensions (each 0-25)

1. **Dispersion**: Sector diversification via `get_true_exposure()`
2. **Performance**: 1-week weighted return vs SPY
3. **Macro Fit**: Sector alignment with current macro risk level
4. **Stability**: Weighted portfolio volatility vs SPY

## Dependencies

- `portfolio` module: HoldingView, ProfileView, exposure_parser, db
- `macro.risk` module: macro risk dashboard data
- `shared/data_tools`: quotes, fundamentals
- `shared/profile_context`: inject_profile for agent personalization

## DB tables (deployed separately)

- `portfolio_health_reports`: full health report with scores + diagnosis
- `portfolio_insights`: latest snapshot per user (for brew injection)

Edge Function: `portfolio-health` (see `backend/app/edge_functions/portfolio-health.js`)
Schema: `backend/migrations/u1b_health_schema.sql`
