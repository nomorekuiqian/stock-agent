# Frank MCP - Market Lens MCP Server

## 功能概述

`app/frank_mcp/` 是和 FastAPI 后端同仓部署的 FastMCP server。当前 v1 暴露 qinbafrank persona 的方法论 lens 和推文证据搜索，供外部 agent 通过 `/frank/mcp/` 调用。

该 MCP 输出的是「历史观点证据 + 方法论上下文」，不是实时行情服务，也不能代表 qinbafrank 本人给出投资建议。

## 文件结构

| 文件 | 职责 |
|------|------|
| `server.py` | FastMCP 实例、工具注册、standalone dev runner |
| `middleware.py` | tool-call 结构化日志、可选 shared-token access gate |

## 工具

| Tool | 说明 |
|------|------|
| `frank_list_sectors` | 列出 qinbafrank sector lenses |
| `frank_get_sector_lens` | 返回指定 sector 的 stance、signals、triggers |
| `frank_get_ticker_lens` | 返回指定 ticker 的 Frank lens |
| `frank_search_evidence` | 语义搜索 qinbafrank 历史推文 chunks |

## 挂载与运行

- FastAPI mount: `app.main` 将 MCP app 挂在 `/frank/mcp/`
- 本地 standalone: `cd backend && python -m app.frank_mcp.server`
- 默认 standalone 地址: `http://127.0.0.1:9000/mcp/`

## 依赖

- `fastmcp`
- `app.features.kol_research.skill_cockpit`
- `app.features.kol_research.router._mcp_search_chunks`
- `app.core.logging.get_logger`

## 环境变量

- `FRANK_MCP_ACCESS_TOKEN`: 可选。设置后调用方必须发送 `Authorization: Bearer <token>` 或 `X-Frank-Token`。

## 注意事项

- `server.py` 的工具返回必须保持 agent-readable JSON，不要返回前端 HTML。
- `frank_search_evidence` 是历史证据搜索；回答层必须区分「Frank 原话证据」和「方法论推断」。
- access gate 是 private-preview 软门禁；不设置 token 时 MCP 是开放的。

## 可恢复功能暂停（2026-09-04）

MCP 暂停：HTTP 挂载路径由统一中间件阻断，standalone FastMCP AccessGateMiddleware 也在 on_request/on_call_tool 拒绝，旧 token 无法继续调用。
