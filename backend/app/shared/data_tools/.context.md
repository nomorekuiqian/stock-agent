# Data Tools - 数据获取工具层

## 功能概述

为 AI Agent 提供结构化市场数据的获取工具。所有函数返回 JSON 兼容的字典，不做分析解读，纯数据获取层。被 market、stock、sector、digest、weekly_report 等 Agent 模块调用。

## 模块一览

| 文件 | 职责 | 数据源 |
|------|------|--------|
| `market_data.py` | 市场指数、利率、商品、汇率、个股报价 | yfinance + FMP |
| `news.py` | 市场新闻聚合 (3 源合并去重) | FMP API |
| `calendar.py` | 经济日历 (高影响力美国事件) | FMP API |
| `earnings.py` | 财报日历 (大盘股) | FMP API |
| `technical.py` | 技术分析指标 (30+ 指标 + 趋势) | tvscreener + pandas-ta |
| `fundamentals.py` | 公司资料、财务报表 (替代 openbb_service.py) | FMP API |
| `quotes.py` | 统一报价接口 (批量 + 实时单只) | FMP API |
| `search.py` | 股票搜索 | FMP API |
| `peers.py` | 同行比较、行业估值 | FMP API |
| `briefs.py` | 复合 brief 工具（个股/同行/宏观/行业一次聚合）| 细粒度工具 + `macro_data_cache` |
| `research_tools.py` | ADK Agent 暴露的 async tool 包装层 | 复用细粒度工具 |

## market_data.py

### get_all_market_data() -> dict
一次调用获取全部市场数据，供 Agent 分析使用。

**返回结构**:
```python
{
  "status": "success",
  "equities": {
    "S&P 500": {value, daily_change, week_change, month_change, trend, position_in_range},
    "Nasdaq": {...}, "Dow Jones": {...}, "Russell 2000": {...}, "S&P 400": {...}
  },
  "volatility": {"VIX": {...}},
  "rates": {
    "yield_curve": {"3M": {rate, daily_change_bps}, "5Y": {...}, "10Y": {...}, "30Y": {...}},
    "spreads": {"10y_3m", "10y_5y", "30y_10y"},
    "source": "fmp|yfinance",
    "yield_curve_shape": "normal|inverted|flat"
  },
  "credit": {"HYG": {...}, "LQD": {...}, "hyg_lqd_spread": float},
  "financials": {"XLF": {...}, "KRE": {...}},
  "commodities": {"Gold": {...}, "Oil": {...}},
  "currencies": {"US Dollar": {...}},
  "report_date": {date, weekday, time, formatted}
}
```

**数据源优先级**:
- 国债利率: FMP (12 期限点 + 日变化 bps) -> yfinance 降级 (4 期限点)
- 商品: FMP 现货 (当前价+日变化) + yfinance 期货 (周/月趋势) 合并
- 其他: yfinance (1 个月历史数据下载)

**每个资产的通用字段**:
```python
{
  "value": float,          # 当前价/值
  "previous_close": float,
  "daily_change": float,   # 百分比
  "week_change": float,    # 百分比
  "month_change": float,   # 百分比
  "trend": "up|down|flat", # 基于 week_change
  "position_in_range": float  # 0-100, 在 1 月区间中的位置
}
```

用户自选股报价（最多 20 只）。

**返回**: 每只股票包含 price, daily/week/month_change, pe_ratio, market_cap, 52_week_high/low

## news.py

### get_combined_market_news(days=1, symbols=None) -> dict
**主入口**，合并 3 个新闻源并去重排序。

**3 个新闻源**:
1. `fmp_ticker`: 个股新闻（Mag7 + 半导体 + 指数 + 用户 symbols）
2. `fmp_general`: 宏观/政策/经济新闻
3. `fmp_latest`: 广泛市场新闻

**去重逻辑**: 标题前 50 字符（去特殊字符）作为 key，相同 key 只保留第一条

**时间过滤**: 工作日按 24 小时滚动；周末/周一包含上周五的新闻

**返回**:
```python
{
  "news_count": int,
  "news": [{symbol, headline, text, publishedDate, url, ...}],
  "source": "fmp_combined",
  "sources": {"ticker_news": n, "general_news": n, "latest_news": n}
}
```

## calendar.py

### get_economic_calendar(days=14) -> dict
获取未来 N 天高影响力美国经济事件（最多 90 天）。

**过滤条件**: `impact == "High" AND country == "US"`

**关键事件标记**: Fed 利率决议、FOMC、CPI/PPI、非农、GDP 等

**返回**:
```python
{
  "events_count": int,
  "events": [{date, event, previous, estimate, actual, impact, is_key_event}],
  "filter": "US High Impact only"
}
```

## technical.py

### get_technical_data(symbol, timeframe="daily", limit=200) -> dict
**主入口**，从 FMP 获取 OHLCV + 技术指标序列，本地计算衍生信号，供技术分析 Agent 和前端图表使用。

**数据源**: FMP (Financial Modeling Prep) API
- `fmp.get_historical_price()` -> OHLCV 日线数据
- `fmp.get_technical_indicators()` -> RSI, SMA, EMA, ADX, Williams %R 时间序列

**本地计算** (pandas + numpy, 不使用 pandas-ta):
- MACD: 从 EMA(12) 和 EMA(26) 计算 MACD/Signal/Histogram
- Bollinger Bands: SMA(20) +/- 2*StdDev
- 支撑/阻力: 滚动窗口 swing high/low
- 衍生信号: MA 排列、RSI 区域、MACD/SMA 交叉、BB 位置/挤压、趋势强度、成交量趋势
- 趋势摘要: 最近 20 日指标变化总结 (供 AI Agent 上下文)
- 周线聚合: 日线 OHLCV 聚合为周线蜡烛图

**返回结构**:
```python
{
  "symbol": "AAPL",
  "timeframe": "daily",
  "source": "fmp",
  "ohlcv": [{date, open, high, low, close, volume}],
  "indicators": {
    "rsi_14": [{date, value}], "sma_20": [...], "sma_50": [...], "sma_200": [...],
    "ema_12": [...], "ema_26": [...], "adx_14": [...],
    "macd": [{date, macd, signal, histogram}],
    "bb": [{date, upper, middle, lower}],
  },
  "current": {price, volume, rsi_14, macd_histogram, macd_level, macd_signal, adx_14, sma_20/50/200, bb_upper/lower, williams_r},
  "derived": {ma_alignment, rsi_zone, macd_cross, sma_50_200_cross, bb_position, bb_squeeze, trend_direction, trend_strength, volume_trend, volume_ratio},
  "support_resistance": {current_price, support_1/2, resistance_1/2},
  "trend_summary": {rsi_20d_ago, rsi_direction, macd_histogram_direction, price_change_5d/20d, volume_vs_avg},
  # Backward-compatible keys for router/research_tools:
  "ratings": {}, "moving_averages": {...}, "oscillators": {...}, "volatility": {...},
  "trend": {...}, "price_volume": {...}, "trends": {...}, "pattern_signals": {...},
}
```

**缓存策略**: 15 分钟 TTL, key = `{symbol}_{timeframe}`

**兼容字段**:
`get_technical_data()` 直接返回 `ratings`、`moving_averages`、`oscillators`、
`volatility`、`trend`、`price_volume`、`trends`、`pattern_signals` 等旧格式字段，
供 router 和 agent 工具继续读取。

## briefs.py

**Brief-level 复合工具**：将多个细粒度调用并发聚合成一份 JSON 输出，供 `kol_research/agent.py` 等需要"一次拿完整画面"的 agent 使用。

四个 brief 入口（均为 async）：

- `get_stock_brief(symbol)` — 个股全景：quote + fundamentals + valuation + news + peers
- `get_peer_brief(symbol)` — 同行比较与行业估值聚合
- `get_macro_brief()` — 宏观全景：只读 `macro_data_cache` 数据库快照（risk / liquidity / sentiment / economic calendar / treasury / economy / inflation / CPI / liquidity context）
- `get_industry_brief(symbol)` — 行业链条画面：profile + peer comparison + 行业估值

**容错策略**：任一子调用抛错 -> 该 section 输出 `{"error": "..."}`，整体 brief 永不失败。`get_macro_brief()` 例外：在线路径 DB-only，不穿透 FRED/FMP；缓存过期时返回 stale 数据并在 `cache.freshness` 标记，全部缺失才返回顶层 `error`。细粒度工具仍保留，brief 只是面向 KOL agent 的"粗颗粒"补充层。

## 注意事项

- 所有函数返回 `{"status": "error", "error": str}` 格式的错误响应
- 所有函数打印 `[TOOL] function_name()` 日志便于调试
- 时间全部使用 Pacific 时区（FMP 返回 UTC，内部转换）
- `safe_float()` 辅助函数处理 NaN/None -> 默认值
- 提取资产数据至少需要 5 个数据点，否则返回 None
- 这是纯数据层，不做任何分析或解读，解读由 Agent 完成
