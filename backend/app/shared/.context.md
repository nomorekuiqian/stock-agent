# Shared - 跨模块共享服务

## 功能概述

提供外部数据源封装 + 跨 feature 的公共能力（profile cache、KOL 配置、LLM 用量埋点）。每个数据服务都是单例，内置缓存和错误处理。

## 服务一览

| 文件 | 数据源 / 用途 | 主要用途 | 被谁调用 |
|------|--------|----------|----------|
| `agent_runtime_feedback.py` | Insforge `agent-sessions` Edge Function | 更新 `agent_session_events.assistant_message` 行上的 thumbs feedback columns | memory.router, agent_runtime.db |
| `fmp_service.py` | Financial Modeling Prep API | 新闻、国债利率、经济日历、财报日历、股票搜索、同行对比、报价、公司资料、内部人交易、earnings transcript | stock, macro/risk, macro/cache, data_tools (market_data/news/calendar/earnings/fundamentals/quotes/search/peers) |

## fmp_service.py (1772 行, 最大)

### 核心能力
- **QuoteCache 类**: 线程安全内存缓存，支持 TTL 和请求合并
- **国债利率**: 12 期限点收益率曲线 + 日变化(bps)
- **新闻**: 个股新闻 + 通用宏观新闻 + 最新市场新闻 (3 个 API)
- **日历**: 经济日历 (High Impact US only) + 财报日历 (大盘股)
- **股票**: 搜索、批量报价、同行分析、行业指标、历史估值
- **商品**: 现货报价 (XAUUSD, BZUSD 等)

### 关键函数
| 函数 | 说明 |
|------|------|
| `get_treasury_rates()` | 12 期限国债 + 日变化 bps |
| `get_market_news(symbols, days)` | 个股新闻 |
| `get_general_news(days)` | 宏观/政策新闻 |
| `get_economic_calendar(from, to)` | 经济日历 |
| `get_major_earnings(from, to)` | 大盘股财报日历 |
| `search_stocks(query, limit)` | 股票搜索（FMP `/stable/stock-list` 无 exchange 字段，故按**符号形状**判主/次：无点号=美股主挂牌、`.KS/.T/.HK`=本土主挂牌、其余 `.XX`=薄量境外交叉挂牌。按 公司名+股份类别 去重：BRK-A/BRK-B 视为不同行；存在主挂牌时丢弃境外交叉挂牌；优先股/权证(`-PA/-WT`)折叠进普通股）|
| `get_peer_stocks(symbol)` | 同行公司列表 |
| `get_industry_pe(industry, sector)` | 行业平均 PE |
| `get_historical_key_metrics(symbol)` | 5 年历史估值 |

### 缓存
- 24 小时股票列表缓存
- QuoteCache: 可配置 TTL + LRU + 请求合并

## yfinance_service.py

### 核心能力
- **YFQuoteCache 类**: 线程安全，TTL 缓存 (用于报价和 Ticker.info)
- **批量报价**: 一次 `yfinance.download()` 获取 70+ 只股票
- **全量指标**: 一次 `yf.Ticker(symbol).info` 获取 TTM、估值、盈利能力、增长、远期估值
- 自动计算日涨跌幅

### 关键函数
| 函数 | 说明 |
|------|------|
| `get_stock_quotes(symbols)` | 批量报价 (高效单次调用) |
| `get_ticker_metrics(symbol)` | 全量基本面指标 (TTM/估值/盈利/增长/远期, 10min 缓存) |
| `clear_cache()` | 清空所有缓存 |

### 使用模式
```python
yf_service = get_yfinance_service()  # 单例
quotes = yf_service.get_stock_quotes(["AAPL", "MSFT", ...])
metrics = yf_service.get_ticker_metrics("NVDA")  # {ttm, valuation, forward, profitability, growth}
```

## llm_metering.py

LLM usage 记录器，给每个 `LlmAgent` 自动记录 token 用量到 Insforge `llm_usage` 表，按 `feature × model` 维度归因成本。非 ADK provider（例如 DeepSeek direct API）使用 `record_usage(...)` 写入同一张表。

```python
from app.shared.llm_metering import meter

my_agent = LlmAgent(
    name="my_agent",
    model=MY_MODEL,
    ...,
    after_model_callback=meter("feature.subtask", model=MY_MODEL),
)
```

- **fire-and-forget**: 写库失败只 warn，不阻塞 LLM 响应
- **feature 命名约定 / 查询 SQL / 故障速查 / 禁忌** 全部见 `docs/guides/llm-usage-metering.md`
- **新 LlmAgent 必须挂 callback**，否则那个 feature 进 prod 后就是成本黑洞

## llm_clients/

当前生成链路使用 Gemini 原生 API 和 structured JSON adapter：

- `deepseek.py`: 调 `DEEPSEEK_BASE_URL/chat/completions`，使用 `DEEPSEEK_API_KEY`。
- `structured.py`: JSON parse、Pydantic validation、validation-error retry，并调用 `llm_metering.record_usage()`；provider 为 `google`，候选文本和 thinking token 分开计量。
- Gemini JSON mode 后继续做本地 schema 校验；调用方使用小 schema 分任务处理，业务质量门保持不变。

## 注意事项

- fmp_service.py 是最大的文件，包含几乎所有外部金融数据获取逻辑
- 所有服务使用单例模式 (`get_xxx_service()` 函数)
- FMP API 需要 `FMP_API_KEY` 环境变量
- 数据库访问应使用 `core/database.py` + 各 feature 模块的 `db.py`
- Feature 之间不要直接互相 import；如果一个 feature 需要另一个 feature 拥有的数据/能力，先通过 `app.shared.*` 暴露明确边界（例如 `entitlements.py`、`user_watchlists.py`、`vector_retrieval.py`）。
- yfinance 只用于 `Ticker.info` 基本面指标 (TTM/估值/盈利)，批量报价已改用 FMP
- openbb_service.py 已删除，功能已迁移到 data_tools/fundamentals.py (直接调 FMP)
- llm_metering.py 是新加的观测层，所有 LlmAgent 都应该挂 `meter()` callback；详见 `docs/guides/llm-usage-metering.md`
- `twitter_kol_config.py` 是 KOL 账号清单的共享入口；新增/改名 KOL 时同步检查 twitter ingestion、twitter_digest、kol_research 和 vector indexing。


### Gemini 3.8 迁移（2026-09-04）

- `llm_clients/gemini.py`：原生 Google GenAI 客户端，`LOW` thinking、JSON MIME、关闭 SDK 隐式重试，由包装层有限重试 429/5xx 和网络错误。
- `llm_clients/deepseek.py`：遗留客户端保留给历史兼容测试；生产结构化调用不再导入它。
- `llm_pricing.py`：Gemini 3.8 精确匹配 token 费率；输出含 thinking，缓存输入避免重复计价，2027-01-01 切换费率。旧模型继续标为粗估，非账单。

## 可恢复功能暂停（2026-09-04）

暂停功能调用 structured JSON helper 时，在 schema/模型请求之前检查 feature；共享日报生成保持可用。

## 临时 Agent 会话（2026-10-13）

`agent_sessions.temporary_agent_session` 仅用于一次性生成。退出时删除会话，清理失败记录 warning，不覆盖生成结果或原始异常；用户持久对话不使用该工具。
