# Utils - 后端通用工具

## 功能概述

`app/utils/` 放置不属于特定 feature 的轻量通用函数。当前主要是市场时区与日期格式工具。

## 文件结构

| 文件 | 职责 |
|------|------|
| `timezone.py` | UTC / 美股市场时区时间函数、日期格式化、旧函数兼容别名 |

## timezone.py

核心口径：

- 存储和 API timestamp 默认使用 UTC。
- 报告业务日期使用美股市场时区 `America/New_York`。
- 前端展示时再按用户本地时区格式化。

常用函数：

| 函数 | 说明 |
|------|------|
| `utc_now()` / `utc_now_iso()` | 当前 UTC 时间 |
| `market_now()` / `market_today()` / `market_today_str()` | 当前美股市场时区时间/日期 |
| `market_week_label()` | 当前市场周标签，如 `2026.W23` |
| `market_days_ago(days)` / `market_days_from_now(days)` | 市场日期偏移 |
| `format_market_date()` / `format_market_date_chinese()` | 报告头日期格式 |
| `parse_date(date_str)` | 解析 `YYYY-MM-DD` |
| `to_market_tz(dt)` | 转为市场时区 |

## 注意事项

- 新代码优先使用 `market_*` / `utc_*` 命名。
- `now_iso()`、`today_str()`、`now_pacific()` 等函数是迁移兼容别名，避免在新代码中继续扩散。
- `PACIFIC_TZ` 目前只是 `MARKET_TZ` 的兼容别名，不代表业务时区是太平洋时间。
